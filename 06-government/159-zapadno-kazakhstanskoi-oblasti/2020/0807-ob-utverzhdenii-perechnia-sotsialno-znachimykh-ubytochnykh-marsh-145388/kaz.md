# Орал қаласы бойынша 2020 жылға субсидиялауға жататын ішкі су көлігіндегі әлеуметтік маңызы бар шығынды маршруттар тізбесін бекіту туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңын, Қазақстан Республикасының 2004 жылғы 6 шілдедегі «Ішкі су көлігі туралы» Заңын басшылыққа алып және әлеуметтік маңызы бар шығынды маршруттарды субсидиялау жөніндегі комиссияның ұсынымы негізінде, қала әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Осы қаулының қосымшасына сәйкес Орал қаласы бойынша 2020 жылға субсидиялауға жататын ішкі су көлігіндегі әлеуметтік маңызы бар шығынды маршруттар тізбесі бекітілсін.

<a id="p2"></a>

2. Орал қаласы әкімдігінің 2019 жылғы 27 маусымдағы № 1490 «Орал қаласы бойынша 2019 жылға субсидиялауға жататын ішкі су көлігіндегі әлеуметтік маңызы бар шығынды маршруттар тізбесін бекіту туралы» қаулысының (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 5739 тіркелген, 2019 жылы 5 шілдеде Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкінде жарияланған) күші жойылды деп танылсын.

<a id="p3"></a>

3. «Орал қаласының тұрғын үй-коммуналдық шаруашылығы, жолаушы көлігі және автомобиль жолдары бөлімі» мемлекеттік мекемесі (Ж.Дуйсенгалиев) осы қаулының әділет органдарында мемлекеттік тіркелуін қамтамасыз етсін.

<a id="p4"></a>

4. Осы қаулының орындалуын бақылау қала әкімінің орынбасары М.Мүлкәйға жүктелсін.

<a id="p5"></a>

5. Осы қаулы алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Орал қаласының әкімі**

**А. Шыныбеков**
