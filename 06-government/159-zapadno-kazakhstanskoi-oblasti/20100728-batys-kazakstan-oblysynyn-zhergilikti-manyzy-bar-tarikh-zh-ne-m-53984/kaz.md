# Батыс Қазақстан облысының жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік тізімін бекіту туралы

Қазақстан Республикасының "Тарихи-мәдени мұра объектілерін қорғау және пайдалану туралы", "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Заңдарын басшылыққа ала отырып, облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

1. Қоса беріліп отырған Батыс Қазақстан облысының жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік тізімі бекітілсін.

2. Батыс Қазақстан облысы әкімдігінің "Жергілікті маңызы бар тарихи және мәдени ескерткіштерді мемлекеттік қорғауға қабылдау туралы" 2005 жылғы 31 наурыздағы № 112 қаулысы (нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 2926 тіркелген және 2005 жылғы 24 мамырдағы облыстық "Орал өңірі" газетінде № 60 және 2005 жылғы 31 мамырдағы "Приуралье" газетінде № 63 санында жарияланған) күші жойылды деп танылсын.

3. Осы қаулының орындалуын бақылау облыс әкімінің орынбасары С. К. Сүлейменге жүктелсін.

4. Осы қаулы алғашқы ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

# Жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік тізімі


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`t001-r001`](kaz/t001-r001.md) | `!` таблица 1, строки 1–400 |
| [`t001-r002`](kaz/t001-r002.md) | `!` таблица 1, строки 401–765 |
| [`t001-r003`](kaz/t001-r003.md) | `!` таблица 1, строки 766–1134 |
| [`t001-r004`](kaz/t001-r004.md) | `!` таблица 1, строки 1135–1434 |
| [`t001-r005`](kaz/t001-r005.md) | `!` таблица 1, строки 1435–1763 |
| [`t001-r006`](kaz/t001-r006.md) | `!` таблица 1, строки 1764–2091 |
| [`t001-r007`](kaz/t001-r007.md) | таблица 1, строки 2092–2154 |
| [`part008`](kaz/part008.md) | part008 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
