# Аудан әкімдігі жанындағы «Діни бірлестіктерімен байланыс жөніндегі Кеңес құру туралы»

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы №148-11 санды "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңының 31 бабына сай аудан әкімдігі ҚАУЛЫ ЕТЕДІ:

1. Аудан әкімдігі жанындағы Діни бірлестіктермен байланыс жөніндегі Кеңес ұсынылып отырған құрамда құрылсын (жалғанды N 1 қосымша).

2. Аудан әкімдігі жанындағы Діни бірлестіктермен байланыс жөніндегі Кеңес құрамы аудандық мәслихат сессиясына бекітуге ұсынылсын.

3. Аудан әкімдігі жанындағы Діни бірлестіктермен байланыс жөніндегі Кеңес туралы Ереже бекітілсін (жалғанды N 2 қосымша).

4. Аудан әкімінің орынбасары А. Балғайшиевке осы қаулының орындалуын бақылау жасау жүктелсін.

## Аудан әкімдігі жанындағы Діни бірлестіктермен байланыс жөніндегі Кеңес құру туралы ЕРЕЖЕ

### 1. Жалпы ереже

1. Діни бірлестіктермен байланыс жөніндегі Кеңес (әрі қарай - Кеңес) аудан әкімдігі жанынан құрылған консультациялық-кеңесші орган болып саналады.

2. Кеңес өз жұмысында Қазақстан Республикасының Конституциясын және Қазақстан Республикасының заңдарын, осы Ережені басшылыққа алады.

3. Кеңес өз қызметінде діни, басқалай қоғамдық бірлестіктермен, аудандық, облыстық және республикалық органдармен тығыз байланыста жұмыс жасайды.

4. Кеңес отырысының қорытындысы ұсынба сипатта болады.

### 2. Кеңестің мақсаты

<a id="p5"></a>

5. Кеңестің мақсаты мемлекеттік саясатты, Қазақстан Республикасы азаматтарының құқығын, дінге сену бостандығын, қоғамдағы діни сенімді тұрақтандыруды үйлестіріп отырады.

### 3. Кеңестің міндеттері

<a id="p6"></a>

6. Аудандағы діни жағдайдың дамуына талдаулар жасап отыру.

<a id="p7"></a>

7. Ішкі саясат саласында азаматтар құқығын қамтамасыз етуді жүзеге асыру.

<a id="p8"></a>

8. Аудан әкімдігі және аудандық атқарушы органдарға аудандағы діни сенім жағдайлары туралы ақпараттар беріп отыруға тиіс.

<a id="p9"></a>

9. Аудандық Кеңес жұмыстарын діни бірлестіктермен үйлестіре жүргізеді.

<a id="p10"></a>

10. Кеңес өзіне жүктелген міндеттерді сәйкесті орныққан заңдар ретімен төмендегідей жүзеге асырады.

<a id="p11"></a>

11. Ақпараттық-насихат шараларын жүзеге асырады.

<a id="p12"></a>

12. Мемлекеттік саясат саласында кеңестер беріп, азаматтардың дінге сену құқықтық еркіндігін реттеу туралы мәселелерді жетілдіреді.

<a id="p13"></a>

13. Қазақстан Республикасы заңдарына сүйене отырып, басқалай қызметтер түрін жүргізеді.

### 4. Кеңес жұмысының тәртібі және қызметін ұйымдастыру

<a id="p14"></a>

14\. Кеңесті аудан әкімінің әлеуметтік мәселелер жөніндегі орынбасары басқарады.

<a id="p15"></a>

15\. Кеңес отырысы үш айда бір рет өткізіледі. Кеңестің кезектен тыс отырысы, Кеңес төрағасының жеке өзінің бастамасымен немесе барлық Кеңес мүшелерінің үштен бірінің өтініші бойынша шақырылады.

<a id="p16"></a>

16\. Кеңес отырысына барлық Кеңес мүшесінің кемінде үштен екісі қатынасса заңды болып саналады. Кеңеске қатынасқандардың көпшілігі дауыс берсе, Кеңес шешімі заңды болып есептеледі. Егер дауыс тепе-тең болса, Кеңес төрағасы дауысы шешуші болып саналады.

<a id="p17"></a>

17\. Мәселелер отырыста қаралып, сарапталып, талдаулар жүргізілгеннен кейін Кеңес жұмысшы тобын құруы мүмкін, оған Кеңес мүшесінің біреуі басшылық жасайды.

18\. Кеңес өзіне тиісті мәселелерді іске асырады заңдылық тәртібіне сәйкесті жүргізуге құқылы.

18\. Мемлекеттік органдардан, діни ұйымдардан және жеке тұлғалардан Кеңес өз құзырына кіретін мәселелер жөніндегі керекті ақпаратты сұрай алады.

<a id="p19"></a>

19\. Кеңес өз құзырына қатысты мәселелерден түсініктер береді.

<a id="p20"></a>

20\. Кеңес өз құзырына қатысты мәселелерден түсініктер береді.

### 5. Кеңес қызметін қамтамасыз ету

<a id="p21"></a>

21. Кеңес төрағасы, оның орынбасары мен Кеңес мүшелері мәслихат сессиясының шешімімен бекітіледі.

<a id="p22"></a>

22. Төраға болмағанда, оның міндетін төрағаның орынбасары атқарады.

<a id="p23"></a>

23. Кеңес мүшелері өз міндеттерін қоғамдық негізде атқарады.

<a id="p24"></a>

24. Кеңестің хатшысы ұйымдастыру, Кеңестің басқалай қамту жұмыстарын жүзеге асырады:

    1) Кеңесте қаралатын мәселелер Кеңес төрағасына ұсынылады;

    2) Кеңес төрағасы:

    3) Кеңес отырысының күн тәртібін бекітеді:

    4) Кеңестің қызметі туралы есепті әзірлейді.

### 6. Кеңес жұмысын тоқтату тәртібі

<a id="p25"></a>

25. Кеңес өз жұмысын аудан әкімдігінің қаулысымен тоқтатады.
