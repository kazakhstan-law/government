# Об определении мест для размещения агитационных печатных материалов для всех кандидатов в депутаты Мажилиса Парламента и маслихатов Республики Казахстан

В соответствии с Конституционым Законом Республики Казахстан от 28 сентября 1995 года "О выборах в Республике Казахстан", Законом Республики Казахстан от 23 января 2001 года "О местном государственном управлении и самоуправлении в Республике Казахстан" акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить совместно с Сырымской районной избирательной комиссией (по согласованию), места для размещения агитационных печатных материалов для всех кандидатов в депутаты Мажилиса Парламента и маслихатов Республики Казахстан согласно приложению.

<a id="p2"></a>

2. Акимам сельских округов оснастить места для размещения агитационных печатных материалов стендами, щитами, тумбами.

<a id="p3"></a>

3. Контроль за исполнением данного постановления возложить на заместителя акима района Батырниязову Ж. Ж.

<a id="p4"></a>

4. Настоящее постановление вводится в действие со дня первого официального опубликования.
