# Карантин аймағын белгілеу туралы

Қазақстан Республикасының "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы", "Өсімдіктер карантині туралы" және "Нормативтік құқықтық актілер туралы" Заңдарын басшылыққа ала отырып, Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің Батыс Қазақстан облыстық аумақтық инспекциясының 2009 жылғы 30 сәуірдегі N 4-17-575 ұсынысын ескере отырып, облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Осы қаулының қосымшасына сәйкес Зеленов, Теректі, Тасқала, Бөрлі, Сырым, Шыңғырлау аудандарының ауылдық округтерінде және Орал қаласының кейбір аумақтарында карантиндік арамшөп ошақтарына карантин аймағы белгіленсін.

<a id="p2"></a>

2. Зеленов, Теректі, Тасқала, Бөрлі, Сырым, Шыңғырлау аудандары мен Орал қаласының әкімдері қолданыстағы заңнамаларға сәйкес:

   1) карантиндік шектеулер және карантинді обьектілерді оқшаулау мен жою жөніндегі шаралар тізбесі карантинді аймақтың жеке, заңды тұлғалары мен халқына хабарлансын;

   2) осы қаулыдан туындайтын қажетті шараларды алсын.

<a id="p3"></a>

3. Батыс Қазақстан облысы әкімдігінің "Зеленов, Теректі, Тасқала және Бөрлі аудандарының аумағында карантин аймағын белгілеу туралы" 2006 жылғы 28 ақпандағы N 90 (нормативтік құқықтық кесімдерді тіркеу тізілімінде N 2959 тіркелген, 2006 жылғы 28 наурыздағы облыстық "Орал өңірі" және "Приуралье" газеттерінде жарияланған), Батыс Қазақстан облысы әкімдігінің 2007 жылғы 11 мамырдағы N 104 "Облыс әкімдігінің "Зеленов, Теректі, Тасқала және Бөрлі аудандарының аумағында карантин аймағын белгілеу туралы" 2006 жылғы 28 ақпандағы N 90 қаулысына өзгерістер мен толықтырулар енгізу туралы" қаулысы (нормативтік құқықтық кесімдерді тіркеу тізілімінде N 2989 тіркелген, 2007 жылғы 29 мамырдағы облыстық "Орал өңірі" және "Приуралье" газеттерінің N 60 санында жарияланған) қаулыларының күші жойылды деп танылсын.

<a id="p4"></a>

4. Осы қаулының орындалуын бақылау облыс әкімінің орынбасары Е. Ғ. Салықовқа жүктелсін.

<a id="p5"></a>

5. Осы қаулы ресми жарияланған күнінен бастап қолданысқа енгізіледі.
