# Об установлении квоты рабочих мест для отдельных категорий граждан по городу Уральск

В соответствии с Законами Республики Казахстан от 23 января 2001 года "О местном государственном управлении и самоуправлении в Республике Казахстан", от 23 января 2001 года "О занятости населения", акимат города ПОСТАНОВЛЯЕТ:

1. Установить квоты рабочих мест для отдельных категорий граждан:

   1) для лиц, освобожденных из мест лишения свободы;

   2) для несовершеннолетних выпускников интернатных организаций.

2. Настоящее постановление вводится в действие по истечении десяти календарных дней со дня его первого официального опубликования.

3. Контроль за исполнением настоящего постановления возложить на заместителя акима города Сафималиева А. С.
