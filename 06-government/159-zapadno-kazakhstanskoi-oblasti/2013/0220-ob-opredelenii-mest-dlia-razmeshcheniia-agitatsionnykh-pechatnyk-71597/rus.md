# Об определении мест для размещения агитационных печатных материалов для всех кандидатов в депутаты Жанибекского районного маслихата по Школьному избирательному округу № 4 вместо выбывшего депутата

Руководствуясь Конституционным Законом Республики Казахстан от 28 сентября 1995 года "О выборах в Республике Казахстан", Законом Республики Казахстан от 23 января 2001 года "О местном государственном управлении и самоуправлении в Республике Казахстан", акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить совместно с районной (территориальной) избирательной комиссией (по согласованию) места для размещения агитационных печатных материалов для всех кандидатов в депутаты Жанибекского районного маслихата по Школьному избирательному округу № 4 вместо выбывшего депутата, согласно приложению.

<a id="p2"></a>

2. Акиму Жанибекского аульного округа оснастить места для размещения агитационных печатных материалов щитами.

<a id="p3"></a>

3. Контроль за выполнением настоящего постановления возложить на руководителя аппарата акима района Абдолова Ж. К.

<a id="p4"></a>

4. Настоящее постановление вводится в действие со дня первого официального опубликования.
