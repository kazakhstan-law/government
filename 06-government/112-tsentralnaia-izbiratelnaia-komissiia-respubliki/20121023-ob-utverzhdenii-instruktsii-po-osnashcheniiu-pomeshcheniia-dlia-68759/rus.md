# Об утверждении Инструкции по оснащению помещения для голосования на избирательном участке, пункта для голосования

В соответствии с подпунктом 1) статьи 12 Конституционного закона Республики Казахстан «О выборах в Республике Казахстан» Центральная избирательная комиссия Республики Казахстан ПОСТАНОВЛЯЕТ:

1\. Утвердить прилагаемую Инструкцию по оснащению помещения для голосования на избирательном участке, пункта для голосования.

2\. Юридическому отделу аппарата Центральной избирательной комиссии Республики Казахстан обеспечить государственную регистрацию настоящего постановления в Министерстве юстиции Республики Казахстан.

3\. Настоящее постановление вводится в действие со дня его официального опубликования.

Председатель К. Турганкулов

Секретарь Б. Мельдешов

## Инструкция по оснащению помещения для голосования на избирательном участке, пункта для голосования

1\. Настоящая Инструкция по оснащению помещения для голосования на избирательном участке, пункта для голосования разработана в соответствии со статьей 12 Конституционного закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан», и детализирует оснащение помещений для голосования на избирательном участке, пункта для голосования.

2\. В здании, где размещается участковая (территориальная) избирательная комиссия (далее — избирательная комиссия), вывешиваются указатели местонахождения избирательного участка, пункта для голосования, с указанием номера и графика работы комиссии.

Если в одном здании размещены несколько избирательных участков, вывешиваются вывески с указанием номеров всех избирательных участков.

3\. В помещении (пункте) для голосования в специально отведенном видном месте размещается Государственный Герб Республики Казахстан, с левой стороны от него устанавливается (размещается) Государственный Флаг Республики Казахстан.

4\. В помещении (пункте) для голосования устанавливаются:

1) письменные столы для членов избирательной комиссии, для подсчета результатов голосования, наблюдателей;

2) стулья;

3) телефонный аппарат;

4) настольная лампа, часы;

5) сейф или металлический шкаф;

6) калькулятор;

7) копировальный аппарат;

8) оборудованные кабины для тайного голосования, с наличием в них стола или подставки, ручек;

9) стенды:

   с указанием состава избирательной комиссии, адресов и номеров телефонов вышестоящих избирательных комиссий, судов и органов прокуратуры;

   с образцами заполненных бюллетеней и информационные материалы обо всех политических партиях, выдвинувших партийные списки, кандидатах, баллотирующихся по избирательному округу, в едином формате и стандартным набором сведений;

   с правилами поведения в помещении, установленными избирательной комиссией;

   на котором вывешивается копия протокола избирательной комиссии об итогах подсчета голосов.

5\. В помещении (пункте) для голосования оборудуются в достаточном количестве кабины для тайного голосования, определяются места выдачи избирательных бюллетеней и устанавливается стационарная урна для голосования таким образом, чтобы голосующие при подходе к ней проходили через кабины для тайного голосовании, а также, чтобы члены избирательной комиссии, присутствующие представители средств массовой информации, наблюдатели и доверенные лица могли видеть, как опускаются бюллетени для голосования в урну.

В помещении (пункте) для голосования столы, за которыми производится подсчет голосов, размещаются таким образом, чтобы обеспечивался полный обзор действий членов избирательной комиссии со стороны всех присутствующих при подсчете.

6\. На столах членов избирательных комиссий устанавливаются указатели, кувертки с надписью: «Председатель участковой (территориальной) избирательной комиссии», «Заместитель председателя участковой (территориальной) избирательной комиссии», «Секретарь участковой (территориальной) избирательной комиссии», а также с буквами алфавита или наименованиями улиц и номерами домов.

7\. В помещениях устанавливаются одна стационарная и две переносные избирательные урны для голосования, соответствующие следующим формам:

1) стационарная (предназначена для голосования в помещении (пункте)) - представляет собой ящик из прозрачного материала (оргстекло) - толщиной не менее 0,5 см, высотой 90 см, шириной 50x50 см; каркас: алюминиевый профиль (цвет серебро), уголок соединительный пластиковый (цвет серый), на лицевой части размещается изображение Государственного Герба Республики Казахстан диаметром - 23 см, верхняя крышка выдвижная, с прорезью для опускания бюллетеней для голосования (по центру) - длиной 15 см, шириной 0,5 см, ящик и крышка имеют металлические ушки для опечатывания или опломбирования;

2) переносная (предназначена для голосования вне помещения) - представляет собой ящик из прозрачного материала (оргстекло) - толщиной не менее 0,5 см, высотой 40 см, шириной 30x30 см; каркас: алюминиевый профиль (цвет серебро), уголок соединительный пластиковый (цвет серый), на лицевой части размещается изображение Государственного Герба Республики Казахстан диаметром - 23 см, верхняя крышка выдвижная, с прорезью для опускания бюллетеней для голосования (по центру) - длиной 15 см, шириной 0,5 см, ящик и крышка имеют металлические ушки для опечатывания или опломбирования, ручку для переноса.

8\. В помещении (пункте) для голосования также имеются:

1) печать избирательной комиссии;

2) приспособления для опечатывания или опломбирования урн для

   голосования, избирательной документации;

3) канцелярские принадлежности (пакеты, конверты, мешки, канцелярский клей, ножницы, упаковочную бумагу, писчую бумагу, линейки, ручки с черной либо синей пастой, шпагат, дырокол, степлер, антистеплер, скобы для степлера и иные принадлежности);

4) журнал регистрации входящей и исходящей корреспонденции, журнал регистрации наблюдателей и представителей средств массовой информации.

9\. В помещениях (пунктах) для голосования, обеспечивается хранение избирательной документации, оборудования и иных материалов.
