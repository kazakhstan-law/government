# Қарасу ауданында 2009 жылға арналған халықтың нысаналы топтарының тізбесін бекіту туралы

"Қазақстан Республикасындағы жергiлiктi мемлекеттiк басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 31-бабының 1-тармағының 13) тармақшасына, "Халықты жұмыспен қамту туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 5-бабына, 7-бабының 2) тармақшасына сәйкес Қарасу ауданының әкімдігі ҚАУЛЫ ЕТЕДI:

1. 2009 жылға арналған халықтың нысаналы топтарының тiзбесi қосымшаға сәйкес бекiтiлсiн.

2. "Қарасу ауданының жұмыспен қамту және әлеуметтік бағдарламалар бөлімі" мемлекеттік мекемесі халықтың нысаналы топтарын жұмыспен қамтуды жәрдемдесу жөнiндегі шараларды қамтамасыз етсiн.

3. Осы қаулы оны алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Қарасу ауданы әкімінің міндетін атқарушысы**

**Н. Әбдірахманов**

> *КЕЛІСІЛДІ*

> *Әкімдіктің*  
> *2009 жылғы 27 шілдедегі*  
> *№ 163 қаулысына қосымша*

# 2009 жылға арналған халықтың нысаналы топтарының ТІЗБЕСІ

> *Ескерту. Қосымша жаңа редақцияда - Қостанай облысы Қарасу ауданы әкімдігінің 2009.07.27 № 163 (қолданысқа енгізілу тәртібін 2-тармақтан қараңыз) қаулысымен.*

1. Табысы аз адамдар;

2. Жиырма бip жасқа дейінгі жастар;

3. Балалар үйлерінің тәрбиеленушілері, жетім балалар мен ата-ананың қамқорлығынсыз қалған жиырма үш жасқа дейінгі балалар;

<a id="p4"></a>

4. Кәмелетке толмаған балаларды тәрбиелеп отырған жалғызілікті, көп балалы ата-аналар;

<a id="p5"></a>

5. Қазақстан Республикасының заңдарында белгіленген тәртіппен асырауында тұрақты күтімдi, көмекті немесе қадағалауды қажет етеді деп танылған адамдар бар азаматтар;

<a id="p6"></a>

6. Зейнеткерлік жас алдындағы адамдар (жасына байланысты зейнеткерлікке шығуға екі жыл қалғанда);

<a id="p7"></a>

7. Мүгедектер;

<a id="p8"></a>

8. Қазақстан Республикасының Қарулы Күштері қатарынан босаған адамдар;

<a id="p9"></a>

9. Бас бостандығынан айыру және мәжбүрлеп емдеу орындарынан босатылған адамдар;

<a id="p10"></a>

10. Оралмандар;

<a id="p11"></a>

11. Бастауыш, орта және жоғары кәсіби білім оқу орындарының түлектері;

<a id="p12"></a>

12. Жұмыс берушінің-заңды тұлғаның жойылуына не жұмыс беруші-заңды тұлға қызметінің тоқталуына, қызметкерлер санының немесе штатының қысқартуына байланысты босатылған адамдар;

<a id="p13"></a>

13. Бес жасқа дейінгі баласы бар ана;

<a id="p14"></a>

14. Елу жастан үлкен адамдар;

<a id="p15"></a>

15. Уәкілетті органының бағдары бойынша кәсіптік оқуды аяқтаған жұмыссыздар;

<a id="p16"></a>

16. Ұзақ уақыт жұмыс істемейтін адамдар (он екі және одан астам ай);

<a id="p17"></a>

17. Жиырма бір жастан жиырма тоғыз жасқа дейінгі жастағы жастар;

<a id="p18"></a>

18. Алған мамандығы бойынша жұмыс тәжірибесі және өтілі жоқ жұмыссыз жастар.
