# Об утверждении перечня объектов коммунальной собственности по Костанайской области, подлежащих приватизации

<a id="p1"></a>

1. Утвердить прилагаемый перечень объектов коммунальной собственности по Костанайской области, подлежащих приватизации.

<a id="p2"></a>
