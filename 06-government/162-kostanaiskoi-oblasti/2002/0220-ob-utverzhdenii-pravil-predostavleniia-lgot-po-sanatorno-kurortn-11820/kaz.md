# Мүгедектердің жекелеген санаттарын санаторлық-курорттық емдеу үшін облыстық бюджеттің қаражаты есебінен жеңілдіктер беру ережесін бекіту туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Z010148_ "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңының 27-бабына, Қазақстан Республикасының 1991 жылғы 21 маусымдағы N 1900 "Қазақстан Республикасында мүгедектерді әлеуметтік қорғау туралы" Заңының 44-бабына және Қазақстан Республикасы Үкiметiнiң 2001 жылғы 29 желтоқсандағы N 1758 Z011758_ "2002-2005 жылдарға арналған мүгедектердi сауықтыру бағдарламасы туралы" қаулысына сәйкес облыс бюджетiнiң орындалуын қамтамасыз ету мақсатында Қостанай облысының әкiмияты

ҚАУЛЫ ЕТЕДI:

1. Қоса берiлiп отырған мүгедектердiң жекелеген санаттарын санаторлық-курорттық емдеу үшiн облыстық бюджеттiң қаражаты есебiнен жеңiлдiктер беру ережесi бекiтiлсiн.

2. Қаулының орындалуына бақылау жасау Қостанай облысы әкiмiнiң орынбасары С.Ә. Құлмағанбетовке жүктелсiн.

Облыс әкiмi

```
Қазақстан Республикасы
Қостанай облысы әкiмиятының
2002 жылғы 20 ақпандағы
N 47 қаулысымен бекiтiлген
```

Мүгедектердiң жекелеген санаттарын

санаторлық-курорттық емдеу үшiн облыстық бюджеттiң

қаражаты есебiнен жеңiлдiктер беру Ережесi

Осы Ереже "Санаторлық-курорттық емдеу жеңiлдiктерi" жөнiндегi бюджеттiк бағдарлама бойынша мүгедектердiң жекелеген санаттарын санаторлық-курорттық емдеу үшiн облыстық бюджеттiң қаражаты есебiнен жеңiлдiктер беру тәртiбiн реттейдi.

<a id="pi"></a>

I. Жалпы ережелер

1. Ереженiң 2-тармағында көрсетiлген мүгедектердiң жекелеген санаттарына емдеу жөнiндегi жеңiлдiктер, оларды әлеуметтiк қолдауға, сауықтыруға және бейiмдеуге бағытталған санаторлық-курорттық емдеудi қамтамасыз ету түрiнде берiледi.

2. Санаторлық-курорттық жолдамаларды тегiн алуға мүгедектердiң (әрi қарай-мүгедектер) төмендегi санаттары құқылы:

   1) Ұлы Отан соғысының мүгедектерi;

   2) тиiстi жылға республикалық бюджет туралы заң белгiлеген ең төменгi мөлшердегi зейнетақы алатын 2, 3 топтағы мүгедек зейнеткерлер;

   3) кәмелетке толмаған балалары бар 1,2,3 топтағы мүгедек әйелдер (қорғаншы болып табылатын әйелдер, аналар (қамқоршылар, баланы(қызды) асырап алушылар);

   4) 1 топтағы мүгедектер.

<a id="p3"></a>

3. Мүгедектердiң санаторлық-курорттық емдеу құжаттарын ресiмдеудi және есеп жүргiзудi арыз берушiнiң тұрғылықты жерi бойынша аудандық, қалалық еңбек, жұмыспен қамту және халықты әлеуметтiк қорғау басқармалары (әрi қарай-уәкiлеттi орган) жүргiзедi.

<a id="pii"></a>

II. Қажеттi құжаттар тiзбесi

<a id="p4"></a>

4\. Тегiн санаторлық-курорттық емдеуге құқығы бар адам уақытын

```
көрсетiп, уәкiлеттi органға арыз бередi.
Арызға төмендегi құжаттар тiркеледi:
1) мүгедектiң санаторлық-курорттық емге мұқтаждығы туралы жергiлiктi
жердегi емдеу мекемесiнiң қорытындысы.
Санаторлық-курорттық емдеудiң қажеттiлiгi туралы емдеу мекемесiнiң
қорытындысы тиiстi бланкiде ресiмделедi, оған тиiстi уәкiлеттi адам қол
қойып, мөрмен растайды.
Қорытындыда мiндеттi түрде берiлген уақыты көрсетiледi.
2) арыз берушiнiң жеке куәлiгiнiң көшiрмесi;
3) 1, 2, 3 топтағы мүгедектер үшiн медициналық-әлеуметтiк сараптау
комиссиясының мүгедектiктi белгiлеу туралы анықтамасының көшiрмесi;
4) Ұлы Отан соғысының мүгедектерi үшiн:
арыз берушiнiң көрсетiлген әлеуметтiк дәрежесiн растайтын куәлiктiң
көшiрмесi.
5. Бұдан басқа, арыз берушiлер төмендегi құжаттарды тапсырады:
1) мүгедектердiң Ереженiң 2-тармағының 2)-тармақшасында көрсетiлген
санаттары үшiн:
зейнетақы мөлшерi туралы анықтама;
2) мүгедек әйелдердiң Ереженiң 2-тармағының 3)-тармақшасында
көрсетiлген санаттары үшiн:
баланың туу туралы куәлiгiнiң көшiрмесiн;
баланы (қызды) асырап алушылар баланы (қызды) асырап алғандары туралы
сот шешiмiнiң көшiрмесiн ұсынады;
```

қорғаншылар (қамқоршылар) қорғаншы (қамқоршы) куәлiгiнiң көшiрмесiн немесе қорғаншы және қамқоршы тағайындау органдарының балаға қорғаншы (қамқоршы) етiп тағайындау туралы шешiмiн ұсынады.

<a id="p6"></a>

6\. Уәкiлеттi органға ақысыз санаторлық-курорттық емделудi қамтамасыз етуге қажет құжаттардың салыстыру үшiн түпнұсқасы және көшiрмесi тапсырылады. Салыстырғаннан кейiн арыз берушiге құжаттардың түпнұсқасы қайтарылады. Уәкiлеттi органның қызметкерлерi құжаттардың көшiрмелерiн растайды және iстi ресiмдейдi.

<a id="p7"></a>

7\. Жоғарыда көрсетiлген құжаттардың бiрi болмаса, ақысыз санаторлық-курорттық емделу мүмкiндiгi берiлмейдi.

<a id="p8"></a>

8\. Арыз берушi арызда және құжаттарда көрсетiлген мәлiметтiң толықтығына, растығына заңдылықтарға сәйкес жауапты болады.

<a id="p9"></a>

9\. Уәкiлеттi орган мүгедектердiң санаторлық-курорттық емделуi үшiн ақысыз жолдамаларды берiлген арызға сәйкес кезек тәртiбiмен (тiркеу) бередi.

<a id="p10"></a>

10\. Санаторлық-курорттық емделуге ақысыз жолдама беруден бас тартқан жағдайда, уәкiлеттi орган арыз бергеннен кейiн 10 күн iшiнде арыз берушiге бас тартудың дәлелiн келтiрiп, жауап беруге мiндеттi.

<a id="p11"></a>

11\. Уәкiлеттi орган мүгедекке емделу үшiн санаторлық-курорттық жолдама бермеген жағдайда, ақшалай өтемақы төленбейдi.

<a id="p12"></a>

12\. Санаторлық-курорттық емделу жолдамасы календарлық жыл iшiнде бiр рет берiледi.

<a id="piii"></a>

III. Санаторлық-курорттық емделуге

жолдама алу және беру тәртiбi

<a id="p13"></a>

13. Санаторлық-курорттық емделуге жолдамаларды облыстық еңбек, жұмыспен қамту және халықты әлеуметтiк қорғау басқармасы облыстық бюджет есебiнен мемлекеттiк сатып алулар туралы заңдылықтарға сәйкес алады.

<a id="p14"></a>

14. Уәкiлеттi орган ақысыз санаторлық-курорттық жолдама алуға құқылы мүгедектердiң тiзiмiн ресiмдейдi және ай сайын облыстық еңбек, жұмыспен қамту және халықты әлеуметтiк қорғау басқармасына бередi.

<a id="p15"></a>

15. Облыстық еңбек, жұмыспен қамту және халықты әлеуметтiк қорғау

```
басқармасы аудандық, қалалық еңбек, жұмыспен қамту және халықты әлеуметтiк
қорғау басқармалары берген тiзiмдерге сәйкес санаторлық-курорттық емдеу
жолдамаларын белгiленген мақсат бойынша пайдалану үшiн аудандық, қалалық
еңбек, жұмыспен қамту және халықты әлеуметтiк қорғау басқармаларына бөлiп
бередi.
16. Берiлген жолдамада уәкiлеттi орган мүгедектiң тегiн, атын,
әкесiнiң атын көрсетуге тиiс.
17. Санаторлық-курорттық емделуге берiлетiн жолдамаға уәкiлеттi
органның бастығы, немесе оның орынбасары қол қояды және мөрмен растайды.
___________________
(Маман Л.В. Ещенко)
```
