# Об оказании социальной помощи молодежи из числа студентов для частичного возмещения расходов, связанных с получением образования

> *Сноска. Утратило силу постановлением акимата города Лисаковска Костанайской области от 08.12.2007 № 2539.*

В соответствии со статьей 31 Закона Республики Казахстан «О местном государственном управлении в Республике Казахстан», пунктом 5 статьи 4 Закона Республики Казахстан «Об образовании», во исполнение городской комплексной Программы «Молодежь Лисаковска» на 2006 - 2008 годы», утвержденной решением сессии Лисаковского городского маслихата от 22 февраля 2006 года № 234, акимат города Лисаковска ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Оказать социальную помощь молодежи из числа студентов для частичного возмещения расходов, связанных с получением образования. Оплата стоимости курса обучения:

   для пяти студентов дневной формы обучения высших учебных заведений по педагогическим специальностям, набравших на Едином национальном тестировании не менее 50 баллов, начиная с первого курса обучения, а также продолжающих обучение;

   для пяти студентов дневной формы обучения высших учебных заведений по медицинским специальностям, набравших на Едином национальном тестировании не менее 70 баллов, начиная с первого курса обучения, а также продолжающих обучение.

<a id="p2"></a>

2. Заявитель имеет право использовать полученные средства только для оплаты курса обучения путем безналичного перечисления средств на счет высшего учебного заведения, в котором обучается.

<a id="p3"></a>

3. Совету по делам молодежи при акиме города Лисаковска рассматривать заявления и определять кандидатов на получение социальной помощи.

<a id="p4"></a>

4. Государственному учреждению «Отдел внутренней политики города Лисаковска» (Ляшенко Л.С.):

   обеспечить выполнение мероприятий городской комплексной Программы «Молодежь Лисаковска» на 2006 - 2008 годы в части оказания социальной помощи молодежи для частичного возмещения расходов, связанных с получением образования;

   заключить договоры с получателями социальной помощи, предусматривающие отработку в учреждениях здравоохранения и образования города Лисаковска в течение пяти лет после окончания высших учебных заведений средств, затраченных из городского бюджета на их обучение.

<a id="p5"></a>

5. Социальная помощь молодежи из числа студентов для частичного возмещения расходов, связанных с получением образования, выплачивается два раза в год по 50%: в сентябре - первая выплата, феврале - остаток от общей стоимости курса обучения.

<a id="p6"></a>

6. Выплата социальной помощи осуществляется через банки второго уровня путем зачисления денежных средств на лицевые счета заявителей.

<a id="p7"></a>

7. Источник финансирования - городской бюджет.

<a id="p8"></a>

8. Отменить постановление акимата города Лисаковска от 29 августа 2006 года № 793 «Об оказании социальной помощи молодежи из числа студентов в для частичного возмещения расходов, связанных с получением образования.

<a id="p9"></a>

9. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня первого официального опубликования.

<a id="p10"></a>

10. Контроль за исполнением настоящего постановления возложить на заместителя акима города Лисаковска Сенчева А.П.

**Аким города Лисаковска**

**В. Полешко**
