# 2008 жылғы көктемгі су тасқыны кезеңіндегі төтенше жағдайлардың алдын алу жөніндегі шаралар туралы

«Табиғи және техногендік сипаттағы төтенше жағдайлар туралы» Қазақстан Республикасының 1996 жылғы 5 шілдедегі Заңының 13-бабына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы» Қазақстан Республикасы Заңының 31-бабына сәйкес және көктемгі су тасқыны кезеңінде төтенше жағдайларды алдын алу, ауданның экономикасы мен инфрақұрылымының тұрақты жұмыс істеуін қамтамасыз ету мақсатында Сарыкөл ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Су тасқынына қарсы іс - шараларды жүзеге асыруына бақылау жасау жөніндегі комиссия құрылсын (қосымша).

<a id="p2"></a>

2. Ауданда су тасқынына қарсы іс - шаралар жоспары бекітілсін.

<a id="p3"></a>

3. Кәсіпорындар, ұйымдар басшылары және ауылдық округтердің әкімдері су тасқыны өту кезеңіне авариялық бригадалардың тәулік бойы кезекшілігін белгілесін, оларды қажетті тетіктермен және материалдармен қамтамасыз етуі ұсынылсын.

<a id="p4"></a>

4. «Көктемгі су тасқыны кезеңіндегі төтенше жағдайлардың алдын-алу жөніндегі шаралар туралы» Сарыкөл ауданы әкімдігінің 2005 жылғы 24 наурыздағы № 85 қаулысының күші жойылсын.

<a id="p5"></a>

5. Берілген қаулының орындалуына бақылау жасау аудан әкімінің орынбасары А.Р. Жалғасовқа жүктелсін.

<a id="p6"></a>

6. Осы қаулы алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Су тасқынына қарсы іс - шараларды жүзеге асыруына бақылау жасау жөніндегі комиссияның құрамы

```
Асылхан Рақымбайұлы Жалғасов - аудан әкімінің орынбасары, комиссия төрағасы
Серік Ғабдоллаұлы Ғайсенов   - «Сарыкөл ауданының тұрғын үй-коммуналдық шаруашылығы,
                               жолаушылар көлігі және автомобиль жолдары бөлімі»
                               мемлекеттік мекемесінің бастығы, комиссия төрағасының
                               орынбасары
Марат Бергенұлы Байгентов    - «Сарыкөл ауданы әкімінің аппараты» мемлекеттік мекемесінің
                               азаматтық қорғаныс және төтенше жағдайлар жөніндегі бас
                               маманы, комиссия хатшысы
```
