# Об установлении квоты рабочих мест для инвалидов

В соответствии с подпунктом 5-2) статьи 7 Закона Республики Казахстан от 23 января 2001 года "О занятости населения", акимат Костанайского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Установить квоту рабочих мест для инвалидов в размере трех процентов от общей численности рабочих мест Костанайского района.

<a id="p2"></a>

2. Государственному учреждению "Отдел занятости и социальных программ" акимата Костанайского района принять меры по содействию в трудоустройстве инвалидов в соответствии с квотой.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на заместителя акима Костанайского района С. Кульбекова.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Аким района**
