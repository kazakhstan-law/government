# Азаматтық қызметшілер болып табылатын және ауылдық жерде жұмыс істейтін денсаулық сақтау, әлеуметтік қамсыздандыру, білім беру, мәдениет, спорт және ветеринария саласындағы мамандар лауазымдарының тізбесін айқындау туралы

2015 жылғы 23 қарашадағы Қазақстан Республикасы Еңбек Кодексі 18-бабының 2) тармақшасына, 139-бабының 9-тармағына сәйкес Арқалық қаласының әкімдігі ҚАУЛЫ ЕТТІ:

1. Осы қаулының қосымшасына сәйкес азаматтық қызметшілер болып табылатын және ауылдық жерде жұмыс істейтін денсаулық сақтау, әлеуметтік қамсыздандыру, білім беру, мәдениет, спорт және ветеринария саласындағы мамандар лауазымдарының тізбесі айқындалсын.

2. Арқалық қаласы әкімдігінің 2016 жылғы 4 сәуірдегі № 112 «Азаматтық қызметшілер болып табылатын және ауылдық жерде жұмыс істейтін және лауазымдық айлықақылар мен тарифтік мөлшерлемелерін жиырма бес пайызға жоғарылатуға құқығы бар әлеуметтік қамсыздандыру, білім беру, мәдениет, спорт және ветеринария саласындағы мамандар лауазымдарының тізбесін айқындау туралы» қаулысының (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 6307 болып тіркелген, 2018 жылғы 31 мамырда Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкінде жарияланған) күші жойылды деп танылсын.

3. «Арқалық қаласы әкімдігінің экономика және бюджеттік жоспарлау бөлімі» мемлекеттік мекемесі Қазақстан Республикасының заңнамасында белгіленген тәртіппен:

   1) осы қаулының аумақтық әділет органында мемлекеттік тіркелуін;

   2) осы қаулы мемлекеттік тіркелген күнінен бастап күнтізбелік он күн ішінде оның қазақ және орыс тіліндеріндегі қағаз және электрондық түрдегі көшірмесін «Республиқалық құқықтық ақпарат орталығы» шаруашылық жүргізу құқығындағы республиқалық мемлекеттік кәсіпорнына ресми жариялау және Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкіне енгізу үшін жіберілуін;

   3) осы қаулыны ресми жарияланғаннан кейін Арқалық қаласы әкімдігінің интернет-ресурсында орналастыруын қамтамасыз етсін.

4. Осы қаулының орындалуын бақылау Арқалық қаласы әкімінің жетекшілік ететін орынбасарына жүктелсін.

5. Осы қаулы алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Азаматтық қызметшілер болып табылатын және ауылдық жерде жұмыс істейтін денсаулық сақтау, әлеуметтік қамсыздандыру, білім беру, мәдениет, спорт және ветеринария саласындағы мамандар лауазымдарының тізбесі

Денсаулық сақтау мамандарының лауазымдары:

1. барлық мамандықтағы дәрігерлер;

2. акушер;

3. мейіргер;

4. зертханашы (медициналық);

5. фельдшер;

<a id="p6"></a>

6. медициналық тіркеуші.

Әлеуметтік қамсыздандыру мамандарының лауазымдары:

<a id="p7"></a>

7. қарттар мен мүгедектерге күтім жасау жөніндегі әлеуметтік қызметкер;

<a id="p8"></a>

8. психоневрологиялық аурулары бар жасы 18-ден асқан мүгедек балаларға және мүгедектерге күтім жасау жөніндегі әлеуметтік қызметкер;

<a id="p9"></a>

9. әлеуметтік жұмыс жөніндегі консультант;

<a id="p10"></a>

10. әлеуметтік жұмыс жөніндегі маман.

Білім беру мамандарының лауазымдары:

<a id="p11"></a>

11. директор;

<a id="p12"></a>

12. директордың оқу ісі жөніндегі орынбасары;

<a id="p13"></a>

13. директордың тәрбие ісі жөніндегі орынбасары;

<a id="p14"></a>

14. директордың бейіндік оқыту бойынша орынбасары;

<a id="p15"></a>

15. мектепке дейінгі тәрбие мен оқытудың меңгерушісі;

<a id="p16"></a>

16. әдіскер (негізгі қызметтердің);

<a id="p17"></a>

17. дене тәрбиесі нұсқаушысы (негізгі қызметтердің);

<a id="p18"></a>

18. мектепке дейінгі, бастауыш, негізгі орта, жалпы орта білім беру ұйымдарының барлық мамандық мұғалімдері;

<a id="p19"></a>

19. педагог-психолог;

<a id="p20"></a>

20. қосымша білім беретін педагог;

<a id="p21"></a>

21. әлеуметтік педагог;

<a id="p22"></a>

22. бастапқы әскери даярлықты ұйымдастырушы оқытушы;

<a id="p23"></a>

23. кітапхана басшысы (меңгерушісі);

<a id="p24"></a>

24. кітапханашы;

<a id="p25"></a>

25. тәлімгер;

<a id="p26"></a>

26. тәрбиелеуші;

<a id="p27"></a>

27. логопед;

<a id="p28"></a>

28. музыкалық жетекші (негізгі қызметтердің);

<a id="p29"></a>

29. зертханашы;

<a id="p30"></a>

30. барлық мамандықты дәрігерлер;

<a id="p31"></a>

31. мейірбике (мейіргер);

<a id="p32"></a>

32. емдәмдік мейірбике.

Мәдениет мамандарының лауазымдары:

<a id="p33"></a>

33. аудандық маңызы бар мемлекеттік мекемесінің және мемлекеттік қазыналық кәсіпорынының (облыстық маңызы бар қалалар) басшысы;

<a id="p34"></a>

34. библиограф;

<a id="p35"></a>

35. кітапханашы;

<a id="p36"></a>

36. хореограф;

<a id="p37"></a>

37. барлық атаудағы әдістемеші (негізгі қызметтер);

<a id="p38"></a>

38. мәдени ұйымдастырушы (негізгі қызметтер);

<a id="p39"></a>

39. музыкалық жетекші;

<a id="p40"></a>

40. аудандық маңызы бар мемлекеттік мекемесінің және мемлекеттік қазыналық кәсіпорынының (облыстық маңызы бар қалалар) көркемдік жетекшісі.

Спорт мамандарының лауазымдары:

<a id="p41"></a>

41. әдіскер.

Ветеринария мамандарының лауазымдары:

<a id="p42"></a>

42. ветеринариялық дәрігер;

<a id="p43"></a>

43. ветеринариялық фельдшер.
