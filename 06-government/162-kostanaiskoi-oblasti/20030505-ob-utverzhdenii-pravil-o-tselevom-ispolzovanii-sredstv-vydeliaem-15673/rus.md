# Об утверждении Правил о целевом использовании средств, выделяемых из местного бюджета для оралманов на 2003 год

Во исполнение Закона Республики Казахстан «О миграции населения» и на основании статьи 31 Закона Республики Казахстан «О местном государственном управлении в Республике Казахстан», постановления Правительства Республики Казахстан от 18 августа 1999 года № 1194 «Об утверждении Положения о целевом использовании средств, выделяемых из республиканского бюджета для оралманов» акимат Денисовского района постановляет:

1. Утвердить Правила о целевом использовании средств, выделяемых из местного бюджета для оралманов на 2003 год.

2. Контроль за исполнением настоящего постановления возложить на заместителя акима Денисовского района Омарову К.Ж.

**Аким Денисовского района**

**А. Нагайцев**

> *Приложение*  
> *к решению Денисовского районного маслихата от 6 мая 2003 года № 69*

## ПРАВИЛА о целевом использовании средств, выделяемых из местного бюджета для репатриантов (оралманов) на 2003 год по Денисовскому району

### 1. Общие положения

1. Настоящие Правила устанавливают порядок использования средств, выделяемых из местного бюджета для репатриантов (оралманов), направленных на финансирование переселенческих мероприятий и социальную защиту репатриантов (оралманов) в соответствии с Законом Республики Казахстан «О миграции населения» по бюджетной программе «Социальные выплаты отдельным категориям граждан по решению местных представительных органов».

### 2. Порядок назначения и выплаты единовременного пособия

2. Назначение единовременного пособия оралманам производится территориальными органами по вопросам миграции населения по месту жительства оралманов.

3. Для получения единовременного пособия необходимо предоставить следующие документы:

   1) заявление о назначении единовременного пособия;

   2) копию документа, удостоверяющего личность оралмана;

   3) копии свидетельств о рождении детей;

   4) справку, удостоверяющую статус оралмана.

4. Единовременные пособия оралманам назначаются:

   главе семьи - в размере пятнадцатикратного месячного расчетного показателя;

   каждому члену семьи - в размере десятикратного месячного расчетного показателя.

   Возмещение расходов на провоз личного имущества семьи оралманов производится по предъявлению документов об оказании транспортных услуг, но в сумму не более пятидесятикратного месячного расчетного показателя.

   Оплата проезда каждого оралмана производится по фактическим затратам при предъявлении проездных документов (кроме авиатранспорта), но в размере не более десятикратного месячного расчетного показателя.

   Размер месячного расчетного показателя исчисляется на момент назначения в соответствии с законодательством Республики Казахстан.

   Приобретение жилья для оралманов осуществляется в соответствии с законодательством Республики Казахстан о государственных закупках.

### 3. Выплата единовременного пособия

5. Выплата производится через Денисовский районный филиал Народного банка № 221400 согласно списков, предоставленных территориальными органами по вопросам миграции.

6. Выплата единовременных пособий оралманам осуществляется наличными деньгами в национальной валюте Республики Казахстан.
