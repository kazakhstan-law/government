# Амангелді ауданының аумағында үгіттік баспа материалдарын орналастыру үшін орындар белгілеу туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі "Қазақстан Республикасындағы сайлау туралы" Конституциялық заңының 28-бабының 6-тармағына, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін өзі басқару туралы" Заңының 31, 37-баптарына сәйкес Амангелді ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Амангелді ауданының аумағында аудандық сайлау комиссиясымен бірлесіп үгіттік баспа материалдарын орналастыру үшін орындар қосымшаға сәйкес белгіленсін.

<a id="p2"></a>

2. Амангелді ауданы әкімдігінің 2011 жылғы 21 ақпандағы № 37 "Аманкелді ауданының аумағында үгіттік баспа материалдарын орналастыру үшін орындарды белгілеу туралы" (Нормативтік құқықтық актілерді тіркеу тізіліміне № 9-6-122 болып тіркелген, 2011 жылғы 4 наурызда "Аманкелді арайы" аудандық газетінде жарияланған) қаулысының күші жойылды деп танылсын.

<a id="p3"></a>

3. Осы қаулының орындалуын бақылау аудан әкімі аппаратының басшысы Қ.У. Кеделбаевқа жүктелсін.

<a id="p4"></a>

4. Осы қаулы алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
