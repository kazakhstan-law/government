# 2014 жылға арналған халықтың нысаналы топтарын анықтау туралы

"Халықты жұмыспен қамту туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 5-бабының 2-тармағына, 7-бабының 2) тармақшасына сәйкес, Қостанай ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

1. Қосымшаға сәйкес 2014 жылға арналған Қостанай ауданының аумағында тұратын халықтың нысаналы топтары анықталсын.

2. Қостанай ауданы әкімдігінің "Жұмыспен қамту және әлеуметтік бағдарламалар бөлімі" мемлекеттік мекемесі, "Қостанай ауданы әкімдігінің жұмыспен қамту орталығы" коммуналдық мемлекеттік мекемесі халықтың нысаналы топтарына жататын адамдарды жұмысқа орналастыру бойынша шаралар қарастырсын.

3. Осы қаулы алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Аудан әкімі**

**А. Ахметжанов**

> *Әкімдіктің*  
> *2013 жылғы 18 желтоқсандағы*  
> *№ 1036 қаулысына қосымша*

## 2014 жылға арналған Қостанай ауданының аумағында тұратын халықтың нысаналы топтары

1. Табысы аз адамдар.

2. Жиырма бір жасқа дейінгі жастар.

3. Балалар үйлерінің тәрбиеленушілері, жетім балалар мен ата-ананың қамқорлығысыз қалған жиырма үш жасқа дейінгі балалар.

<a id="p4"></a>

4. Кәмелетке толмаған балаларды тәрбиелеп отырған жалғызілікті, көп балалы ата-аналар.

<a id="p5"></a>

5. Қазақстан Республикасының заңдарында белгіленген тәртіппен асырауында тұрақты күтімді, көмекті немесе қадағалуды қажет етеді деп танылған адамдары бар азаматтар.

<a id="p6"></a>

6. Зейнеткерлік жас алдындағы адамдар (жасына байланысты зейнеткерлікке шығуға екі жыл қалған).

<a id="p7"></a>

7. Мүгедектер.

<a id="p8"></a>

8. Қазақстан Республикасының Қарулы Күштері қатарынан босаған адамдар.

<a id="p9"></a>

9. Бас бостандығынан айыру және (немесе) мәжбүрлеп емдеу орындарынан босатылған адамдар.

<a id="p10"></a>

10. Оралмандар.

<a id="p11"></a>

11. Жоғары және жоғары оқу орнынан кейінгі білім беру ұйымдарын бітірушілер.

<a id="p12"></a>

12. Жұмыс беруші-заңды тұлғаның таратылуына не жұмыс беруші-жеке тұлғаның қызметін тоқтатуына, қызметкерлер санының немесе штатының қысқаруына байланысты жұмыстан босатылған адамдар.

<a id="p13"></a>

13. Қылмыстық–атқару инспекциясы пробация қызметінің есебінде тұрған адамдар.

<a id="p14"></a>

14. Ұзақ (он екі айдан аса) жұмыспен қамтылмаған адамдар.

<a id="p15"></a>

15. Жұмыспен қамту мәселелері жөніндегі уәкілетті органда жұмыссыз ретінде тіркелген елу бес жастан асқан адамдар.

<a id="p16"></a>

16. Алған мамандығы бойынша еңбек өтілі мен тәжірибесі жоқ, жиырма бір жастан жиырма тоғыз жас аралығындағы жұмыспен қамтылмаған жастар.

<a id="p17"></a>

17. Уәкілетті органның жолдамасы бойынша кәсіби оқуды аяқтаған жұмыссыз адамдар.
