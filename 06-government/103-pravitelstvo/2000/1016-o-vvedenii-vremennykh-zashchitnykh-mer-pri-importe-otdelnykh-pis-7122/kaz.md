# Жекелеген азық-түлік тауарлар импорты кезінде уақытша қорғау шараларын енгізу туралы

"Тауар импорты жағдайында iшкi рынокты қорғау шаралары туралы" Z980337_ Қазақстан Республикасының 1998 жылғы 28 желтоқсандағы Заңына сәйкес iшкi рынокта тең бәсекелестiк жағдайын жасау және отандық өндiрушiлердiң өтiнiшi бойынша жүзеге асырылатын анықтауды ескере отырып, отандық шаруашылық жүргiзушi субъектiлердi қолдау мақсатында Қазақстан Республикасының Үкiметi қаулы етеді:

<a id="p1"></a>

1. Қосымшаға сәйкес тауарлар импортына алты ай мерзiмге уақытша қорғау шаралары енгiзiлсiн.

<a id="p2"></a>

2. Қазақстан Республикасының Энергетика, индустрия және сауда министрлiгi жүргiзiлетiн анықтау рәсiмi аяқталғанға дейiн, заңнамада белгіленген тәртiппен, қосымшаға сәйкес тауарлар импортын лицензиялауды қамтамасыз етсiн.

<a id="p3"></a>

3. Қазақстан Республикасы Мемлекеттiк кiрiс министрлiгiнiң Кеден комитетi қосымшаға сәйкес мөлшерлерде тауарларды импорттау кезiнде қолданылып жүрген кедендiк баж ставкасынан тыс алынатын уақытша қорғау бажын депозитке енгiзсiн.

<a id="p4"></a>

4. Қазақстан Республикасы Энергетика, индустрия және сауда министрлiгiнiң Антидемпингтiк бақылау жөнiндегi комитетi Қазақстан Республикасының Сыртқы iстер министрлiгiмен бiрлесiп заңнамада белгiленген тәртiппен Беларусь Республикасы, Қазақстан Республикасы, Қырғыз Республикасы, Ресей Федерациясы және Тәжiкстан Республикасының
