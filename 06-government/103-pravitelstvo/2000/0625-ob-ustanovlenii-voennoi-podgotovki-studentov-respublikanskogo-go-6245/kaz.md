# "Тұрар Рысқұлов атындағы Қазақ мемлекеттік басқару академиясы" республикалық мемлекеттік қазыналық кәсіпорны студенттерінің әскери даярлығын белгілеу туралы

Қазақстан Республикасының Қарулы Күштері үшін "Тұрар Рысқұлов атындағы Қазақ мемлекеттік басқару академиясы" республикалық мемлекеттік қазыналық кәсіпорнының студенттері қатарынан запастағы офицерлер даярлау мақсатында Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. Қазақстан Республикасы Білім және ғылым министрлігінің "Тұрар Рысқұлов атындағы Қазақ мемлекеттік басқару академиясы" республикалық мемлекеттік қазыналық кәсіпорнында оқу орнының бюджеттен тыс кірістері есебінен әскери кафедра құру туралы ұсынысы қабылдансын.

<a id="p2"></a>

2. Қазақстан Республикасының Білім және ғылым министрлігі Қазақстан Республикасының Қорғаныс министрлігімен бірлесіп осы қаулыны іске асыру жөнінде заңнамада көзделген шараларды қабылдасын.

<a id="p3"></a>

3. "Жоғары оқу орындарының студенттерін (курсанттарын) запастағы офицерлер бағдарламасы бойынша әскери даярлау туралы, жоғары оқу орындары жанындағы әскери кафедралар туралы Ережелерді және запастағы офицерлер бағдарламасы бойынша студенттердің (курсанттардың) әскери даярлығы белгіленген жоғары оқу орындарының тізбесін бекіту туралы" Қазақстан Республикасы Министрлер Кабинетінің 1994 жылғы 3 қазандағы N 1094 P941094_ қаулысына (Қазақстан Республикасының ПҮКЖ-ы, 1994 ж., N 40, 439-құжат) мынадай толықтыру енгізілсін:

```
көрсетілген қаулымен бекітілген Запастағы офицерлер бағдарламасы
бойынша студенттердің (курсанттардың) әскери даярлығы белгіленген жоғары
оқу орындарының тізбесінде:
"Басқа оқу орындары" бөлімі мынадай мазмұндағы жолмен толықтырылсын:
"Тұрар Рысқұлов атындағы Қазақ мемлекеттік басқару академиясы"
республикалық мемлекеттік қазыналық кәсіпорны, Алматы қаласы".
4. Осы қаулы қол қойылған күнінен бастап күшіне енеді.
Қазақстан Республикасының
Премьер-Министрі
Оқығандар:
Қасымбеков Б.А.
Икебаева Ә.Ж.
```
