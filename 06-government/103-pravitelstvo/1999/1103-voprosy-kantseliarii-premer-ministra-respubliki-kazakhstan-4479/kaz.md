# Қазақстан Республикасының Премьер-Министрі Кеңсесінің мәселелері

Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. Қазақстан Республикасының Премьер-Министрі Кеңсесінің құрылымы қосымшаға сәйкес бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасының Премьер-Министрі Кеңсесінің Басшысына үш, оның ішінде бір бірінші орынбасары болуға рұқсат етілсін.

<a id="p3"></a>

3. Қазақстан Республикасы Үкіметінің 1999 жылғы 20 мамырдағы N 592
