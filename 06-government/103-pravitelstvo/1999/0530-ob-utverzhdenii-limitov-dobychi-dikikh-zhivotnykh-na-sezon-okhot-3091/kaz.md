# 1999 жылдың аңшылық маусымына арналған жабайы аңдарды аулаудың лимиттерін бекіту туралы

"Жануарлар дүниесін қорғаУ, өсімін молайту және пайдалану туралы" Қазақстан Республикасының Заңына сәйкес Қазақстан Республикасының Үкіметі қаулы етеді:

1. 1999 жылдың аңшылық маусымына арналған жабайы аңдарды аулаудың лимиттері 1-3 қосымшаға сәйкес бекітілсін.

2. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

```
Қазақстан Республикасының
Премьер-Министрі
```

```
Қазақстан Республикасы
Үкіметінің 1999 жылғы
31 мамырдағы
N 666 қаулысына
1-қосымша
```
