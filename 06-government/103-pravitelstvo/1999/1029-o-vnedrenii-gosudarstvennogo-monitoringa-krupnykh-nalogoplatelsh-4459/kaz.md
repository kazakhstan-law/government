# Ірі салық төлеушілердің мемлекеттік мониторингін енгізу туралы

"Салық және бюджетке төленетін басқа да міндетті төлемдер туралы" Қазақстан Республикасының 1995 жылғы 24 сәуірдегі N 2235 Z952235_ Заңына сәйкес Қазақстанның ірі кәсіпорындарының салық пен бюджетке төленетін басқа да міндетті төлемдерді дұрыс және уақытылы есептеу, бюджеттің кіріс бөлігінің орындалуы үшін мемлекеттік бақылауды одан әрі күшейту мақсатында Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. Қазақстан Республикасы Мемлекеттік кіріс министрлігінің деректер базасына ақпаратты жинау әдісімен ірі салық төлеушілердің электрондық мониторингінің жүйесі енгізілсін.

<a id="p2"></a>

2. Қоса беріліп отырған мемлекеттік мониторингке жататын ірі салық төлеушілердің тізбесі бекітілсін.

<a id="p3"></a>

3. Осы қаулының орындалуын бақылау Қазақстан Республикасының Мемлекеттік кіріс министрі З.Х.Кәкімжановқа жүктелсін.

<a id="p4"></a>

4. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

```
Қазақстан Республикасының
Премьер-Министрі
```

```
Қазақстан Республикасы
Үкіметінің 1999 жылғы 30 қазандағы
N 1631 қаулысымен
бекітілген
```
