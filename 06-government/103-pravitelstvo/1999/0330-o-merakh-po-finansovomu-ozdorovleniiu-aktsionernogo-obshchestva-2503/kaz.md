# "Қазаккумулятор" акционерлік қоғамын қаржылық сауықтыру жөніндегі шаралар туралы

"Қазаккумулятор" акционерлік қоғамын қаржылық-экономикалық сауықтыру, инвестицияларды, озық менеджмент пен технологияларды тарту мақсатында Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. Қазақстан Республикасы Қорғаныс министрлігінің Қорғаныс өнеркәсібі жөніндегі комитеті белгіленген тәртіппен "Қазаккумулятор" акционерлік қоғамы акцияларының мемлекеттік пакетін Қазақстан Республикасы Қаржы министрлігінің Мемлекеттік мүлік және жекешелендіру комитетіне берсін.

<a id="p2"></a>

2. Қазақстан Республикасы Қаржы министрлігінің Мемлекеттік мүлік және жекешелендіру комитеті белгіленген тәртіппен арнайы мақсаттағы өнімдерді шығару жөнінде мамандандыруды сақтауды ескере отырып, "Қазаккумулятор" акционерлік қоғамы акцияларының мемлекеттік пакетін сату жөнінде ашық тендер өткізсін.

<a id="p3"></a>

3. күші жойылды - ҚР Үкіметінің 1999.09.10. N 1363 қаулысымен.

<a id="p4"></a>

4. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Премьер-Министрі**
