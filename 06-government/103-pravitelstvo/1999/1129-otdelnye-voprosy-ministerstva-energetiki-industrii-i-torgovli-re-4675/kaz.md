# Қазақстан Республикасы Энергетика, индустрия және сауда министрлігінің жекелеген мәселелері

Қазақстан Республикасы Президентінің "Қазақстан Республикасы мемлекеттік органдарының құрылымын жетілдіру және олардың құзыретін нақтылау жөніндегі шаралар туралы" 1999 жылғы 13 қазандағы N 235 Жарлығына сәйкес Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. күші жойылды - ҚР Үкіметінің 2001.01.25. N 133 қаулысымен.

<a id="p2"></a>

2. "Қазақстан Республикасы Энергетика, индустрия және сауда министрлігінің мәселелері туралы" Қазақстан Республикасы Үкіметінің 1999 жылғы 27 мамырдағы N 657 қаулысына (Қазақстан Республикасының ПҮАЖ-ы, 1999 ж., N 22, 224-құжат) мынадай өзгерістер мен толықтырулар енгізілсін:

   1) 1-тармақтың күші жойылды деп танылсын;

   2) 2-тармақ мынадай мазмұндағы 7) және 8) тармақшалармен толықтырылсын:

   "7) Атом энергетикасы жөніндегі комитет;

   8) Аэроғарыш комитеті";

<a id="p3"></a>

3. Мыналардың күші жойылды деп танылсын:

   1) "Қазақстан Республикасы Үкіметінің 1999 жылғы; 27 мамырдағы N 657 қаулысына өзгерістер мен толықтырулар енгізу туралы" Қазақстан Республикасы Үкіметінің 1999 жылғы 13 шілдедегі N 968 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, N 1999 ж., N 34, 305-құжат);

   2) "Қазақстан Республикасы Энергетика, индустрия және сауда министрлігінің Мемлекеттік материалдық резервтер жөніндегі комитетінің мәселелері туралы" Қазақстан Республикасы Үкіметінің 1999 жылғы 27 тамыздағы N 1268 қаулысының (Қазақстан Республикасының ПҮАЖ-ы, 1999 ж., N 43, 293-құжат) 5-тармағының 2) тармақшасы.

<a id="p4"></a>

4. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Премьер-Министрі**
