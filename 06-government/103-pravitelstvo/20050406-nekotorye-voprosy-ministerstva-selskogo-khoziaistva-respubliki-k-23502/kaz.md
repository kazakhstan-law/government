# Қазақстан Республикасы Ауыл шаруашылығы министрлігінiң кейбiр мәселелерi

Қазақстан Республикасы Президентінiң "Қазақстан Республикасының мемлекеттік басқару жүйесiн одан әрi жетiлдiру жөніндегі шаралар туралы" 2004 жылғы 29 қыркүйектегi N 1449 Жарлығын іске асыру мақсатында Қазақстан Республикасының Үкiметi ҚАУЛЫ ЕТЕДІ:

1. Қоса берілiп отырған:

   1) Қазақстан Республикасы Ауыл шаруашылығы министрлiгi туралы ереже;

   2) (алынып тасталды - 2007.03.02 N 164 қаулысымен)

   3) Қазақстан Республикасы Ауыл шаруашылығы министрлiгiнiң қарамағындағы ұйымдардың тiзбесi;

   4) (алынып тасталды - 2007.10.28 N 995 қаулысымен)

   5) Қазақстан Республикасы Ауыл шаруашылығы министрлiгiнiң Орман және аңшылық шаруашылығы комитетi аумақтық органдары - мемлекеттік мекемелерiнiң тiзбесi;

   6) Қазақстан Республикасы Ауыл шаруашылығы министрлiгi Орман және аңшылық шаруашылығы комитетінің қарамағындағы ұйымдардың тізбесi;

   7) (алынып тасталды - 2007.10.28 N 995 қаулысымен)

   8) Қазақстан Республикасы Ауыл шаруашылығы министрлiгiнiң Су ресурстары комитетi аумақтық органдары - мемлекеттік мекемелерiнiң тізбесi;

   9) Қазақстан Республикасы Ауыл шаруашылығы министрлiгi Су ресурстары комитетiнiң қарамағындағы ұйымдардың тізбесі;

   10) (алынып тасталды - 2007.10.28 N 995 қаулысымен)

   11) Қазақстан Республикасы Ауыл шаруашылығы министрлігі Балық шаруашылығы комитетiнiң аумақтық органдары - мемлекеттiк мекемелерiнiң тiзбесi;

   12) Қазақстан Республикасы Ауыл шаруашылығы министрлiгi Балық шаруашылығы комитетiнiң қарамағындағы ұйымдардың тiзбесi;

   13) (алынып тасталды - 2007.10.28 N 995 қаулысымен)

       > *Ескерту. 1-тармаққа өзгерту енгізілді - ҚР Үкіметінің 2007.10.28 N 995 (қолданысқа енгізілу тәртібін 3-тармақтан қараңыз) Қаулысымен.*

2. Алынып тасталды - 2007.10.28 N 995 (қолданысқа енгізілу тәртібін 3-тармақтан қараңыз) Қаулысымен.

3. Қосымшаға сәйкес Қазақстан Республикасы Үкiметiнiң кейбiр шешiмдерiнiң күшi жойылды деп танылсын.

4. Осы қаулы қол қойылған күнінен бастап қолданысқа енгiзіледi.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | `!` Қазақстан Республикасы Ауыл шаруашылығы министрлігі туралы ереже |
| [`part004`](kaz/part004.md) | 3. Министрліктің қызметін ұйымдастыру |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
