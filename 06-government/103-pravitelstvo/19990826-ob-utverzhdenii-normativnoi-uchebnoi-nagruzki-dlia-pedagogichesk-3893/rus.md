# Об утверждении нормативной учебной нагрузки для педагогических работников государственных организаций образования

В соответствии с Законом Республики Казахстан от 7 июня 1999 года Z990389_ "Об образовании" Правительство Республики Казахстан постановляет:

1. Утвердить прилагаемую нормативную учебную нагрузку для педагогических работников государственных организаций образования.

2. Настоящее постановление вступает в силу со дня опубликования.

```
Премьер-Министр
Республики Казахстан
```

```
Утверждено
постановлением Правительства
Республики Казахстан
от 27 августа 1999 года № 1262
```

Нормативная учебная нагрузка

```
для педагогических работников государственных
организаций образования
Установить следующую нормативную учебную нагрузку в неделю для
педагогических работников государственных организаций образования:
20 часов - для начальной ступени общеобразовательного учебного
заведения;
18 часов - для основной и старшей ступеней общеобразовательного
учебного заведения;
18 часов - для организаций начального профессионального образования и
среднего профессионального образования;
24 часа - для дошкольных организаций;
18 часов - для внешкольных организаций;
24 часа - для детско-юношеских спортивных школ.
(Специалисты: Склярова И.В.,
Кушенова Д.С.)
```
