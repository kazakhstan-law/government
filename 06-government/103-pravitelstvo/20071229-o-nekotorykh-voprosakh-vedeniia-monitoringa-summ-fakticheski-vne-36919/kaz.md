# Салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомаларына инфляция деңгейін ескере отырып мониторинг жүргізудің кейбір мәселелері туралы

"Қазақстан Республикасында зейнетақымен қамсыздандыру туралы" Қазақстан Республикасының 1997 жылғы 20 маусымдағы Заңының 6-бабына сәйкес Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ :

1. Қазақстан Республикасы Еңбек және халықты әлеуметтік қорғау министрлігі:

   1) осы қаулыға қосымшаға сәйкес формула бойынша әрбір салымшы (алушы) бойынша ай сайынғы есептің негізінде салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомаларына инфляция деңгейін ескере отырып мониторингті жүзеге асырсын;

   2) салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомаларына инфляция деңгейін ескере отырып мониторинг жүргізудің тетігін белгілесін.

2. Осы қаулы қол қойылған күнінен бастап қолданысқа енгізіледі.

## Салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомаларын инфляция деңгейін ескере отырып есептеу формуласы

Салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомасы инфляция деңгейін ескере отырып, мына формула бойынша есептеледі:

n = 2, 3, ..., 12 болған кезде S n = S n-1 *I n + P n

S 1 = P 1 ,

I n < 100% болған кезде I n =100%

n - есепті ай;

S n - n айындағы инфляция деңгейін ескере отырып, салымшылардың (алушылардың) іс жүзінде енгізілген міндетті зейнетақы жарналарының сомасы, теңгемен;

I n - алдыңғы айға қатысты n айындағы инфляцияның көрсеткіші, пайызбен;

P n - n айындағы міндетті зейнетақы жарналарының түсімі, теңгемен.
