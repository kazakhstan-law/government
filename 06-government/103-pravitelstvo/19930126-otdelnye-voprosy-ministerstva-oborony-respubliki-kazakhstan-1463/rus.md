# Отдельные вопросы Министерства обороны Республики Казахстан

Кабинет Министров Республики Казахстан ПОСТАНОВЛЯЕТ:

2. Предоставить Министру обороны Республики Казахстан право по согласованию с Министерством финансов Республики Казахстан устанавливать должностные оклады по нетиповым должностям центрального аппарата Министерства обороны Республики Казахстан.

3. Признать утратившим силу пункт 3 постановления Кабинета Министров Республики Казахстан от 2 июля 1992г. N 575 P920575_ (САПП Республики Казахстан, 1992г., N 27, ст.413).
