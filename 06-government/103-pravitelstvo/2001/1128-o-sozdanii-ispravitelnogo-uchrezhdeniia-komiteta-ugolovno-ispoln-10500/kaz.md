# Қазақстан Республикасының Iшкi iстер министрлiгi Қылмыстық-атқару жүйесi комитетiнiң түзеу мекемесін құру туралы

Қазақстан Республикасының Үкiметi қаулы етеді:

<a id="p1"></a>

1. "Қазақстан Республикасының Iшкi iстер министрлiгi Қылмыстық-атқару жүйесi комитетiнiң ЖД-158/6 түзеу мекемесi" мемлекеттiк мекемесi (бұдан әрi - мекеме) құрылсын.

<a id="p2"></a>

2. Қылмыстық-атқару жүйесi штат санының лимитi шегiнде мекеменiң штат санының лимитi 20 бiрлiк мөлшерiнде бекiтiлсiн.

<a id="p3"></a>

3. Мекеменi ұстау шығындары тиiстi жылға арналған республикалық бюджетте сотталғандарды ұстауға Қылмыстық-атқару жүйесi комитетiне көзделген қаражат шегiнде жүргiзiледi деп белгiленсiн.

<a id="p4"></a>

4. Қазақстан Республикасының Iшкi iстер министрлiгi Қылмыстық-атқару жүйесi комитетi заңнамамен белгiленген тәртiппен:

   1) мекеменiң Жарғысын бекiтсiн және оның әдiлет органдарында тiркелуiн қамтамасыз етсiн;

   2) осы қаулыны iске асыру жөнiнде өзге де шараларды қабылдасын.

<a id="p5"></a>

5. "Қазақстан Республикасының Iшкi iстер министрлiгi Қылмыстық-атқару жүйесi комитетiнiң мәселелерi" туралы Қазақстан Республикасы Yкiметiнiң 2000 жылғы 5 мамырдағы N 668 P000668_ қаулысына (Қазақстан Республикасының ПYКЖ-ы, 2000 ж., N 21, 235-құжат) мынадай толықтыру енгiзiлсiн:

```
көрсетiлген қаулымен бекiтiлген Қазақстан Республикасының Iшкi істер
министрлiгi Қылмыстық-атқару жүйесi комитетiнiң қарамағындағы ұйымдардың
тiзбесi мынадай мазмұндағы реттiк нөмiрi 99-жолмен толықтырылсын:
"99. ЖД-158/6 мекемесi".
6. Осы қаулы қол қойылған күнінен бастап күшiне енедi.
Қазақстан Республикасының
Премьер-Министрі
Мамандар:

```
