# Қазақстан Республикасының Ішкі істер министрлігі Қылмыстық-атқару жүйесі комитетінің түзеу мекемесін құру туралы

Сотталғандарды ұстаудың жағдайларын жақсарту мақсатында Қазақстан Республикасының Үкіметі қаулы етеді:

<a id="p1"></a>

1. Сотталғандар мен тергеу-қамауындағы адамдарды ұстауға 2001 жылға арналған республикалық бюджетте Қазақстан Республикасы Ішкі істер министрлігінің Қылмыстық-атқару жүйесі комитетіне көзделген қаражат есебінен және шегінде ("Түзеу мекемелері" кіші бағдарламасы) "Қазақстан Республикасының Ішкі істер министрлігі Қылмыстық-атқару жүйесі комитетінің ЕЦ-166/26 түзеу мекемесі" (бұдан әрі - мекеме) мемлекеттік мекемесі құрылсын.

<a id="p2"></a>

2. Мекеменің штат санының лимиті 375 бірлік мөлшерінде белгіленсін.

<a id="p3"></a>

3. Мекеменің штат санын ұстауға арналған шығыстарды қаржыландыру 2002 жылғы 1 қаңтардан бастап республикалық бюджеттен жүргізілсін.

<a id="p4"></a>

4. Қазақстан Республикасы Ішкі істер министрлігінің Қылмыстық-атқару жүйесі комитеті заңнамада белгіленген тәртіппен:

   1) мекеменің жарғысын бекітсін және оның әділет органдарында мемлекеттік тіркелуін қамтамасыз етсін;

   2) осы қаулыны іске асыру жөнінде өзге де шаралар қабылдасын.

<a id="p5"></a>

5. Қазақстан Республикасы Үкіметінің кейбір шешімдеріне мынадай өзгерістер мен толықтыру енгізілсін:

   1) күші жойылды - ҚР Үкіметінің 2002.12.29. N 1443 қаулысымен;

   2) күші жойылды - ҚР Үкіметінің 2001.12.28. N 1755 қаулысымен;

   3) күші жойылды - ҚР Үкіметінің 2002.12.29. N 1443 қаулысымен.

<a id="p6"></a>

6. Қазақстан Республикасының Мемлекеттік құпияларды қорғау жөніндегі агенттігі мемлекеттік құпияларды құрайтын мәлімет көздерінің құпиясын ашу тәртібін әзірлесін және Қазақстан Республикасының Үкіметіне бекітуге ұсынсын.

<a id="p7"></a>

7. Осы қаулы, оның 3-тармағынан басқасы, қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Премьер-Министрі**
