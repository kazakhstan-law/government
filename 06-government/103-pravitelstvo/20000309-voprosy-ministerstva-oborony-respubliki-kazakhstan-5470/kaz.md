# Қазақстан Республикасы Қорғаныс министрлігінің мәселелері

Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

1. Мыналар бекітілсін:

   1) күші жойылды - ҚР Үкіметінің 2001.08.16 N 1074 қаулысымен;

   2) Қорғаныс министрлігінің 489 бірліктегі штат санының лимиті.

   3) күші жойылды - ҚР Үкіметінің 27.06.2014 № 707 қаулысымен.

> *Ескерту. 1-тармаққа өзгеріс енгізілді - ҚР Үкіметінің 2000.12.06 N 1816, 2001.08.16 N 1074, 2001.10.15 N 1330, 2002.03.19 N 332, 2002.06.14 N 649, 2002.06.17 N 659, 2002.12.18 N 1320, 2004.01.15 N 39, 2004.04.12 N 404, 2004.07.12 N 754, 2004.10.12 N 1045, 2005.02.02 N 84, 2005.09.05 N 897, 2005.11.14 N 1125, 2008.08.29 N 806, 2009.08.06 N 1208 (құпия), 2010.10.11 N 1057 (құпия), 2010.10.29 N 1136 (2010.11.01 бастап қолданысқа енгізіледі), 2012.05.08 N 598, 2012.10.08 N 1261 қбпү (жариялануға жатпайды); 27.06.2014 № 707 қаулыларымен.*

2. Мыналардың күші жойылды деп танылсын:

   1) "Қазақстан Республикасы Қорғаныс министрлігінің құрылымы туралы" Қазақстан Республикасы Үкіметінің 1998 жылғы 23 ақпандағы N 127 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 1998 ж., N 6, 34-құжат);

   2) "Қазақстан Республикасының Қорғаныс министрлігі және Қазақстан Республикасы Қарулы Күштерінің Бас штабы туралы ережелерді бекіту туралы" Қазақстан Республикасы Үкіметінің 1998 жылғы 19 маусымдағы N 574 қаулысы .

3. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Премьер-Министрі**
