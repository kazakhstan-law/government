# Қазақстан Республикасы Қорғаныс министрлігінің мәселелері

Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

1. Мыналар бекітілсін:

   1) <*>

   2) Қорғаныс министрлігінің 575 бірліктегі штат санының лимиті.

   3) Құпия.

      > *Ескерту. 3) тармақшамен толықтырылды - ҚР Үкіметінің 2000.12.06. N 1816 қаулысымен .*

      > *Ескерту. 1) тармақшаның күші жойылды - ҚР Үкіметінің 2001.08.16. N 1074 қаулысымен .*

      > *Ескерту. 3) тармақшамен толықтырылды - ҚР Үкіметінің 2001.10.15. N 1330 қаулысымен .*

      > *Ескерту. 1-тармаққа өзгеріс енгізілді - ҚР Үкіметінің 2002.03.19. N 332 қаулысымен .*

      > *Ескерту. 1-тармаққа өзгеріс енгізілді - ҚР Үкіметінің 2002.06.14. N 649 қаулысымен .*

      > *Ескерту. 1-тармаққа өзгеріс енгізілді - ҚР Үкіметінің 2002.06.17. N 659 қаулысымен .*

      > *Ескерту. 1-тармақтың 3) тармақшасы өзгерді - ҚР Үкіметінің 2002.12.18. N 1320 қаулысымен.*

      > *Ескерту. 1-тармақтың 3) тармақшасына өзгеріс енгізілді - ҚР Үкіметінің 2004.01.15. N 39 қаулысымен .*

      > *Ескерту. 1-тармақтың 3) тармақшасына өзгеріс енгізілді - ҚР Үкіметінің 2004.04.12. N 404 қаулысымен .*

      > *Ескерту. 1-тармақтың 3) тармақшасына өзгеріс енгізілді - ҚР Үкіметінің 2004.07.12. N 754 қаулысымен .*

      > *Ескерту. 1-тармақтың 3) тармақшасына өзгеріс енгізілді - ҚР Үкіметінің 2004.10.12. N 1045 қаулысымен .*

2. Мыналардың күші жойылды деп танылсын:

   1) "Қазақстан Республикасы Қорғаныс министрлігінің құрылымы туралы" Қазақстан Республикасы Үкіметінің 1998 жылғы 23 ақпандағы N 127 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 1998 ж., N 6, 34-құжат);

   2) "Қазақстан Республикасының Қорғаныс министрлігі және Қазақстан Республикасы Қарулы Күштерінің Бас штабы туралы ережелерді бекіту туралы" Қазақстан Республикасы Үкіметінің 1998 жылғы 19 маусымдағы N 574 қаулысы .

3. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

   Қазақстан Республикасының
