# Қазақстан Республикасы Денсаулық сақтау министрлiгiнiң "Ақмола мемлекеттiк медицина академиясы" республикалық мемлекеттiк қазыналық кәсіпорнын қайта атау туралы

Қазақстан Республикасының Yкiметi қаулы етеді:

<a id="p1"></a>

1. Қазақстан Республикасы Денсаулық сақтау министрлiгiнiң "Ақмола мемлекеттiк медицина академиясы" республикалық мемлекеттiк қазыналық кәсiпорны Қазақстан Республикасы Денсаулық сақтау министрлiгiнiң "Қазақ мемлекеттік медицина академиясы" республикалық мемлекеттiк қазыналық кәсiпорны (бұдан әрi - Кәсiпорын) болып қайта аталсын.

<a id="p2"></a>

2. Қазақстан Республикасының Денсаулық сақтау министрлiгi Қазақстан Республикасының заңнамасында белгiленген тәртiппен Кәсiпорынның әдiлет органдарында мемлекеттiк қайта тiркелуiн қамтамасыз етсiн.

<a id="p3"></a>

3. Қазақстан Республикасы Үкiметiнің кейбiр шешiмдерiне мынадай өзгерiстер енгiзiлсiн:

   1) "Республикалық мемлекеттiк кәсiпорындардың тiзбесi туралы" Қазақстан Республикасы Yкiметiнің 1996 жылғы 25 маусымдағы N 790 қаулысына (Қазақстан Республикасының ПҮКЖ-ы, 1996 ж., N 29, 256-құжат):

      көрсетiлген қаулымен бекiтiлген Республикалық мемлекеттiк кәсiпорындардың тiзбесінде:

      "Қазақстан Республикасының Денсаулық сақтау министрлiгi" деген бөлiмде:

      реттiк нөмiрi 9-3-жол мынадай редакцияда жазылсын:

<a id="p9-3"></a>

"9-3. "Қазақ мемлекеттiк

медицина академиясы"

қазыналық кәсіпорны Астана қаласы";

2) <*>

   > *Ескерту. 2)-тармақшаның күші жойылды - ҚР Үкіметінің 2004.10.28. N 1117 қаулысымен.*

<a id="p4"></a>

4. Осы қаулы қол қойылған күнінен бастап күшiне енедi.
