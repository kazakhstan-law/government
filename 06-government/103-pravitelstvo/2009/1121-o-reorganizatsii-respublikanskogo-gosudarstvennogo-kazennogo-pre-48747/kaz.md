# Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің "Республикалық ветеринариялық зертхана" республикалық мемлекеттік қазыналық кәсіпорнын қайта ұйымдастыру туралы

Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің "Республикалық ветеринариялық зертхана" республикалық мемлекеттік қазыналық кәсіпорны заңнамада белгіленген тәртіппен Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің "Республикалық ветеринариялық зертхана" шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорны (бұдан әрі - кәсіпорын) болып қайта құру жолымен қайта ұйымдастырылсын.

<a id="p2"></a>

2. Кәсіпорын қызметінің мәні:

   1) ветеринария саласындағы уәкілетті орган бекітетін тізбеге енгізілген жануарлардың аса қауіпті ауруларының диагностикасы;

   2) облыстың, республикалық маңызы бар қаланың, астананың жергілікті атқарушы органы бекітетін тізбеге енгізілген жануарлардың энзоотиялық ауруларының диагностикасы болып айқындалсын.

> *Ескерту. 2-тармақ жаңа редакцияда - ҚР Үкіметінің 29.09.2015 № 803 қаулысымен (алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі).*

<a id="p3"></a>

3. Қазақстан Республикасы Ауыл шаруашылығы министрлігінің Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитеті кәсіпорынның мемлекеттік басқару органы болып белгіленсін.

<a id="p4"></a>

4. Қазақстан Республикасы Ауыл шаруашылығы министрлігі заңнамада белгіленген тәртіппен:

   1) Қазақстан Республикасы Қаржы министрлігінің Мемлекеттік мүлік және жекешелендіру комитетіне кәсіпорынның Жарғысын бекітуге енгізсін және оны әділет органдарында мемлекеттік тіркеуді қамтамасыз етсін;

   2) осы қаулыдан туындайтын өзге де шараларды қабылдасын.

<a id="p5"></a>

5. Қоса беріліп отырған Қазақстан Республикасы Үкіметінің кейбір шешімдеріне енгізілетін өзгерістер бекітілсін.

<a id="p6"></a>

6. Осы қаулы қол қойылған күнінен бастап қолданысқа енгізіледі.

## Қазақстан Республикасы Үкіметінің кейбір шешімдеріне енгізілетін өзгерістер

<a id="an0_p1"></a>

1. Күші жойылды - ҚР Үкіметінің 05.08.2013 № 796 қаулысымен.

<a id="an0_p2"></a>

2. Күші жойылды - ҚР Үкіметінің 2010.11.09 № 1177 Қаулысымен.

<a id="an0_p3"></a>

3. "Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің кейбір мәселелері" туралы Қазақстан Республикасы Үкіметінің 2007 жылғы 2 наурыздағы N 164 қаулысына (Қазақстан Республикасының ПҮАЖ-ы, 2007 ж., N 7, 82-құжат):

   көрсетілген қаулымен бекітілген Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитетінің қарамағындағы ұйымдардың тізбесінде:

   "Республикалық мемлекеттік кәсіпорындар" деген 1-бөлімде:

   2-тармақта "республикалық мемлекеттік қазыналық кәсіпорны" деген сөздер "шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорны" деген сөздермен ауыстырылсын.

<a id="an0_p4"></a>

4. Күші жойылды - ҚР Үкіметінің 28.08.2015 № 683 қаулысымен.
