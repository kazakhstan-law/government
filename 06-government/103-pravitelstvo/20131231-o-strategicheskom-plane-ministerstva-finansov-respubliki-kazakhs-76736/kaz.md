# Қазақстан Республикасы Қаржы министрлігінің 2014 - 2018 жылдарға арналған стратегиялық жоспары туралы

> РҚАО-ның ескертпесі!

Осы қаулы 2014 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.

2008 жылғы 4 желтоқсандағы Қазақстан Республикасы Бюджет кодексінің 62-бабына сәйкес Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

1. Қоса беріліп отырған Қазақстан Республикасы Қаржы министрлігінің 2014 – 2018 жылдарға арналған стратегиялық жоспары бекітілсін.

2. Осы қаулы 2014 жылғы 1 қаңтардан бастап қолданысқа енгізіледі және ресми жариялануға тиіс.

Қазақстан Республикасының

Премьер-Министрі С. Ахметов

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| [`part023`](kaz/part023.md) | 6. Қаржы мониторингі |
| [`part028`](kaz/part028.md) | 3.1 Стратегиялық бағыттар, мақсаттар, міндеттер, нысаналы индикатор, іс-шаралар мен нәтижелер көрсеткіштері |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
