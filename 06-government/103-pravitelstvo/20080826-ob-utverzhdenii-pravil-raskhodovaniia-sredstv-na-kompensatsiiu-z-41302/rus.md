# Об утверждении Правил расходования средств на компенсацию затрат по поставкам топлива для энергопроизводящей организации в целях обеспечения стабильного электроснабжения потребителей южных регионов Казахстана

В соответствии со статьей 16-1 Закона Республики Казахстан от 6 декабря 2007 года "О республиканском бюджете на 2008 год" Правительство Республики Казахстан ПОСТАНОВЛЯЕТ:

1. Утвердить прилагаемые Правила расходования средств на компенсацию затрат по поставкам топлива для энергопроизводящей организации в целях обеспечения стабильного электроснабжения потребителей южных регионов Казахстана.

2. Министерству энергетики и минеральных ресурсов Республики Казахстан принять необходимые меры, вытекающие из настоящего постановления.

3. Настоящее постановление вводится в действие со дня подписания.

**Премьер-Министр Республики Казахстан**

**К. Масимов**

> *Утверждены*  
> *постановлением Правительства*  
> *Республики Казахстан*  
> *от 26 августа 2008 года N 769*

## Правила расходования средств на компенсацию затрат по поставкам топлива для энергопроизводящей организации в целях обеспечения стабильного электроснабжения потребителей южных регионов Казахстана

1. Настоящие Правила расходования средств на компенсацию затрат по поставкам топлива для энергопроизводящей организации в целях обеспечения стабильного электроснабжения потребителей южных регионов Казахстана (далее - Правила) определяют порядок расходования средств на компенсацию затрат по поставкам топлива для энергопроизводящей организации в целях обеспечения стабильного электроснабжения потребителей южных регионов Казахстана (далее - компенсация затрат по поставкам топлива).

2. Расходование средств на компенсацию затрат по поставкам топлива осуществляется за счет средств, предусмотренных в республиканском бюджете на 2008 год по бюджетной программе 026 "Обеспечение стабильного энергоснабжения потребителей южных регионов Казахстана".

3. Компенсация затрат акционерному обществу "Жамбылская государственная районная электрическая станция имени Т.И. Батурова" (далее - АО "Жамбылская ГРЭС") по поставкам топлива осуществляется на расходы по компенсации затрат за поставку топлива и для покрытия разницы между ценой покупки топлива с учетом расходов на транспортировку и стоимостью топлива, необходимого для сохранения устойчивых тарифов на электроэнергию для потребителей южных регионов Казахстана.

4. Министерство энергетики и минеральных ресурсов Республики Казахстан:

   1) утверждает расчет фактических затрат, произведенных для снижения стоимости электроэнергии, отпускаемой АО "Жамбылская ГРЭС";

   2) на основании платежных документов, представленных АО "Жамбылская ГРЭС" по обеспечению стабильного электроснабжения потребителей южных регионов Казахстана в соответствии с пунктом 3 настоящих Правил, осуществляет в установленном законодательством порядке перечисление средств АО "Жамбылская ГРЭС";

   3) в пределах своей компетенции несет ответственность за эффективное, результативное и целевое использование средств на компенсацию затрат по поставкам топлива.
