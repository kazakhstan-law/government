## Қазақстан Республикасы Үкіметінің күші жойылған кейбір шешімдерінің тізбесі

<a id="an6_p1"></a>

1. "Қазақстан Республикасының Қаржы министрлігі Қазынашылық комитетінің мәселелері" Қазақстан Республикасы Үкіметінің 1999 жылғы 24 мамырдағы N 626 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 1999 ж., N 22, 215-құжат), 1-тармағының 3) тармақшасын қоспағанда.

<a id="an6_p2"></a>

2. "Қазақстан Республикасының Қаржы министрлігі Мемлекеттік мүлік және жекешелендіру комитетінің мәселелері" туралы Қазақстан Республикасы Үкіметінің 1999 жылғы 5 шілдедегі N 930 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 1999 ж., N 32-33, 295-құжат), 1-тармақтың 3) тармақшасын және 2, 3-тармақтарын қоспағанда.

<a id="an6_p3"></a>

3. Қазақстан Республикасының Қаржы министрлігі жүйесінің жекелеген мәселелері туралы" Қазақстан Республикасы Үкіметінің 2000 жылғы 1 наурыздағы N 338 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2000 ж., N 11-12, 125-құжат), 2-тармағын қоспағанда.

<a id="an6_p4"></a>

4. "Қазақстан Республикасы Үкіметінің 1999 жылғы 24 мамырдағы N 626 және 1999 жылғы 5 шілдедегі N 930 қаулыларына өзгерістер енгізу туралы" Қазақстан Республикасы Үкіметінің 2000 жылғы 18 шілдедегі N 1084 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2000 ж., N 30, 369-құжат).

<a id="an6_p5"></a>

5. "Қазақстан Республикасы Үкіметінің кейбір шешімдеріне өзгерістер мен толықтырулар енгізу туралы" Қазақстан Республикасы Үкіметінің 2001 жылғы 12 маусым N 813 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2001 ж., N 22, 276-құжат).

<a id="an6_p6"></a>

6. "Қазақстан Республикасы Қаржы министрлігінің кейбір мәселелері" туралы Қазақстан Республикасы Үкіметінің 2002 жылғы 3 қыркүйектегі N 962 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2002 ж., N 29, 322-құжат), 3-тармағын қоспағанда.

<a id="an6_p7"></a>

7. "Қазақстан Республикасының Қаржы министрлігі Салық комитетінің мәселелері" Қазақстан Республикасы Үкіметінің 2002 жылғы 9 қазандағы N 1102 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2002 ж., N 33, 359-құжат), 1-тармақтың 3) тармақшасын және 2-тармағын қоспағанда.

<a id="an6_p8"></a>

8. "Қазақстан Республикасы Үкіметінің 1999 жылғы 5 шілдедегі N 930 қаулысына өзгерістер мен толықтырулар енгізу туралы" Қазақстан Республикасы Үкіметінің 2002 жылғы 11 қазандағы N 1113 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2002 ж., N 34, 366-құжат).

<a id="an6_p9"></a>

9. "Қазақстан Республикасының Қаржы министрлігі Салық комитетінің N 1 аймақаралық салық комитеті" мемлекеттік мекемесін құру туралы" Қазақстан Республикасы Үкіметінің 2003 жылғы 31 қаңтардағы N 114 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2003 ж., N 4, 54-құжат), 1-тармағын қоспағанда.

<a id="an6_p10"></a>

10. "Қазақстан Республикасының Қаржы министрлігі Мемлекеттік мүлік және жекешелендіру комитетінің кейбір мәселелері" Қазақстан Республикасы Үкіметінің 2004 жылғы 28 қазандағы N 1114 қаулысы , (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 40, 525-құжат), 1-тармақтың 3) тармақшасын қоспағанда.

<a id="an6_p11"></a>

11. "Қазақстан Республикасы Қаржы министрлігі Дәрменсіз борышкерлермен жұмыс комитетінің кейбір мәселелері" Қазақстан Республикасы Үкіметінің 2004 жылғы 28 қазандағы N 1115 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 40, 526-құжат), 1-тармақтың 3) тармақшасын қоспағанда.

<a id="an6_p12"></a>

12. "Қазақстан Республикасы Қаржы министрлігінің кейбір мәселелері" туралы Қазақстан Республикасы Үкіметінің 2004 жылғы 28 қазандағы N 1119 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 41, 531-құжат).

<a id="an6_p13"></a>

13. "Қазақстан Республикасы Қаржы министрлігі Салық комитетінің кейбір мәселелері" Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1127 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 42, 536-құжат), 1-тармақтың 3) тармақшасын қоспағанда.

<a id="an6_p14"></a>

14. "Қазақстан Республикасы Қаржы министрлігі Қазынашылық комитетінің кейбір мәселелері" туралы Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1129 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 42, 537-құжат).

<a id="an6_p15"></a>

15. "Қазақстан Республикасы Қаржы министрлігі Кедендік бақылау комитетінің мәселелері" Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1133 қаулысы , (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 43, 541-құжат), 1, 2-тармақтарын және 3-тармақтың 3) тармақшасын қоспағанда.

<a id="an6_p16"></a>

16. "Қазақстан Республикасы Қаржы министрлігі Қаржылық бақылау және мемлекеттік сатып алу комитетінің кейбір мәселелері" Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1134 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2004 ж., N 43, 542-құжат), 1, 2, 3-тармақтарын және 4-тармақтың 3) және 4) тармақшаларын қоспағанда.

<a id="an6_p17"></a>

17. "Қазақстан Республикасы Үкіметінің 2005 жылғы 8 сәуірдегі N 114 қаулысына өзгеріс енгізу туралы" Қазақстан Республикасы Үкіметінің 2005 жылғы 3 ақпандағы N 101 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2005 ж., N 6, 51-құжат).

<a id="an6_p18"></a>

18. "Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1129 қаулысына өзгеріс енгізу туралы" Қазақстан Республикасы Үкіметінің 2005 жылғы 8 сәуірдегі N 320 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2005 ж., N 15, 180-құжат).

<a id="an6_p19"></a>

19. "Қазақстан Республикасы Үкіметінің 2004 жылғы 29 қазандағы N 1129 қаулысына өзгеріс енгізу туралы" Қазақстан Республикасы Үкіметінің 2005 жылғы 10 тамыздағы N 823 қаулысы .

<a id="an6_p20"></a>

20. "Қазақстан Республикасы Үкіметінің кейбір шешімдеріне өзгерістер енгізу туралы" Қазақстан Республикасы Үкіметінің 2005 жылғы 22 қазандағы N 1063 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2005 ж., N 38, 542-құжат).

<a id="an6_p21"></a>

21. "Қазақстан Республикасы Қаржы министрлігі Кедендік бақылау комитетінің Маңғыстау облысы бойынша Кедендік бақылау департаменті" мемлекеттік мекемесін қайта ұйымдастыру туралы" Қазақстан Республикасы Үкіметінің 2005 жылғы 30 қарашадағы N 1175 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2005 ж., N 44, 586-құжат), 1-тармағын қоспағанда.

<a id="an6_p22"></a>

22. "Қазақстан Республикасы Үкіметінің 2004 жылғы 28 қазандағы N 1115 және 2004 жылғы 28 қазандағы N 1119 қаулыларына өзгерістер мен толықтырулар енгізу туралы" Қазақстан Республикасы Үкіметінің 2006 жылғы 27 сәуірдегі N 333 қаулысы (Қазақстан Республикасының ПҮАЖ-ы, 2006 ж., N 15, 147-құжат).
