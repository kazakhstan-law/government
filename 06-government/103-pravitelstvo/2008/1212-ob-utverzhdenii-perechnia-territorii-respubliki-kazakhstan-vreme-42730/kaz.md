# Қазақстан Республикасының шетелдіктердің болуы үшін уақытша жабық аумақтарының тізбесін бекіту туралы

"Мемлекеттік құпиялар туралы" Қазақстан Республикасының 1999 жылғы 15 наурыздағы Заңының 7-бабының 7) тармақшасына сәйкес Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Қоса беріліп отырған Қазақстан Республикасының шетелдіктердің болуы үшін уақытша жабық аумақтарының тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасының шетелдіктердің болуы үшін уақытша жабық аумақтарына шетелдіктердің кіруіне Қазақстан Республикасы Сыртқы істер министрлігі және Ішкі істер министрлігі Қазақстан Республикасы Ұлттық қауіпсіздік комитетімен келісім бойынша рұқсат береді.

<a id="p3"></a>

3. Қазақстан Республикасы Сыртқы істер министрлігі Қазақстан Республикасының шетелдіктердің болуы үшін уақытша жабық аумақтарының тізбесін Қазақстан Республикасында аккредиттелген шетелдік дипломатиялық өкілдіктер мен консулдық мекемелердің назарына жеткізсін.

<a id="p4"></a>

4. "Қазақстан Республикасының шет ел азаматтарының және азаматтығы жоқ адамдардың келіп-қайтуына уақытша жабық аумақтарының тізбесін бекіту туралы" Қазақстан Республикасы Үкіметінің 2001 жылғы 31 қаңтардағы N 153 қаулысының күші жойылды деп танылсын.

<a id="p5"></a>

5. Осы қаулы алғаш рет ресми жарияланған күнінен бастап он күнтізбелік күн өткен соң қолданысқа енгізіледі.

## Қазақстан Республикасының шетелдіктердің болуы үшін уақытша жабық аумақтарының тізбесі

<a id="an0_p1"></a>

1. Жабылатын аумаққа кірмейтін Алматы облысының қалалық үлгідегі Гвардейский кентінің Мәтібұлақ (Рославль) (75 0 16'25; 43 0 33'58), Мәтебұлақ (75 0 15'35; 43 0 36'9) елді мекендерінің және Жамбыл облысының Құлжабасы темір жол разъезінің (75 0 06'04; 43 0 34'18) координата нүктелерімен шектелген аумағы - 2015 жылға дейін;

<a id="an0_p2"></a>

2. Қызылорда облысының Байқоңыр қаласы, Қармақшы және Қазалы аудандары - 2015 жылға дейін.
