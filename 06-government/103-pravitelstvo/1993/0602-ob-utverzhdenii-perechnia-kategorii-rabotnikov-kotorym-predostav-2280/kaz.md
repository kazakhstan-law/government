# Об утверждении Перечня категорий работников, которым предоставляются служебные жилые помещения

(ЕСКЕРТУ. Қазақша аудармасы жоқ, текстi орысшадан қараңыз.)

В соответствии со статьями 124, 125 Жилищного кодекса Республики Казахстан Кабинет Министров Республики Казахстан ПОСТАНОВЛЯЕТ:

Утвердить прилагаемый Перечень категорий работников, которым предоставляются служебные жилые помещения, с приложениями:

N 1 - ордер на служебное жилое помещение;

N 2 - корешок ордера на служебное жилое помещение;

N 3 - контрольный талон к ордеру на служебное жилое помещение.

```
Премьер-министр
Республики Казахстан
```

```
постановлением Кабинета Министров
Республики Казахстан
от 3 июня 1993 г. N 455
```
