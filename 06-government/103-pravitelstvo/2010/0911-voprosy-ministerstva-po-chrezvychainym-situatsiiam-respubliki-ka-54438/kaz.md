# Қазақстан Республикасы Төтенше жағдайлар министрлігінің мәселелері

Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. «Қазақстан Республикасы Төтенше жағдайлар министрлігі Ақмола облысының Төтенше жағдайлар департаменті Щучье ауданының Төтенше жағдайлар бөлімі» мемлекеттік мекемесі «Қазақстан Республикасы Төтенше жағдайлар министрлігі Ақмола облысының Төтенше жағдайлар департаменті Бурабай ауданының Төтенше жағдайлар бөлімі» мемлекеттік мекемесі болып қайта аталсын.

<a id="p2"></a>

2. Қазақстан Республикасы Төтенше жағдайлар министрлігі заңнамада белгіленген тәртіппен осы қаулыдан туындайтын шараларды қабылдасын.

<a id="p3"></a>

3. Күші жойылды - ҚР Үкіметінің 15.08.2014 N 938 қаулысымен.

<a id="p4"></a>

4. Осы қаулы қол қойылған күнінен бастап қолданысқа енгізіледі.

**Қазақстан Республикасының Премьер-Министрі**

**К. Мәсімов**
