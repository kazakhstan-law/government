# Об утверждении лимита штатной численности Комитета по внешнему заимствованию Министерства финансов Республики Казахстан

```
Правительство Республики Казахстан постановляет:
1. Утвердить лимит штатной численности Комитета по внешнему
заимствованию Министерства финансов Республики Казахстан в количестве
27 единиц.
2. Настоящее постановление вступает в силу с даты подписания.
Премьер-Министр
Республики Казахстан
```
