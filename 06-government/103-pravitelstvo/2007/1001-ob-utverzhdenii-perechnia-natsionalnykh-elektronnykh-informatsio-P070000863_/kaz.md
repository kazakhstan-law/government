# Ұлттық электрондық ақпараттық ресурстар мен ұлттық ақпараттық жүйелердің тізбесін бекіту туралы

"Ақпараттандыру туралы" Қазақстан Республикасының 2007 жылғы 11 қаңтардағы Заңының 5-бабына сәйкес Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ:

1\. Қоса беріліп отырған ұлттық электрондық ақпараттық ресурстар мен ұлттық ақпараттық жүйелердің тізбесі бекітілсін.

2\. Осы қаулы алғаш рет ресми жарияланғаннан кейін он күнтізбелік күн өткен соң қолданысқа енгізіледі.

## Ұлттық электрондық ақпараттық ресурстар мен ұлттық ақпараттық жүйелердің тізбесі

> *Ескерту. Тізбе жаңа редакцияда - ҚР Үкіметінің 2011.04.27 N 448 (алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі) Қаулысымен, өзгеріс енгізілді - ҚР Үкіметінің 2011.06.06 N 631 (алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі) Қаулысымен.*

1\. «Мекенжай тіркелімі» мемлекеттік дерекқоры» ақпараттық жүйесі.

2\. «Жеке тұлғалар» мемлекеттік дерекқоры» ақпараттық жүйесі.

<a id="para_3"></a>

3\. «Заңды түлғалар» мемлекеттік дерекқоры» ақпараттық жүйесі.

<a id="para_4"></a>

4\. «Жылжымайтын мүлік тіркелімі» мемлекеттік дерекқоры» ақпараттық жүйесі.

<a id="para_5"></a>

5\. «Е-лицензиялау» мемлекеттік дерекқоры» ақпараттык жүйесі.

<a id="para_6"></a>

6\. «Электрондық үкімет» веб-порталы.

<a id="para_7"></a>

7\. «Электрондық үкімет» шлюзі.

<a id="para_8"></a>

8\. «Электрондық үкіметтің» төлем шлюзі» ақпараттық жүйесі.

<a id="para_9"></a>

9\. Қазақстан Республикасының Ұлттық куәландырушы орталығы.

<a id="para_10"></a>

10\. Қазақстан Республикасы мемлекеттік органдарының куәландырушы орталығы.

<a id="para_11"></a>

11\. Қазақстан Республикасы мемлекеттік органдарының электрондық құжат айналымының бірыңғай жүйесі.

<a id="para_12"></a>

12\. «Электрондық ақпараттық ресурстар мен ақпараттық жүйелердің мемлекеттік тіркелімі» ақпараттық жүйесі.

<a id="para_13"></a>

13\. «Ақпараттық жүйелердің, бағдарламалық өнімдердің, бағдарламалық кодтардың және нормативтік-техникалық құжаттамалардың депозитарийі» ақпараттық жүйесі.

<a id="para_14"></a>

14\. «KZ домендік атаулары мониторингінің жүйесі» ақпараттық жүйесі.

<a id="para_15"></a>

15\. Қазынашылыктың біріктірілген ақпараттық жүйесі.

<a id="para_16"></a>

16\. «Біріктірілген салық ақпараттық жүйесі» ақпараттық жүйесі.

<a id="para_17"></a>

17\. «Салықтык есептілікті өңдеу сервистері» ақпараттық жүйесі.

<a id="para_18"></a>

18\. «Салық төлеушінің кабинеті» Web-қосымшасы» ақпараттық жүйесі.

<a id="para_19"></a>

19\. «Электрондық мемлекеттік сатып aлу» автоматтандырылған ақпараттық жүйесі.

<a id="para_20"></a>

20\. Мемлекеттік органдардың электрондық мұрағаттар жүйесі.

<a id="para_21"></a>

21\. Мемлекеттік органдардың бірыңғай көлік ортасы.

<a id="para_22"></a>

22\. «Мемлекеттік стандарттар» автоматтандырылған ақпараттық жүйесі.

<a id="para_23"></a>

23\. Қазақстан Республикасының «Мемлекеттік тіл порталы».

<a id="para_24"></a>

24\. Мемлекеттік жер кадастрының автоматтандырылған ақпараттық жүйесі.

<a id="para_25"></a>

25\. «E-learning» электрондық оқыту жүйесі.
