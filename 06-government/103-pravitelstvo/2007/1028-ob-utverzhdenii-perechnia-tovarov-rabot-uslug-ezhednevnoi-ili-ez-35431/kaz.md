# Үздіксіз қызметті қамтамасыз ету үшін тапсырыс берушілер сатып алатын күнделікті немесе апта сайынғы қажетті тауарлардың, жұмыстардың, көрсетілетін қызметтердің тізбесін бекіту туралы

"Мемлекеттік сатып алу туралы" Қазақстан Республикасының 2007 жылғы 21 шілдедегі Заңының 13-бабының 3) тармақшасына сәйкес Қазақстан Республикасының Үкіметі ҚАУЛЫ ЕТЕДІ :

1\. Қоса беріліп отырған үздіксіз қызметті қамтамасыз ету үшін тапсырыс берушілер сатып алатын күнделікті немесе апта сайынғы қажетті тауарлардың, жұмыстардың, көрсетілетін қызметтердің тізбесі бекітілсін.

2\. Осы қаулы 2008 жылғы 1 қаңтардан бастап қолданысқа енгізіледі және ресми жариялануға тиіс.

## Үздіксіз қызметті қамтамасыз ету үшін тапсырыс берушілер сатып алатын күнделікті немесе апта сайынғы қажетті тауарлардың, жұмыстардың, көрсетілетін қызметтердің тізбесі

1\. Тамақ өнімдері

2\. Жанар-жағармай материалдары

<a id="p3"></a>

3\. А-4, А-3 форматты "қағаз"

<a id="p4"></a>

4\. Жолдарды қысқы ұстау жөніндегі жұмыстары

<a id="p5"></a>

5\. "Мемлекеттік сатып алу бюллетені" газетін шығару

<a id="p6"></a>

6\. Тамақтануды ұйымдастыру жөніндегі қызметтер

<a id="p7"></a>

7\. Жалғыз және туыссыз қайтыс болған азаматтарды жерлеу жөніндегі қызметтер

<a id="p8"></a>

8\. Монша-кір жуу қызметтерін көрсету жөніндегі қызметтер

<a id="p9"></a>

9\. Автокөлік қызметтері

<a id="p10"></a>

10\. Жол қозғалысын реттеудің техникалық құралдарын орнату, монтаждау, жөндеу және пайдалану жөніндегі қызметтер

<a id="p11"></a>

11\. Әкімшілік ғимараттарды ұстау жөніндегі қызметтер

<a id="p12"></a>

12\. Байланыс қызметтері (оның ішінде Интернет, спутниктік, телефон, фелдъегерлік, почта байланысы)

<a id="p13"></a>

13\. Ақпараттық жүйелерді сүйемелдеу жөніндегі қызметтер

<a id="p14"></a>

14\. Бұқаралық ақпарат құралдарында ақпаратты орналастыру жөніндегі қызметтер

<a id="p15"></a>

15\. Серверлік бөлмелерде өрт сөндіру және кондиционер орнату жүйелеріне техникалық қызмет көрсету жөніндегі қызметтер
