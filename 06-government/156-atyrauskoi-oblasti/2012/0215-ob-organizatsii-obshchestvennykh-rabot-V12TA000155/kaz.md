# Қоғамдық жұмыстарды ұйымдастыру туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Заңының 37 бабын басшылыққа алып, 2001 жылғы 23 қаңтардағы "Халықты жұмыспен қамту туралы" Заңының 7 және 20 баптары, Қазақстан Республикасы Үкіметінің 2001 жылғы 19 маусымдағы № 836 "Халықты жұмыспен қамту туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңын іске асыру жөніндегі шаралар туралы" қаулысы негізінде қалалық әкімдік ҚАУЛЫ ЕТЕДІ:

1\. 1, 2 қосымшаға сәйкес қоғамдық жұмыстар жүргізілетін мекемелердің тізімі мен қоғамдық жұмыстардың түрлері және оған төленетін еңбекақының мөлшері мен оларды қаржыландыру көзі бекітілсін.

2\. Осы қаулының орындалуына бақылау жасау қала әкімінің орынбасары А.С. Қарабаеваға жүктелсін.

3\. Осы қаулы әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

*Қала әкімі М. Исмұратов*

> *Қалалық әкімдіктің*  
> *2012 жылғы 15 ақпандағы № 263*  
> *қаулысына қосымша 1*

## Қоғамдық жұмыстар жүргізілетін мекемелердің тізімі

1\. Атырау облысы әкімінің аппараты,

2\. Атырау облыстық білім беру басқармасы,

3\. Атырау облыстық ішкі саясат бақармасы,

<a id="para_4"></a>

4\. Атырау облыстық денсаулық сақтау басқармасы,

<a id="para_5"></a>

5\. Атырау облысы жұмыспен қамтуды үйлестіру және әлеуметтік бағдарламалар басқармасы,

<a id="para_6"></a>

6\. Атырау облыстық сәулет және қала құрылысы басқармасы,

<a id="para_7"></a>

7\. Атырау облыстық ауыл шаруашылығы басқармасы,

<a id="para_8"></a>

8\. Атырау облысы табиғи ресурстар және табиғатты пайдалануды реттеу басқармасы,

<a id="para_9"></a>

9\. Атырау қаласы әкімінің аппараты,

<a id="para_10"></a>

10\. Атырау қалалық білім бөлімі,

<a id="para_11"></a>

11\. Атырау қалалық жер қатынастары бөлімі,

<a id="para_12"></a>

12\. Атырау қалалық қаржы бөлімі,

<a id="para_13"></a>

13\. Атырау қалалық дене шынықтыру және спорт бөлімі,

<a id="para_14"></a>

14\. Атырау қалалық мәдениет және тілдерді дамыту бөлімі

<a id="para_15"></a>

15\. Атырау қалалық тұрғын–үй коммуналдық шаруашылығы жолаушылар көлігі және автокөлік жолдары бөлімі,

16\. Атырау селолық округі,

<a id="para_17"></a>

17\. Ақсай селолық округі,

<a id="para_18"></a>

18\. Балықшы ауылдық округі,

<a id="para_19"></a>

19\. Геолог селолық округі,

<a id="para_20"></a>

20\. Дамбы селолық округі,

<a id="para_21"></a>

21\. Жұмыскер ауылдық округі,

<a id="para_22"></a>

22\. Еркінқала селолық округі,

<a id="para_23"></a>

23\. Кеңөзек селолық округі,

<a id="para_24"></a>

24\. Қайыршақты селолық округі,

<a id="para_25"></a>

25\. Атырау облыстық прокуратурасы,

<a id="para_26"></a>

26\. Атырау қалалық прокуратурасы,

<a id="para_27"></a>

27\. Атырау облысы бойынша экономикалық қылмысқа және сыбайлас жемқорлыққа қарсы күрес департаменті,

<a id="para_28"></a>

28\. Атырау облысы мамандандырылған табиғат қорғау прокуратурасы,

<a id="para_29"></a>

29\. Атырау облысы көлік прокуратурасы,

<a id="para_30"></a>

30\. Атырау қалалық соты,

<a id="para_31"></a>

31\. Атырау облыстық соты,

<a id="para_32"></a>

32\. Қазақстан Республикасы жоғарғы сотының жанындағы соттардың қызметін қамтамасыз ету департаменті (Қазақстан Республикасы Жоғарғы сотының аппараты) Атырау облыстық сотының кеңсесі,

<a id="para_33"></a>

33\. Атырау облыстық ішкі істер департаменті,

<a id="para_34"></a>

34\. Атырау қалалық ішкі істер бақармасы,

<a id="para_35"></a>

35\. Атырау облыстық Ішкі істер Департаменті көші-қон полиция басқармасы,

<a id="para_36"></a>

36\. Атырау қаласы Ішкі істер басқармасының көші-қон полиция бөлімшесі

<a id="para_37"></a>

37\. Атырау облыстық Ішкі істер департаменті жол полициясы басқармасы,

<a id="para_38"></a>

38\. Атырау облысық Ішкі Істер департаменті ақпараттық-техникалық қызмет басқармасының мекен-жай бюросы,

<a id="para_39"></a>

39\. Атырау қалалық қорғаныс істері жөніндегі басқарма,

<a id="para_40"></a>

40\. Атырау облыстық Әділет департаменті,

<a id="para_41"></a>

41\. Атырау қалалық Әділет басқармасы,

<a id="para_42"></a>

42\. Қазақстан Республикасының Жер ресурстарын басқару жөніндегі агенттігі МЕМЖЕРҒЫЛӨНОРТАЛЫҒЫ Атырау еншілес мемлекеттік кәсіпорны,

<a id="para_43"></a>

43\. Атырау облысы бойынша Салық басқармасы,

<a id="para_44"></a>

44\. Зейнетақы төлеу жөніндегі мемлекеттік орталықтың Атырау облысы бойынша филиалы,

<a id="para_45"></a>

45\. Атырау облысының статистика департаменті,

46\. "Казпошта" Акционерлік қоғамының Атырау облыстық филиалы,

<a id="para_47"></a>

47\. Атырау облысы бойынша Қазынашылық департаменті,

<a id="para_48"></a>

48\. Атырау облысы бойынша бақылау және халықты әлеуметтік қорғау департаменті,

<a id="para_49"></a>

49\. Атырау қаласы бойынша мемлекеттік санитарлық эпидемиялогиялық қадағалау басқармасы,

<a id="para_50"></a>

50\. "Атырау облысы Қазақстан халқы ассамблеясы" хатшылығы,

<a id="para_51"></a>

51\. "Нұр Отан" халықтық демократиялық партиясы қоғамдық бірлестігінің Атырау облыстық филиалы,

<a id="para_52"></a>

52\. "Тарлан Атырау" жастар қоғамдық бірлестігі,

<a id="para_53"></a>

53\. "Ар-честь" газеті мекемесі,

<a id="para_54"></a>

54\. "Ізгілік" қалалық қайырымдылық қоры,

<a id="para_55"></a>

55\. Атырау қалалық мүгедектер қоғамы,

<a id="para_56"></a>

56\. "Мүгедек әлемі" қоғамдық бірлестігі,

<a id="para_57"></a>

57\. Облыстық отбасы үлгісіндегі балалар ауылы және жас өспірімдер үйі,

<a id="para_58"></a>

58\. "Оралман-Жайық" қоғамдық бірлестігі,

<a id="para_59"></a>

59\. "БТА Қазахстан" жинақтаушы зейнетақы қоры,

<a id="para_60"></a>

60\. Қазақ Саңыраулар қоғамының Атыраудағы оқу өндірістік кәсіпорны,

<a id="para_61"></a>

61\. Атырау облысы мемлекеттік мұрағаты,

<a id="para_62"></a>

62\. Атырау қаласы мемлекеттік мұрағаты,

<a id="para_63"></a>

63\. "Арнаулы автобаза" коммуналдық мемлекеттік кәсіпорны,

<a id="para_64"></a>

64\. Табиғи мәдени мұраны қорғау, қалпына келтіру және пайдалану жөніндегі мемлекеттік инспекциясы,

<a id="para_65"></a>

65\. Қалалық білім бөліміне қарасты барлық мектепке дейінгі тәрбие мен білім беру ұйымдары (балабақшалар),

<a id="para_66"></a>

66\. Кәсіптік лицейлер, оқу орталықтары,

<a id="para_67"></a>

67\. Атырау қаласы ағылшын тілін тереңдетіп оқытатын техникалық гимназия,

<a id="para_68"></a>

68\. Атырау облыстық ақыл-есі кеміс балалар интернат-үйі.

> *Ескерту: жыл бойына сұранысқа байланысты мекемелер мен ұйымдар саны өзгеруі мүмкін.*

> *Ескерту. 18 және 21 тармақтарына өзгеріс енгізілді - Атырау қалалық әкімдігінің 04.07.2013 № 703 (алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі) қаулысымен.*
