# 1941-1945 жылдардағы Ұлы Отан соғысындағы Жеңістің 62 жылдық мерекесіне орай Ұлы Отан соғысының қатысушылары мен мүгедектеріне, соғыста қаза болған немесе хабарсыз кеткен жауынгерлердің жесірлеріне біржолғы әлеуметтік көмек көрсету туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы №148-II «Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы» Заңының 31 бабын басшылыққа алып, 1941-1945 жылдардағы Ұлы Отан соғысындағы Жеңістің 62 жылдық мерекесіне орай соғысқа қатысушылар мен мүгедектерді, соғыста қаза болған немесе хабарсыз кеткен жауынгерлердің жесірлерін әлеуметтік қолдау мақсатында аудан әкімияты ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Ұлы Жеңістің 62 жылдық мерекесі құрметіне байланысты аудандығы Ұлы Отан соғысының қатысушылары мен мүгедектеріне әр қайсына 10000 (он мың) теңге,соғыста қағаз болған немесе хабарсыз кеткен жауынгерлердің жесірлеріне әр қайсына 5000 ( бес мың) теңге мөлшерінде бір жолға әлеуметтік көмек көрсетілсін.

<a id="p2"></a>

2. Әлеуметтік көмек осы санаттағы азаматтардың табыс мөлшеріне байланссыз төленсін.

<a id="p3"></a>

3. Аудандық жұмыспен қамту және әлеуметтік бағдарламалар бөлімі (А.Әмірғалиев) аудан бойынша жоғарыда көрсетілген санаттағы адамдардың нақты тізімін шығарып,осы мақсатқа қаралған қаржы есебінен біржолға төлем төлеуді жүзеге асырсын.

<a id="p4"></a>

4. Осы қаулы әділет басқармасынан мемлекеттік тіркеуден өткен сон заңды күшіне еніп,алғаш ресми жариялағаннан кейін,күнтізбелік он күн өткен сон қолданысқа енгізілсін.

<a id="p5"></a>

5. Осы қаулының орындалуын бақылауды өзіме қалдырамын.

**Аудан әкімінің міндетін атқарушы**

**С. Рахимов**
