# Ақмола облысы аумағында карантиндік режимін енгізе отырып карантинді аймағын белгілеу туралы

«Өсімдіктер карантині туралы» 1999 жылғы 11 ақпандағы Қазақстан Республикасының Заңына, «Қазақстан Республикасының аумағын карантиндік объектілерден және бөтен текті түрлерден қорғау жөніндегі қағидаларды бекіту туралы» Қазақстан Республикасы Ауыл шаруашылығы министрінің 2015 жылғы 29 маусымдағы бұйрығына сәйкес, Қазақстан Республикасы Ауыл шаруашылығы министрлігі Агроөнеркәсіптік кешендегі мемлекеттік инспекция комитеті Ақмола облыстық аумақтық инспекциясының 2020 жылғы 29 сәуірдегі № 03-06-315 ұсынымының негізінде, Ақмола облысының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Осы қаулының 1-қосымшасына сәйкес залалданған алқаптардың көлемінде, карантиндік арамшөп – жатаған (қызғылт) укекіре бойынша Ақмола облысы аумағында карантиндік режимін енгізе отырып карантинді аймақ белгіленсін.

<a id="p2"></a>

2. Осы қаулының 2-қосымшасына сәйкес залалданған алқаптардың көлемінде, карантиндік арамшөп – далалық арамсояу бойынша Ақмола облысы аумағында карантиндік режимін енгізе отырып карантинді аймақ белгіленсін.

<a id="p3"></a>

3. Осы қаулының 3-қосымшасына сәйкес залалданған алқаптардың көлемінде, орманның карантиндік зиянкесі – жұпсыз жібек көбелегі бойынша Ақмола облысы аумағында карантиндік режимін енгізе отырып карантинді аймақ белгіленсін.

<a id="p4"></a>

4. Осы қаулының 4-қосымшасына сәйкес Ақмола облысы әкімдігінің кейбір қаулыларының күші жойылды деп танылсын.

<a id="p5"></a>

5. Осы қаулының орындалуын бақылау Ақмола облысы әкімінің орынбасары Ғ.К. Әбдіхалықовқа жүктелсін.

<a id="p6"></a>

6. Осы қаулы Ақмола облысының Әділет департаментінде мемлекеттік тіркелген күннен бастап күшіне енеді және ресми жарияланған күннен бастап қолданылысқа енгізіледі.

## Ақмола облысы әкімдігінің күші жойылды деп танылған, кейбір қаулыларының тізбесі

<a id="an3_p1"></a>

1. Ақмола облысы әкімдігінің «Ақмола облысының аумағында карантин режимін енгізе отырып, карантин аймағын белгілеу туралы» 2014 жылғы 27 ақпандағы № А-3/61 қаулысы (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 4080 болып тіркелген, 2014 жылғы 20 тамызында «Әділет» ақпараттық-құқықтық жүйесінде жарияланған).

<a id="an3_p2"></a>

2. Ақмола облысы әкімдігінің «Ақмола облысының аумағында карантин режимін енгізе отырып, карантин аймағын белгілеу туралы» 2017 жылғы 1 маусымдағы № A-6/233 қаулысы (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 6008 болып тіркелген, 2017 жылғы 13 шілдеде Қазақстан Республикасы нормативтік құқықтық актілерінің электрондық түрдегі эталондық бақылау банкінде жарияланған).

<a id="an3_p3"></a>

3. Ақмола облысы әкімдігінің «Ақмола облысының аумағында карантин режімін енгізе отырып, карантин аймағын белгілеу туралы» Ақмола облысы әкiмдiгiнiң 2014 жылғы 27 ақпандағы № А-3/61 қаулысына өзгерістер енгізу туралы» 2017 жылғы 1 маусымдағы № А-6/234 қаулысы (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 6009 болып тіркелген, 2017 жылғы 13 шілдеде Қазақстан Республикасы нормативтік құқықтық актілерінің электрондық түрдегі эталондық бақылау банкінде жарияланған).

<a id="an3_p4"></a>

4. Ақмола облысы әкімдігінің «Ақмола облысының аумағында карантин режимін енгізе отырып, карантин аймағын белгілеу туралы» Ақмола облысы әкiмдiгiнiң 2014 жылғы 27 ақпандағы № А-3/61 қаулысына өзгеріс енгізу туралы» 2018 жылғы 18 шілдедегі № А-7/318 қаулысы (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 6752 болып тіркелген, 2018 жылғы 16 тамызында Қазақстан Республикасы нормативтік құқықтық актілерінің электрондық түрдегі эталондық бақылау банкінде жарияланған).
