# Об установлении публичного сервитута товариществу с ограниченной ответственностью «Темиртас-Холдинг»

В соответствии с Земельным кодексом Республики Казахстан, Законом Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», на основании лицензии на разведку твердых полезных ископаемых № 414-EL от 22 ноября 2019 года, акимат Ерейментауского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Установить товариществу с ограниченной ответственностью «Темиртас-Холдинг» публичный сервитут без изъятия земельного участка у землепользователя сроком до 22 ноября 2030 года для проведения разведки твердых полезных ископаемых на территории Ерейментауского района согласно приложению к настоящему постановлению.

<a id="p2"></a>

2. Товариществу с ограниченной ответственностью «Темиртас-Холдинг»

   1) соблюдать требования законодательства Республики Казахстан при использовании земельного участка для проведения разведки твердых полезных ископаемых;

   2) по окончании работ, привести нарушенные земельные участки в состояние пригодное для дальнейшего использование по целевому назначению.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на курирующего заместителя акима района.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
