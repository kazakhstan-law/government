# Об установлении публичного сервитута товариществу с ограниченной ответственностью «NFS Central Asia LTD»

В соответствии с Земельным кодексом Республики Казахстан, Законом Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», на основании лицензии на разведку твердых полезных ископаемых № 4273-EL от 09 апреля 2026 года, акимат Ерейментауского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Установить товариществу с ограниченной ответственностью «NFS Central Asia LTD» публичный сервитут без изъятия земельного участка у землепользователя сроком до 09 апреля 2032 года для проведения разведки твердых полезных ископаемых на территории Ерейментауского района согласно приложению к настоящему постановлению.

<a id="p2"></a>

2. Товариществу с ограниченной ответственностью «NFS Central Asia LTD»

   1) соблюдать требования законодательства Республики Казахстан при использовании земельного участка для проведения разведки твердых полезных ископаемых;

   2) по окончании работ, привести нарушенные земельные участки в состояние пригодное для дальнейшего использование по целевому назначению.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на курирующего заместителя акима района.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
