# Біржан сал ауданының бюджет шығыстарының басым бағыттарының тізбесін анықтау туралы

«Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңына, Қазақстан Республикасы Қаржы министрінің 2025 жылғы 27 маусымдағы № 328 бұйрығымен бекітілген (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 211793 болып тіркелген) Бюджетті қазынашылық атқару және оған кассалық қызмет көрсету, қазынашылық есепке алу және мониторинг жүргізу рәсімдерінің 228-тармағына сәйкес, Біржан сал ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="para_1"></a>

1. Біржан сал ауданының бюджет шығыстарының басым бағыттарының тізбесі осы қаулының қосымшасына сәйкес анықталсын.

<a id="para_2"></a>

2. «Біржан сал ауданының бюджет шығыстарының басым бағыттарының тізбесін анықтау туралы» Биржан сал ауданы әкімдігінің 2018 жылғы 28 наурыздағы № а-3/127 (Нормативтік құқықтық актілерді тіркеудің мемлекеттік тізілімінде № 120587 тіркелген) қаулысының күші жойылды деп танылсын.

<a id="para_3"></a>

3. Осы қаулының орындалуын бақылау Біржан сал ауданы әкімінің орынбасары Е.М. Хасеновке жүктелсін.

<a id="para_4"></a>

4. Осы қаулы ресми жарияланған күнінен бастап күшіне енеді және қолданысқа енгізіледі..

## Біржан сал ауданының бюджет шығыстарының басым бағыттарының ТІЗБЕСІ

<a id="annex_1__para_1"></a>

1. Қазақстан Республикасы Үкіметінің борыштық міндеттемелерін өтеу және оларға қызмет көрсету жөніндегі төлемдер;

<a id="annex_1__para_2"></a>

2. Зейнетақылар, жәрдемақылар және басқа да әлеуметтік төлемдер;

<a id="annex_1__para_3"></a>

3. Жалақы және басқа да ақшалай төлемдер, оның ішінде штаттан тыс техникалық персоналдың жалақысы және жалақыдан барлық ұстап қалулар;

<a id="annex_1__para_4"></a>

4. Қазақстан Республикасының заңнамалық актілерінде көзделген ақшалай өтемақылар;

<a id="annex_1__para_5"></a>

5. Алименттер;

<a id="annex_1__para_6"></a>

6. Міндетті зейнетақы жарналары, жұмыс берушілердің міндетті зейнетақы жарналары, кәсіптік және ерікті зейнетақы жарналары, әлеуметтік аударымдар, міндетті әлеуметтік медициналық сақтандыру аударымдар және (немесе) жарналар;

<a id="annex_1__para_7"></a>

7. Тұрғын үй төлемдері;

<a id="annex_1__para_8"></a>

8. Жеке тұлғаларға трансферттер;

<a id="annex_1__para_9"></a>

9. Стипендиялар;

<a id="annex_1__para_10"></a>

10. Банк қызметтеріне ақы төлеу;

<a id="annex_1__para_11"></a>

11. Бюджеттік субвенциялар;

<a id="annex_1__para_12"></a>

12. Салық пен бюджетке төленетін басқа да міндетті төлемдер.
