# Об установлении публичного сервитута товариществу с ограниченной ответственностью «Баракат Майнинг»

В соответствии с Земельным кодексом Республики Казахстан, Законом Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», на основании лицензии на разведку твердых полезных ископаемых № 3386-EL от 19 июня 2025 года, акимат Ерейментауского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Установить товариществу с ограниченной ответственностью «Баракат Майнинг» публичный сервитут без изъятия земельного участка у землепользователя сроком до 19 июня 2031года для проведения разведки твердых полезных ископаемых на территории Ерейментауского района согласно приложению к настоящему постановлению.

<a id="p2"></a>

2. Товариществу с ограниченной ответственностью «Баракат Майнинг»

   1) соблюдать требования законодательства Республики Казахстан при использовании земельного участка для проведения разведки твердых полезных ископаемых;

   2) по окончании работ, привести нарушенные земельные участки в состояние пригодное для дальнейшего использование по целевому назначению.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на курирующего заместителя акима района.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
