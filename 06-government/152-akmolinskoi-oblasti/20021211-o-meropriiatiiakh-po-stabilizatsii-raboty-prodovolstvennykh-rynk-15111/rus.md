# О мероприятиях по стабилизации работы продовольственных рынков города Кокшетау

> *Сноска. Утратило силу постановлением акимата Акмолинской области от 28.02.2004 № а-2/80.*

В соответствии с Законами Республики Казахстан «О санитарно-эпидемиологическом благополучии населения», «О местном государственном управлении в Республике Казахстан», «Об охране здоровья граждан в Республике Казахстан» в целях стабилизации работы продовольственных рынков города Кокшетау акимат области постановил:

1. Утвердить прилагаемые мероприятия по стабилизации работы продовольственных рынков города Кокшетау.

2. Руководителям государственных учреждений, предприятий и организаций, ответственных за исполнение санитарно-гигиенических, санитарно-ветеринарных, противопожарных мероприятий, мероприятий по соблюдению архитектурно-градостроительных норм, по государственному надзору за стандартами, единством измерений и сертификации, по соблюдению земельного законодательства принять все необходимые меры по стабилизации работы продовольственных рынков.

3. Ответственным за исполнение мероприятий по стабилизации работы продовольственных рынков города Кокшетау информировать 25 числа последнего месяца каждого квартала Акмолинскую областную санитарно-эпидемиологическую станцию о выполнении мероприятий.

4. Акмолинской областной санитарно-эпидемиологической станции ежеквартально предоставлять обобщенную информацию о выполнении мероприятий заместителю акима области Джалмагамбетовой С.Ж.

5. Контроль за исполнением настоящего постановления возложить на заместителя акима области Джалмагамбетову С.Ж.
