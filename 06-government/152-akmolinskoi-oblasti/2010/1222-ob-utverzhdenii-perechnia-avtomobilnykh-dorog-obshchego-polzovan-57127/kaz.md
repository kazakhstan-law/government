# Облыстық маңызы бар жалпы қолданыстағы автомобиль жолдарының тізбесін бекіту туралы

«Автомобиль жолдары туралы» Қазақстан Республикасының 2001 жылғы 17 шілдедегі Заңына сәйкес, облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Облыстық маңызы бар жалпы қолданыстағы автомобиль жолдарының тізбесі бекітілсін.

<a id="p2"></a>

2. Аудандардың, Көкшетау және Степногорск қалаларының әкімдіктері осы қаулыдан туындайтын шараларды қолдансын.

<a id="p3"></a>

3. Осы қаулының орындалуын бақылау облыс әкімінің орынбасары Қ.Қ. Айтмұхаметовке жүктелсін.

<a id="p4"></a>

4. Осы қаулы Ақмола облысының Әділет департаментінде мемлекеттік тіркелген күнінен бастап күшіне енеді және ресми жарияланған күнінен бастап қолданысқа енгізіледі.
