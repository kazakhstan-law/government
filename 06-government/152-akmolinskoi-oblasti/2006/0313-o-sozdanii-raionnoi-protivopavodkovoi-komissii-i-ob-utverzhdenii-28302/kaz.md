# 2006 жылғы көктемгі су тасуға қарсы аудандық комиссия құру және тасқын суды өткізу жөніндегі іс-шараларды бекіту туралы

Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы» Заңына, Қазақстан Республикасының «Төтенше жағдайлардың табиғи және техногендік сипаты туралы» Заңына сәйкес, 2006 жылғы көктемгі су тасқынын апатсыз, ұйымшылдықпен өткізуге және мүмкін болатын су тасуға қарсы тұру мақсатында, аудан әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Су тасқынына қарсы аудандық комиссия құрылсын (қосымша 1).

<a id="p2"></a>

2. Ақкөл ауданының аумағында 2006 жылғы көктемгі су тасқыны, дайындықпен және апатсыз өткізу жөніндегі іс-шаралар бекітілсін (қосымша 2).

<a id="p3"></a>

3. Қалалық, селолық округгер мен село әкімдері, көктемгі су тасқынына қарсы тұру жөніндегі барлық дайындық жұмыстарының дер мерзімде орындалуға бағытталған іс-шараларын әзірлеп аудандық комиссияға тапсырсын.

<a id="p4"></a>

4. Аудан әкімдігінің қаулысы Ақкөл аудандық әділет Басқармасына мемлекеттік тіркеуге жіберілсін және бұқаралық ақпарат құралдарында жариялануға тиіс.

<a id="p5"></a>

5. Аудан әкімдігінің 2005 жылғы 11 наурыздағы № а-3/74 «Су тасуға қарсы аудандық комиссия құру туралы» қаулысы күшін жойғандығы танылсын.

<a id="p6"></a>

6. Осы қаулының орындалуын бақылау аудан әкімінің орынбасары А.П.Лиге жүктелсін.
