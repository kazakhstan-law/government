# Об определении места для размещения агитационных печатных материалов кандидатов в депутаты Мажилиса Парламента Республики Казахстан, маслихата области, района

В соответствии с п.6 ст.28 Конституционного Закона Республики Казахстан «О выборах в Республике Казахстан», Законом Республики Казахстан «О местном государственном управлении в Республике Казахстан», в целях определения места для размещения агитационных материалов для всех кандидатов акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить места для размещения предвыборных агитационных материалов кандидатов в депутаты Мажилиса, парламента Республики Казахстан, маслихата Аршалынского района.

<a id="p2"></a>

2. Акимам сельских округов и п. Аршалы подготовить стенды, щиты, тумбы для размещения агитационных предвыборных печатных изданий.

<a id="p3"></a>

3. Признать утратившим силу ранее принятое постановление акимата района № 24 от 22 февраля 2006 года «Об определении места для размещения агитационных материалов».

<a id="p4"></a>

4. Данное постановление вступает в силу после регистрации в управлении юстиции Аршалынского района и вводится в действие со дня официального опубликования.

<a id="p5"></a>

5. Контроль за исполнением данного постановления возложить на заместителя Акима Мамбетова Талгата Жанабергеновича.
