# Об определении мест для размещения агитационных печатных материалов и предоставлении помещений для проведения встреч с изберателями кандидатов в Президенты Республики Казахстан на территории Айыртауского района

В соответствии с пунктами 4,6 статьи 28 Конституционного закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан», акимат Айыртауского района Северо-Казахстанской области ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить совместно районной территориальной избирательной комиссии места для размещения агитационных печатных материалов для всех кандидатов в Президенты Республики Казахстан на территории Айыртауского района согласно приложению 1.

<a id="p2"></a>

2. Предоставить помещения на договорной основе для проведения встреч кандидатов в Президенты Республики Казахстан с избирателями в Айыртауском районе согласно приложению 2.

<a id="p3"></a>

3. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
