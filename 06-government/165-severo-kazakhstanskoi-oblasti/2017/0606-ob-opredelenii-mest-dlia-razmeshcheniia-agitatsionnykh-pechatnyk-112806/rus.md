# Об определении мест для размещения агитационных печатных материалов и предоставлении помещений для проведения встреч с выборщиками кандидатов в депутаты Сената Парламента Республики Казахстан

В соответствии с пунктами 4, 6 статьи 28 Конституционного закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан», акимат Тимирязевского района Северо-Казахстанской области ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить совместно с Тимирязевской районной избирательной комиссией (по согласованию) место для размещения агитационных печатных материалов для всех кандидатов в депутаты Сената Парламента Республики Казахстан, согласно приложению 1.

<a id="p2"></a>

2. Предоставить на договорной основе помещение для проведения встреч с выборщиками всем кандидатам в депутаты Сената Парламента Республики Казахстан, согласно приложению 2.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на исполняющего обязанности руководителя аппарата акима Тимирязевского района Северо-Казахстанской области Ищанову В.Б.

<a id="p4"></a>

4. Настоящее постановление вводится в действие со дня его первого официального опубликования.
