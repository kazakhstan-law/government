# Солтүстік Қазақстан облысы Мамлют ауданының бюджеті шығыстарының басым бағыттарын айқындау туралы

«Бюджеттің атқарылуы және оған кассалық қызмет көрсету ережесін бекіту туралы» Қазақстан Республикасы Қаржы министрінің 2014 жылғы 4 желтоқсандағы № 540 бұйрығымен бекітілген, бюджеттің атқарылуы және оған кассалық қызмет көрсету ережесінің 213 тармағына сәйкес (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 9934 болып тіркелген) Солтүстік Қазақстан облысы Мамлют ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Осы қаулының қосымшасына сәйкес Солтүстік Қазақстан облысы Мамлют ауданы бюджетінің басым шығыстары айқындалсын.

<a id="p2"></a>

2. Осы қаулының орындалуын бақылау Солтүстік Қазақстан облысы Мамлют ауданы әкімінің жетекшілік ететін орынбасарына жүктелсін.

<a id="p3"></a>

3. Осы қаулы қол қойылған күнінен бастап қолданысқа енгізіледі.

**Мамлют ауданының әкімі**

**Е. Степаненко**

> *Солтүстік Қазақстан облысы*  
> *Мамлют ауданы әкімдігінің*  
> *2024 жылғы 24 маусымдағы*  
> *№ 180 қаулысына қосымша*

## Солтүстік Қазақстан облысы Мамлют ауданының бюджеті шығыстарының басым бағыттары

<a id="an0_p1"></a>

1. Қаражаттың факт жүзінде түсуі бойынша Қазақстан Республикасының Ұлттық қорынан бөлінген қаражат есебінен қаржыландырылатын шығыстар.

<a id="an0_p2"></a>

2. Бюджеттік субвенциялар.

<a id="an0_p3"></a>

3. Қаражаттың факт жүзінде түсуі бойынша республикалық бюджеттен берілетін нысаналы трансферттер есебінен қаржыландырылатын шығыстар.

<a id="an0_p4"></a>

4. Қаражаттың факт жүзінде түсуі бойынша облыстық бюджеттен берілетін нысаналы трансферттер есебінен қаржыландырылатын шығыстар.

<a id="an0_p5"></a>

5. Борыштық міндеттемелерді өтеу және қызмет көрсету бойынша төлемдер.

<a id="an0_p6"></a>

6. Жалақыны және басқа да ақшалай төлемдерді төлеу, оның ішінде штаттан тыс техникалық персоналдың жалақысы және жалақыдан барлық ұстап қалулар, Қазақстан Республикасының заңнамалық актілерінде көзделген ақшалай өтемақылар.

<a id="an0_p7"></a>

7. Бюджетке төленетін салық төлемдері.

<a id="an0_p8"></a>

8. Жәрдемақылар және басқа да әлеуметтік төлемдер.

<a id="an0_p9"></a>

9. Тамақтандыруды ұйымдастыру және азық-түлік сатып алу бойынша қызметтер.

<a id="an0_p10"></a>

10. Дәрі-дәрмек сатып алу.

<a id="an0_p11"></a>

11. Банктік қызметтерге ақы төлеу.

<a id="an0_p12"></a>

12. Субсидиялар.

<a id="an0_p13"></a>

13. Атқарушылық құжаттар мен сот актілерін орындау.

<a id="an0_p14"></a>

14. Іссапар және қызметтік жол жүрулер.

<a id="an0_p15"></a>

15. Отын сатып алуға арналған шығыстар (ғимараттарды жылыту бөлігінде).

<a id="an0_p16"></a>

16. Коммуналдық қызметтерге, байланыс қызметтеріне, ғимараттарды жалға алуға ақы төлеу.

<a id="an0_p17"></a>

17. Аудандық бюджеттен берілетін нысаналы трансферттерді аудару.

<a id="an0_p18"></a>

18. Жанар-жағармай материалдарын сатып алу.

<a id="an0_p19"></a>

19. Бюджеттік бағдарлама әкімшілерінің шығыстары.

<a id="an0_p20"></a>

20. Міндетті зейнетақы жарналары, ерікті зейнетақы жарналары.

    Қалған төлемдер шоттардың төлемге түсу кезектілігі тәртібімен жүргізіледі.
