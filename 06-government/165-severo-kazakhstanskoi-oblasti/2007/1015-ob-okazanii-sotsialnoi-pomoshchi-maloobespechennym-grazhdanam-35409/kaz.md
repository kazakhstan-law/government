# Аз қамтамасыз етілген азаматтарға әлеуметтік көмек көрсету туралы

"Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы N 148 Заңы 27-бабы 1-тармағы 17) тармақшасына, "Ең төмен күнкөріс деңгейі туралы" Қазақстан Республикасының 1999 жылғы 16 қарашадағы N 474-1 Заңы 4-бабы 3-тармағына сәйкес облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

> *Ескерту. Кіріспе жаңа редакцияда - СҚО әкімдігінің 2009.06.26 N 171 Қаулысымен*

<a id="p1"></a>

1. Жан басына шаққанда орташа айлық табысы облыста белгіленген кедейлік шегінен төмен аз қамтамасыз етілген азаматтарға айлық есептік көрсеткіштің бір проценті мөлшерінде әлеуметтік көмек көрсетілсін.

   > *Ескерту. 1-тармаққа өзгерту енгізілді - СҚО әкімдігінің 2007.12.12 N 290 Қаулысымен*

<a id="p2"></a>

2. Әлеуметтік көмек осы мақсаттарға бөлінген қаражаттандыру шегінде жергілікті бюджет қаражаты есебінен ай сайын ақшалай нысанда көрсетіледі.

   > *Ескерту. 2-тармаққа өзгерту енгізілді - СҚО әкімдігінің 2009.06.26 N 171 Қаулысымен*

<a id="p3"></a>

3. Аудандар мен Петропавл қаласының әкімдері:

   аз қамтамасыз етілген азаматтарға әлеуметтік көмек көрсетуге қаржы бөлуді көздесін;

   аз қамтамасыз етілген азаматтарға тоқсан сайын әлеуметтік көмек тағайындауды және ай сайын төлеуді ұйымдастыруды қамтамасыз етсін.

   > *Ескерту. 3-тармаққа өзгерту енгізілді - СҚО әкімдігінің 2007.12.12 N 290 Қаулысымен*

<a id="p4"></a>

4. Осы қаулының орындалуын бақылау облыс әкімінің бірінші орынбасары Ж.А. Смаиловқа жүктелсін.

   > *Ескерту. 4-тармаққа өзгерту енгізілді - СҚО әкімдігінің 2009.06.26 N 171 Қаулысымен*

<a id="p5"></a>

5. Осы қаулы алғаш ресми жарияланған күнінен бастап он күнтізбелік күн өткеннен кейін қолданысқа енгізіледі.

   *Облыс әкімі*
