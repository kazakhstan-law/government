# Об определении мест для размещения агитационных печатных материалов и помещений для проведения встреч кандидатов в Президенты Республики Казахстан с избирателями на территории района имени Габита Мусрепова Северо-Казахстанской области

В соответствии с пунктом 3 статьи 27, пунктами 4, 6 статьи 28 Конституционного закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан», акимат района имени Габита Мусрепова Северо-Казахстанской области ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить места для размещения агитационных печатных материалов для кандидатов в Президенты Республики Казахстан на территории района имени Габита Мусрепова Северо-Казахстанской области согласно приложению 1.

<a id="p2"></a>

2. Предоставить на договорной основе помещения для проведения встреч всем кандидатам в Президенты Республики Казахстан с избирателями на территории района имени Габита Мусрепова Северо-Казахстанской области согласно приложению 2.

<a id="p3"></a>

3. Акимам сельских округов оснастить определенные места для размещения агитационных печатных материалов стендами, щитами и тумбами.

<a id="p4"></a>

4. Контроль за исполнением настоящего постановления возложить на исполняющего обязанности руководителя аппарата акима района имени Габита Мусрепова Северо-Казахстанской области.

<a id="p5"></a>

5. Настоящее постановление вводится в действие с момента его первого официального опубликования.

**Аким района имени Габита Мусрепова Северо-Казахстанской области**
