# Об определении мест для размещения агитационных печатных материалов и предоставлении помещения для встреч с выборщиками кандидатов в депутаты Сената Парламента Республики Казахстан

> *Сноска. Утратило силу постановлением акимата Тайыншинского района Северо-Казахстанской области от 24.12.2014 № 656.*

В соответствии с пунктами 4, 6 статьи 28 Конституционного закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан» акимат Тайыншинского района Северо-Казахстанской области ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить совместно с Тайыншинской районной избирательной комиссией места для размещения агитационных печатных материалов для всех кандидатов в депутаты Сената Парламента Республики Казахстан, согласно приложению 1.

<a id="p2"></a>

2. Предоставить на договорной основе помещение для проведения встреч с выборщиками всем кандидатам в депутаты Сената Парламента Республики Казахстан, согласно приложению 2.

<a id="p3"></a>

3. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
