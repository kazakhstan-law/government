# Петропавл қаласында Қазақстан Республикасы Парламенті Сенатының депутаттығына кандидаттардың сайлаушылармен кездесуіне үй-жай беруге және үгіттік баспа материалдарын орналастыруға арналған орындар белгілеу туралы

> *Ескерту. Қолданылу мерзімінің өтуіне байланысты күші жойылды (Солтүстік Қазақстан облысы Петропавл қаласы әкімі аппаратының 11.12.2014 № 16-1.-3-19/2830 хаты)*

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық заңы 28-бабының 4, 6-тармақтарына сәйкес Солтүстік Қазақстан облысы Петропавл қаласының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Петропавл қаласында Қазақстан Республикасы Парламенті Сенатының депутаттығына кандидаттардың үгіттік баспа материалдарын орналастыруға орындар белгіленсін, қосымшаға сәйкес.

<a id="p2"></a>

2. Қазақстан Республикасы Парламенті Сенатының депутаттығына кандидаттардың Петропавл қаласы бойынша сайлаушылармен кездесуі үшін шарт негізінде Қаныш Сәтбаев атындағы көше, 37 мекенжайында орналасқан «Қалалық мәдениет үйі» мемлекеттік коммуналдық қазыналық кәсіпорны үй-жайы берілсін.

<a id="p3"></a>

3. Осы қаулының орындалуын бақылау қала әкімінің орынбасары Е.С. Баллоға жүктелсін.

<a id="p4"></a>

4. Осы қаулы оны бірінші ресми жарияланған күнінен бастап қолданысқа енгізіледі.
