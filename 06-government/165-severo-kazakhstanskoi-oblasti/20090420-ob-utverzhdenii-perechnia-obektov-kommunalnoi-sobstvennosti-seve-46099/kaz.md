# 2009 жылы жекешелендіруге жататын Солтүстік Қазақстан облысы коммуналдық меншік объектілерінің тізбесін бекіту туралы

> *Ескерту. Қолданылу мерзімінің өтуіне байланысты күші жойылды (Солтүстік Қазақстан облысы әкімі аппаратының 01.07.2015 № 1.14-7/1840 хаты).*

«Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы № 148 Заңы 27 бабы 1-тармағы 2) тармақшасына сәйкес облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

1. 2009 жылы жекешелендіруге жататын Солтүстік Қазақстан облысы коммуналдық меншік объектілерінің қоса берілген тізбесі бекітілсін.

2. Осы қаулының орындалуын бақылау облыс әкімінің орынбасары А.М.Чженге жүктелсін.

3. Осы қаулы алғаш ресми жарияланған күннен он күнтізбелік күн өткеннен кейін қолданысқа енгізіледі.

**Облыс әкімі**

**С. Біләлов**

> *Облыс әкімдігінің*  
> *2009 ж.20 сәуірдегі N 101*  
> *қаулысымен бекітілді*

# 2009 жылы жекешелендіруге жататын Солтүстік Қазақстан облысының коммуналдық меншік нысандарының тізімі

> *Ескерту. Қосымшаға өзгерту енгізілді - Солтүстік Қазақстан облыстық әкімдігінің 2009.10.27 № 285 Қаулысымен*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`t001-r001`](kaz/t001-r001.md) | `!` таблица 1, строки 1–326 |
| [`t001-r002`](kaz/t001-r002.md) | `!` таблица 1, строки 327–602 |
| [`t001-r003`](kaz/t001-r003.md) | `!` таблица 1, строки 603–883 |
| [`t001-r004`](kaz/t001-r004.md) | таблица 1, строки 884–949 |
| [`part005`](kaz/part005.md) | part005 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
