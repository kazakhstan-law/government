# О проведении приписки граждан призывному участку

В соответствии со статьями 17, 18 Закона Республики Казахстан «О воинской обязанности и воинской службе», постановлением Правительства Республики Казахстан от 5 мая 2006 года № 371 «Об утверждении Правил о порядке ведения воинского учета военнообязанных и призывников в Республике Казахстан», акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Провести приписку граждан, родившихся в 1990 году и старших возрастов, ранее не прошедших приписку, к призывному участку в январе-марте 2007 года.

<a id="p2"></a>

2. Для проведения приписки к призывному участку создать комиссию по приписке с резервным составом:

   Председатель комиссии - Начальник Отдела по делам обороны Кызылжарского района Мусаев Канатбек Умирбекович

   Заместитель председателя комиссии - Заместитель акима Кызылжарского района Молдагулов Артур Кенжеакимович

   Члены комиссии:

   - заместитель начальника Кызылжарского районного отдела внутренних дел Жамартов Иманбай Капышевич.

   - старший врач медицинской комиссии подростковый врач - терапевт Садвокасова Кама Ашуовна.

   Секретарь комиссии - медицинская сестра подросткового кабинета Мамбетова Любовь Николаевна

   В случае необходимости использовать соответствующего специалиста из следующего резервного состава комиссии по приписке:

   Председатель комиссии - Начальник отделения набора военнослужащих по контракту и призыва Отдела по делам обороны Кызылжарского района Хорошенко Андрей Борисович

   Заместитель председателя комиссии - Заместитель акима Кызылжарского района Колышпаев Туяк Каирбекович

   Члены комиссии:

   - заместитель начальника Кызылжарского районного отдела внутренних дел Мейманов Кайрат Темиргалиевич.

   - заместитель главного врача центральной районной больницы Богданов Владимир Юрьевич

<a id="p3"></a>

3. Акимам сельских округов обеспечить своевременную явку граждан на призывной участок.

<a id="p4"></a>

4. Для качественного медицинского освидетельствования призываемых граждан рекомендовать главному врачу Кызылжарской центральной районной больницы Ко А.Я. (по согласованию):

   обеспечить снабжение медицинской комиссии необходимым инструментарием в соответствии с требованием Правил военно-врачебной экспертизы в Вооруженных Силах, других войсках и воинских формированиях Республики Казахстан;

   обеспечить медицинское обслуживание и лечение выявленных больных граждан, подлежащих приписке, с выделением необходимого количества койко-мест для их стационарного обследования.

<a id="p5"></a>

5. Начальнику Кызылжарского районного отдела внутренних дел Мизамбаеву Е.А.:

   в период приписки граждан к призывному участку обеспечить поддержание общественного порядка на призывном участке, выделить на указанный период работника полиции, по заявке Отдела по делам обороны, производить розыск, задержание лиц, уклоняющихся от выполнения воинской обязанности.

<a id="p6"></a>

6. Рекомендовать начальнику Отдела по делам обороны района Кызылжарского района Мусаеву К.У. (по согласованию) использовать служебный легковой автомобиль Отдела по делам обороны для проверки состояния учета призывников в организациях, на которых возложено ведение далекого учета призывников.

<a id="p7"></a>

7. Начальнику государственного учреждения «Кызылжарский районный отдел финансов» Айткужановой А.М. обеспечить своевременное финансирование проведения приписки граждан к приписному участку согласно смете расходов.

<a id="p8"></a>

8. Руководителю государственного учреждения «Аппарат акима Кызылжарского района» Даровику Н.В.:

   произвести оплату медицинским учреждениям за проведенное медицинское освидетельствование, согласно запланированной сметы расходов;

   для доставки граждан, подлежащих приписке, с населенных пунктов района использовать автобус, предоставленный для этих целей Отделом по делам обороны Кызылжарского района;

   на время проведения приписки граждан к призывному участку для материально-технического обеспечения приписки принять на работу делопроизводителей в количестве 4 единиц, водителя автобуса, предоставленного Отделом по делам обороны, уборщицу помещения, в котором производится комиссия по приписке граждан к призывному участку.

<a id="p9"></a>

9. Комиссию по приписке провести в здании Отдела по делам обороны.

<a id="p10"></a>

10. Утвердить прилагаемый график проведения приписки граждан к призывному участку.

<a id="p11"></a>

11. Контроль за выполнением настоящего постановления возложить на заместителя акима района Молдагулова А.К.

<a id="p12"></a>

12. Настоящее постановление вводится в действие с момента его регистрации в органах юстиции.
