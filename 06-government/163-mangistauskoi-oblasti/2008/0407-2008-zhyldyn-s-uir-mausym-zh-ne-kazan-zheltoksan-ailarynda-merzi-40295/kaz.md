# 2008 жылдың сәуір-маусым және қазан-желтоқсан айларында мерзімді әскери қызметке кезекті шақыруды өткізу туралы

ҚР «Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы» 23.01.2001 жылғы, «Әскери міндеттілік және әскери қызмет туралы» 08.07.2005 жылғы Заңын және Қазақстан Республикасы Президентінің «Белгіленген әскери қызмет мерзімін өткерген мерзімді әскери қызметтегі әскери қызметшілерді запасқа шығару және Қазақстан Республикасының азматтарын, 2008 жылдың сәуір-маусымында кезекті мерзімді әскери қызметке шақыру туралы» 31.03.2008 жылдың №563 санды Жарлығына сәйкес, 2008 жылдың сәуір-маусым және қазан-желтоқсан айларында азаматтардың мерзімді әскери қызметке уақытылы шақырылуын қамтамасыз ету мақсатында, аудан әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. 2008 жылдың сәуір-маусым және қазан-желтоқсан айларына 18-ден 27 жасқа толған әскери қызметке шақыруын кейінге қалдыру құқығы жоқ ер азаматтарды мерзімді әскери қызметке шақырылуы жүргізілсін.

<a id="p2"></a>

2. Төмендегі құрамда аудандық әскерге шақыру комиссиясы құрылсын:

```
Сүйеубаев Қуаныш Жұмабекұлы              – комиссия төрағасы, аудандық қорғаныс
                                           істері жөніндегі бөлім бастығы,
Төреева Қаным Қыдырбайқызы               – комиссия төрағасының орынбасары, аудан
                                           әкім аппаратының бас маманы,
Комиссия мүшелері
Биманов Серікқали Тәжіғалиұлы            – аудандық ішкі істер бөлімі бастығының
                                           орынбасары (келісім бойынша)
Шалабаева Гүлшат Бақытқызы               – аудандық емхананың бас дәрігері,
                                           медициналық комиссиясының төрайымы
                                           (келісім бойынша)
Алекеева Бағила Жиғанғалиқызы            – комиссия хатшысы, денсаулық нығайту
                                           орталығының мейірбикесі (келісім бойынша).
```

<a id="p3"></a>

3. Шақыру комиссиясының төрағасының орынбасары Қ.Төреева село, поселке әкімдері, ішкі істер қызметкерлерін аудандық емхананың бас дәрігерін шақыруға қатысты кәсіпорын, мекеме басшыларын қатыстыра отырып, нұсқаулау-ұйымдастыру кеңесін өткізу тапсырылсын.

<a id="p4"></a>

4. Аудандық емхананың бас дәрігері Г.Шалабаева аудандық медициналық комиссиясының қалыпты жұмыс жасауын қамтамасыз ету үшін Түпқараған ауданының қорғаныс істер жөніндегі бөлімінің тапсырысы бойынша жеткілікті мөлшерлерде бұрын шақыру комиссиясының құрамында жұмыс тәжірибесі бар маман дәрігерлермен, құралдармен, желеңдермен қамтамасыз етсін. Жалғанды: / қосымша № 1/

<a id="p5"></a>

5. Аудандық ішкі істер бөлімінің бастығы Құрымбаев Семейхан Айдарбекұлына (келісім бойынша) әскери міндетін өтеудің қашып, іздеуде жүрген азаматтарды жеткізіп беруін қадағалау, дәрігерлік комиссиясының кезінде және әскер қатарына шақырылған азаматтарды облыстық жиын пункіне жіберілу кезінде аудандық қорғаныс істері жөніндегі бөлімінде қоғамдық тәртіпті қадағалау үшін қызметкерлер бөлуді ұйымдастыру ұсынылсын. Жалғанды:/қосымша № 2/

<a id="p6"></a>

6. Аудандық емхананың бас дәрігері Г.Шалабаева:

   1) әскерге шақырылған азаматтардың флюрографиядан өтуін, анализдер тапсыруын, қан құрамын айыруын қамтамасыз етсін.

   2) әскерге шақырылған азаматтардың өкпе (туберкулез), трахома,бұлшықет, сүйек, буын органдарының тізімін, дәрігерлік бақылау мен диспансерлік байқаудың мәліметтерін табыс ету:

   3) комиссияның маман дәрігерлерін қажетті аспаптармен, рентген пленкасымен, флюропленкамен, элентрокардиографияға арналған қағазбен қамтамасыз етсін:

   4) әскери шақырылғандардың комиссиядан өту кезінде оларға қажетті егу жұмыстарын жүргізсін.

<a id="p7"></a>

7. Аудандық мәдениет үйінің директорына (Р. Жолдыбаева) аудандық қорғаныс істері жөніндегі бөлімімен келісе отырып, әскер қатарына шақырылатын азаматтардың салтанатты түрде соғыс ардагерлерімен, Отан алдындағы борышын өтеп келген азаматтермен кездесуін ұйымдастырылсын.

<a id="p8"></a>

8. Село поселке әкімдеріне, меншік нысандарына қарамастан мекемелер, ұйымдар мен оқу орындарының басшыларына, әсерге шақырушыларды шақыру комиссиясының өтеуге қажетті мезгілде жұмыстан (оқудан) босатуды, әскерге шақырышуларды іс сапардан, еңбек демалысынан кері шақырылып алынсын және әскери есеп мамандарына немесе кадр бөліміне қаулының басшылығымен олардың уақытылы келуін қамтамасыз ету ұсынылсын.

<a id="p9"></a>

9. Аудандық қорғаныс істері жөніндегі бөлім бастығы Қ.Сүйеубаев (келісім бойынша) әскерге шақыру бойынша қорытынды хабарламаны аудан әкіміне 2008 жылдың маусымның 25- не дейін ақпарат беру ұсынылсын.

<a id="p10"></a>

10. Осы қаулының орындалысына бақылау жасау аудан әкімінің орынбасары О.Жарылғаповаға жүктелсін.

<a id="p11"></a>

11. Осы қаулы ресми жарияланғаннан күннен бастап қолданысқа енгізіледі.
