# 2009 жылға арналған нысаналы топтарды жұмыспен қамтитын мекемелер мен кәсіпорындар тізбесін бекіту туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы", 2001 жылғы 23 қаңтардағы "Халықты жұмыспен қамту туралы" заңдарына сәйкес, қала әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. 2009 жылға арналған нысаналы топтарды жұмыспен қамтитын мекемелер мен кәсіпорындар тізбесі қосымшаға сәйкес бекітілсін.

<a id="p2"></a>

2. Жұмыс берушілер халықтың бекітілген нысаналы топтарын жұмыспен қамтамасыз етуге ұсынылсын.

<a id="p3"></a>

3. Осы қаулының орындалсын бақылау қала әкімінің орынбасары Т.Сатыбалдиевке жүктелсін.

<a id="p4"></a>

4. Осы қаулы алғаш ресми жарияланған күнінен бастап күнтізбелік он күн өткен соң қолданысқа енгізіледі.

*Қала әкімі Ж.Бабаханов*
