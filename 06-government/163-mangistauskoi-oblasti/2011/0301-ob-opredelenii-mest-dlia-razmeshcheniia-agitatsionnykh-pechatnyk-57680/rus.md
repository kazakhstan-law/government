# Об определении мест для размещения агитационных печатных материалов для всех кандидатов и оснащении их стендами, щитами, тумбами по Тупкараганскому району

Руководствуясь пунктом 6 статьи 28 Конституционного Закона Республики Казахстан № 2464 от 28 сентября 1995 года и письмом № 04 от 22 февраля 2011 года Тупкараганской районной избирательной комиссии акимат района ПОСТАНОВЛЯЕТ:

1. Определить места для размещения агитационных печатных материалов для всех кандидатов по Тупкараганскому району согласно приложению № 1.

2. Заместителю акима района Д.О.Меңдіханову, акимам поселка, сел (Азирбаев Ш., Әбдіғалиев Е.Қ., Дуйшов К., Ермекбаев У.К., Нугманов А.Ж.) до 03.03.2011 года организовать оснащение мест для размещения агитационных печатных материалов для всех кандидатов согласно приложению № 1 стендами, щитами, тумбами во всех населенных пунктах соответственно.

3. Контроль за исполнением настоящего постановления возложить на заместителя акима района Д.О.Меңдіханова.

4. Настоящее постановление вступает в силу после государственной регистрации в департаменте юстиции Мангистауской области и вводится в действие после первого официального опубликования в средствах массовой информации.

# Об определений мест для размещения агитационных печатных материалов для всех кандидатов по Тупкараганскому району.

## 1.Щиты:

### 1. По городу Форт - Шевченко:

1) Спереди здания «Центр обслуживания населения»;

2) Спереди здания Тупкараганского районного филиала акционерного общества «Народный Банк Республики Казахстан»;

3) Спереди здания городской железнодорожной кассы (старая автостанция);

4 )Спереди магазина «Нурай» (напротив здания «Бизнес инкубатор»);

### 2. По поселку Баутино:

1) Посередине спереди между зданиями школы - лицея имени Алексея Максимовича Горького и Баутинского филиала Мангистауского политехнического колледжа;

2) Спереди здания поселкового отделения акционерного общества «Казахтелеком» (здание поселковой почты);

3) Спереди здания государственного учреждения «Аппарат акима поселка Баутино»;

### 3. По населенному пункту Аташ поселка Баутино:

1) Спереди здания сельской библиотеки;

### 4. По селу Акшукур:

1) Спереди здания отделения акционерного общества «Казпочта»;

2) Спереди здания сельского Дома культуры;

3) Спереди 2 - этажного здания магазина «Малика»;

4) Спереди офисного здания государственного коммунального предприятия «Акшукургазсервис»;

<a id="p5"></a>

### 5. По селу Таушык:

1) Посередине спереди между зданиями государственного учреждения «Аппарат акима села Таушык» и сельского отделения акционерного общества «Казпочта»;

2) Посередине спереди между зданиями сельского Дома культуры и офиса товарищества с ограниченной ответственностью «Таушык ауылшаруашылыгы»;

<a id="p6"></a>

### 6. По селу Сайын Шапагатов:

1) Спереди здания государственного учреждения «Аппарат акима села Сайын Шапагатов»;

2) Спереди здания сельского фельдшерско - акушерского пункта;

3) Спереди здания государственного учреждения «Школа - лицей среднего образования № 1»

## 2.Тумбы:

<a id="p7"></a>

### 7. По городу Форт - Шевченко:

1) Вдоль по две стороны автодороги при въезде со стороны города Актау;

2) Спереди здания районной поликлиники;

<a id="p8"></a>

### 8. По поселку Баутино:

1) Спереди здания детского сада «Акбота»;

2) Спереди гостиницы «Достык»;

<a id="p9"></a>

### 9. По населенному пункту Аташ поселка Баутино:

1) Спереди двухэтажного жилого дома № 1 по улице Джангельдина

<a id="p10"></a>

### 10. По селу Кызылозен:

1) Вблизи здания магазина «Актаукоопсауда»;

<a id="p11"></a>

### 11. По селу Таушык:

1) На площади спереди здания государственного учреждения «Аппарат акима села Таушык»;

<a id="p12"></a>

### 12. По селу Сайын Шапагатов:

1) Вблизи здания государственного учреждения «Школа - лицей среднего образования № 1»;

<a id="p13"></a>

### 13. По селу Акшукур:

1) Спереди здания «Центр обслуживания населения».
