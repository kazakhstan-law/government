# О Координационном Совете по борьбе с туберкулезом

> *Сноска. Утратило силу постановлением акимата Мангистауской области от 28.12.2004 № 286.*

В соответствии с Законами Республики Казахстан " О местном государственном управлении в Республике Казахстан", " О нормативно -правовых актах" и в связи с реорганизацией ряда учреждений и кадровыми изменениями, акимат области ПОСТАНОВЛЯЕТ:

1. Одобрить обновленный состав Координационного Совета по борьбе с туберкулезом (далее Совет) согласно приложению 1.

2. Персональный состав обновленного Совета направить в установленном порядке на утверждение очередной сессии областного маслихата.

3. Утвердить Положение о Совете согласно приложению 2.

4. Акимам городов и районов:

   рассматривать на заседаниях совета по борьбе с туберкулезом вопрос о состоянии противотуберкулезной работы с принятием конкретных мер, обеспечивающих предотвращение распространения туберкулеза;

   ежегодно при формировании бюджета предусматривать выделение средств на приобретение противотуберкулезных препаратов, медицинского оборудования и ремонт противотуберкулезных учреждений.

5. Контроль за исполнением настоящего постановления возложить на заместителя акима области Макежанова С.А.

# ПОЛОЖЕНИЕ об областном координационном Совете по борьбе с туберкулезом

## 1. Общие положения

1. Координационный Совет по борьбе с туберкулезом (далее Совет) является консультативно-совещательным органом при акимате области.

2. В состав областного координационного совета по борьбе с туберкулезом входят представители управления здравоохранения, управления образования, финансового управления, управления внутренних дел (по согласованию), управления информации (по согласованию), управления сельского хозяйства, управления комитета уголовно-исполнительной системы Министерства юстиции Республики Казахстан (по согласованию), департамента юстиции (по согласованию), Департамента государственного санитарно-эпидемиологического надзора, Департамента внутренней политики.

3. Совет в своей деятельности руководствуется Конституцией Республики Казахстан и иными нормативными правовыми актами Республики Казахстан по вопросам борьбы с туберкулезом, постановлениями акимата, решениями акима области и настоящим Положением.

## 2. Задачи Совета

4. Задачами Совета являются:

   обеспечение взаимодействия исполнительных местных органов, неправительственных, общественных и других организация по вопросам организации борьбы с туберкулезом в области;

   организация мероприятий направленных на улучшение эпидемиологической ситуации по туберкулезу.

## 3. Функции Совета

5. Основными функциями Совета являются:

   заслушивание информации руководителей учреждений здравоохранения, образования, сельского хозяйства, ветеринарии, внутренних дел и других государственных органов о состоянии борьбы с туберкулезом на местах с предварительной проверкой проводимых мероприятий;

   внесение на рассмотрение областного акимата и областного маслихата обоснованных предложений по совершенствованию борьбы с туберкулезом.

## 4. Организация работы Совета

<a id="p6"></a>

6\. Совет возглавляет председатель, который руководит его деятельностью, председательствует на заседаниях, планирует его работу и осуществляет общий контроль за реализацией решений Совета. Во время отсутствия председателя его функции выполняет заместитель.

<a id="p7"></a>

7\. Секретарь Совета готовит предложения по повестке и оформляет протоколы после его проведения.

<a id="p9"></a>

9\. Решения принимаются открытым голосование и считаются принятыми, если за них подано большинство голосов от общего количества членов Совета. В случае равенства голосов принятым считается решение, за которое проголосовал председатель. Решение носит рекомендательный характер.

<a id="p10"></a>

10\. Заседания Совета проводятся два раза в год.

## 5. Права и ответственность членов Совета

<a id="p11"></a>

11. Члены Совета присутствуют на заседаниях Совета, выполняют поручения председателя, связанные с деятельностью Совета.

<a id="p12"></a>

12. Члены Совета вправе вносить предложения по повестке дня заседания Совета, формулировать конкретные предложения и высказывать свое отношение по обсуждаемым вопросам.
