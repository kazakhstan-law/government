# Об определении мест для размещения агитационных печатных материалов для всех кандидатов на территории города Тараз

В соответствии с пунктом 6 статьи 28 Конституционного закона Республики Казахстан «О выборах в Республике Казахстан», акимат города Тараз ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить места для размещения агитационных печатных материалов для всех кандидатов на территории города Тараз согласно приложению.

<a id="p2"></a>

2. Признать утратившим силу постановление акимата города Тараз от 13 августа 2025 года № 1901 «Об определении мест для размещения агитационных печатных материалов для всех кандидатов на территории города Тараз».

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на руководителя аппарата акима города Тараз.

<a id="p4"></a>

4. Настоящее постановление вводится в действие после дня его первого официального опубликования.
