# О предоставлении кандидатам на договорной основе помещений для встреч с избирателями и определении мест для размещения агитационных печатных материалов во время выборов

В соответствии с пунктами 4, 6 статьи 28 Конституционного Закона Республики Казахстан от 28 сентября 1995 года "О выборах в Республике Казахстан" акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Предоставить кандидатам на договорной основе помещения для встреч с избирателями согласно приложению 1.

<a id="p2"></a>

2. Совместно с Жуалынской районной территориальной избирательной комиссией (по согласованию) определить места для размещения агитационных печатных материалов для всех кандидатов согласно приложению 2.

<a id="p3"></a>

3. Признать утратившим силу постановление акимата Жуалынского района Жамбылской области от 23 февраля 2015 года №90 (зарегистрировано Департаментом юстиции Жамбылской области №2566, опубликованное в газете «Жаңа-өмір-Новая-жизнь» от 20 марта 2015 года) «О предоставлении кандидатам на договорной основе помещений для встреч с избирателями и определении мест для размещения агитационных печатных материалов во время выборов».

<a id="p4"></a>

4. Контроль за исполнением настоящего постановления возложить на руководителя аппарата акима района Койбакова Серика Дуйсенбаевича.

<a id="p5"></a>

5. Настоящее постановление вступает в силу со дня государственной регистрации в органах юстиции и вводится в действие по истечении десяти календарных дней со дня первого официального опубликования.
