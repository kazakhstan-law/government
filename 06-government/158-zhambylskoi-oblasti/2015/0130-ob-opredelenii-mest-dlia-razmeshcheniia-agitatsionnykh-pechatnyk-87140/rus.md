# Об определении мест для размещения агитационных печатных материалов и предоставлении кандидатам на договорной основе помещений для встреч с избирателями

В соответствии с пунктами 4, 6 статьи 28 Конституционного Закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан» акимат района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Совместно с Меркенской районной территориальной избирательной комиссией (по согласованию) определить места для размещения агитационных печатных материалов для всех кандидатов согласно приложению 1.

<a id="p2"></a>

2. Предоставить кандидатам на договорной основе помещения для встреч с избирателями согласно приложению 2.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на руководителя аппарата акима района Наметкулова Амангелди Наметкуловича.

<a id="p4"></a>

4. Настоящее постановление вступает в силу со дня государственной регистрации в органах юстиции и вводится в действие по истечении десяти календарных дней со дня его первого официального опубликования.
