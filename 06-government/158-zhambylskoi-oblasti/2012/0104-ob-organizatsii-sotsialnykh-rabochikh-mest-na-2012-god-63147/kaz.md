# 2012 жылға әлеуметтiк жұмыс орындарын ұйымдастыру

«Халықты жұмыспен қамту туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 7 бабының 5-4) тармақшасына сәйкес, әлеуметтiк жұмыс орындарын ұйымдастыру мақсатында, Қордай ауданы әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Қосымшаға сәйкес 2012 жылға әлеуметтік жұмыс орындарын ұйымдастыратын жұмыс берушілердің тізбесі бекітілсін.

<a id="p2"></a>

2. Осы қаулының орындалуын бақылау аудан әкімінің орынбасары Еркін Құлымбайұлы Үйсімбаевқа жүктелсін.

<a id="p3"></a>

3. Осы қаулы әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді,алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі және 2012 жылдың 4 қаңтарынан пайда болған қатынастарға таралады.

**Қордай ауданының әкімі**
