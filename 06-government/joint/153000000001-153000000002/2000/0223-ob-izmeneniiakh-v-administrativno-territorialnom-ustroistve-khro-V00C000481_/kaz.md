# Хромтау ауданының әкiмшiлiк-аумақтық құрылымындағы өзгерiстер туралы

"Қазақстан Республикасының әкiмшiлiк-аумақтық құрылымы туралы " Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы N 4200 Заңы 11 бабының 2, 3 тармақтарына сәйкес Хромтау ауданының өкiлдi және атқарушы органдарының ұсынысы негiзiнде облыстық мәслихат пен облыс әкiмi ШЕШIМ ЕТТI:

<a id="para_1"></a>

1. Новоресей селолық округiнiң құрамынан жалпы көлемi 80056 га аумақты шығара отырып сызба-картаға сәйкес шекарасы өзгертiлсiн.

<a id="para_2"></a>

2. Әкiмшiлiк орталығы Табантал селосы Табантал селолық округi құрылсын, сызба-картаға сәйкес оның құрамына елдi мекендер мен жалпыкөлемi 80056 га аумақ кiргiзiлсiн.

<a id="para_3"></a>

3. Жаңадан құрылған Табантал селолық округiн ұстау шығыны 2000 жылғы аудандық басқару органдарын ұстауға қаралған лимит көлемiнде жүргiзiлсiн.

<a id="para_4"></a>

4. Облыстық статистика басқармасы (А. Д. Мұқаев) облыстық әкiмшiлiк аумақтық бiрлiктердiң есептiк мәлiметтерiне тиiстi өзгерiстер енгiзсiн.

<a id="para_5"></a>

5. Облыстық жер ресурстарын басқару жөнiндегi комитет (М. Н. Жекеев) ауданның әкiмшiлiк - аумақтық құрылымына енгiзiлген өзгерiстерге сәйкес жер-кадастр құжаттарын тәртiпке келтiрсiн.
