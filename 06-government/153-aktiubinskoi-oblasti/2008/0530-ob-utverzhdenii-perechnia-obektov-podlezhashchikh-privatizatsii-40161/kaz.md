# Жекешелендіруге ұсынылып отырған объектілердің тізбесін бекіту туралы

"Жекешелендіру туралы" Қазақстан Республикасының 1995 жылғы 23 желтоқсандағы N 2721 Заңына, "Коммуналдық меншік объектілерін жекешелендіру мәселелері" Қазақстан Республикасы Үкіметінің 1999 жылғы 21 қыркүйектегі N 1431 қаулысына, "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы N 148 Заңының 27 бабына сәйкес облыс әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Жекешелендіруге ұсынылып отырған объектілердің тізбесі қосымшаға сәйкес бекітілсін.

<a id="p2"></a>

2. "Ақтөбе облысының қаржы басқармасы" ММ (С. Еңсегенұлы) мемлекеттік коммуналдық меншік объектілерінің тізіліміне тиісті өзгерістер енгізсін.

   > *Ескерту. 2 тармағына өзгерту енгізілді - Ақтөбе облысы әкімдігінің 2009.11.18 № 340 (қолданысқа енгізілу тәртібін 4 тармағынан қараңыз) қаулысымен.*

<a id="p3"></a>

3. Осы қаулының орындалуын бақылау облыс әкімінің орынбасары А. Дубовенко жүктелсін.

   > *Ескерту. 3 тармағына өзгерту енгізілді - Ақтөбе облысы әкімдігінің 2009.11.18 № 340 (қолданысқа енгізілу тәртібін 4 тармағынан қараңыз) қаулысымен.*

<a id="p4"></a>

4. Осы қаулы әділет органдарында мемлекеттік тіркеуден өткен күннен бастап күшіне енеді және ресми жарияланған күннен бастап қолданысқа енгізіледі.

*Облыс әкімі Е. Сағындықов*

> *Ақтөбе облысы әкімдігінің*  
> *2008 жылғы 30 мамырдағы N 195*  
> *қаулысына қосымша*

> *Ескерту. Қосымшаға өзгерту енгізілді - Ақтөбе облысы әкімдігінің 2009.03.30 N 102 (қолданысқа енгізілу тәртібін 3 тармағынан қараңыз), 2009.11.18 № 340 (қолданысқа енгізілу тәртібін 4 тармағынан қараңыз) қаулыларымен.*
