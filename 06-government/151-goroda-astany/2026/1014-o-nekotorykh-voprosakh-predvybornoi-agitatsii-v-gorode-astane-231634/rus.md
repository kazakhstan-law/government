# О некоторых вопросах предвыборной агитации в городе Астане

В соответствии со статьей 28 Конституционного закона Республики Казахстан «О выборах в Республике Казахстан», акимат города Астаны ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить места для размещения агитационных печатных материалов для всех кандидатов в депутаты маслихата города Астаны согласно приложению 1 к настоящему постановлению.

<a id="p2"></a>

2. Перечень помещений, предоставляемых на договорной основе для всех кандидатов в депутаты маслихата города Астаны, для встреч с избирателями согласно приложению 2 к настоящему постановлению.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на руководителя Государственного учреждения «Аппарат акима города Астаны».

<a id="p4"></a>

4. Настоящее постановление вступает в силу со дня подписания и подлежит опубликованию.
