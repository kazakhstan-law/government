# Об утверждении дислокации мест для размещения агитационных печатных материалов и перечня помещений для проведения встреч с избирателями кандидатов в депутатов маслихатов Республики Казахстан

> *Сноска. Утратило силу постановлением акимата города Балхаша Карагандинской области от 06.02.2014 № 05/02.*

Согласно пунктам 4, 6 статьи 28 Конституционного Закона Республики Казахстан «О выборах в Республике Казахстан» акимат города Балхаша ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Утвердить дислокацию мест для размещения печатных агитационных материалов кандидатов в депутаты маслихатов Республики Казахстан по городу Балхашу и прилегающим поселкам (приложение № 1).

<a id="p2"></a>

2. Утвердить перечень помещений, предоставляемых на договорной основе для встреч с избирателями кандидатов в депутаты маслихатов Республики Казахстан (приложение № 2).

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на руководителя аппарата акима города Балхаша Асылбекову С.С.

<a id="p4"></a>

4. Настоящее постановление вводится в действие со дня его официального опубликования.
