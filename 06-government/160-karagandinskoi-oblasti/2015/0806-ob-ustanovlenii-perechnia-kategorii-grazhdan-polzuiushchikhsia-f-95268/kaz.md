# Мүгедектерді қоспағанда, дене шынықтыру-сауықтыру қызметтерін тегін немесе жеңілдікті шарттармен пайдаланатын азаматтар санаттарының тізбесін, сондай-ақ жеңілдіктер мөлшерін белгілеу туралы

«Дене шынықтыру және спорт туралы» Қазақстан Республикасының 2014 жылғы 3 шілдедегі Заңының 48-бабына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңына сәйкес, Саран қаласының әкімдігі ҚАУЛЫ ЕТЕДІ:

<a id="p1"></a>

1. Мүгедектерді қоспағанда, дене шынықтыру-сауықтыру қызметтерін тегін немесе жеңілдікті шарттармен пайдаланатын азаматтар санаттарының тізбесі, сондай-ақ жеңілдіктер мөлшері белгіленсін.

<a id="p2"></a>

2. Осы қаулының орындалуын бақылау Саран қаласы әкімінің аппарат басшысы Елена Ивановна Бородинаға жүктелсін.

<a id="p3"></a>

3. Осы қаулы алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Саран қаласының әкімі**
