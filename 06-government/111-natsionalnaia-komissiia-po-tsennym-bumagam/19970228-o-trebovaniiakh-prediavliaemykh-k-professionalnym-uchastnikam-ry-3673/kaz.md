# "Бағалы қағаздар рыногының кәсiпқой қатысушыларына қойылатын талаптар туралы"

Бағалы қағаздар рыногындағы кәсiпқой қызметтi реттеу және инвесторлардың мүдделерiн қорғау мақсатында Қазақстан Республикасының Бағалы қағаздар жөнiндегi ұлттық комиссиясы қаулы етедi:

1. Мыналарды жүзеге асыруға арналған лицензия алу үшiн БҚҰК-ға

```
құжаттар беру күнiне жеке капиталдық жеткiлiктi деңгейi былайша
белгiленсiн:
нақтылы ұстаушы ретiнде клиенттердiң шоттарын жүргiзу құқығымен
брокерлiк және дилерлiк қызметтi - кемiнде 15000 есептi көрсеткiш;
клиенттердiң шоттарын жүргiзу құқығынсыз брокерлiк және дилерлiк
қызметтi - кемiнде 5000 есептi көрсеткiш;

```

2. Брокерлiк және дилерлiк, тiркеушiлiк қызметке лицензиясы бар

```
кәсiпқой қатысушылар 15 сәуiрге дейiнгi мерзiмде жеке капиталының
жеткiлiктi деңгейiн және олардың бағалы қағаздар рыногындағы қызметiн
айқындайтын құжаттарын осы қаулыға және қолданылып жүрген заңдарға
сәйкестендiрсiн.
3. Осы қаулының орындалысына бақылау жасау Бағалы қағаздар
рыногындағы кәсiби қызметтi реттеу басқармасына және Ұлттық комиссияның
оған жетекшiлiк ететiн мүшесiне жүктелсiн.
4. Қаулы қабылданған сәттен бастап күшiне енедi.
Ұлттық комиссияның
Төрағасы
```
