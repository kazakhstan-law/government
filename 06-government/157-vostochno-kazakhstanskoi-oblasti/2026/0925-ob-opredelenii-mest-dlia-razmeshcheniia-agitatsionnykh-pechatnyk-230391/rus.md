# Об определении мест для размещения агитационных печатных материалов для всех кандидатов на территории города Усть-Каменогорска

В соответствии с пунктом 6 статьи 28 Конституционного Закона Республики Казахстан «О выборах в Республике Казахстан», пунктом 2 статьи 31 Закона Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», акимат города Усть-Каменогорска ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Совместно с Усть-Каменогорской городской территориальной избирательной комиссией определить места для размещения агитационных печатных материалов для всех кандидатов на территории города Усть-Каменогорска согласно приложению к настоящему постановлению.

<a id="p2"></a>

2. Государственному учреждению «Аппарат акима города Усть-Каменогорска Восточно Казахстанской области» в установленном законодательством Республики Казахстан порядке обеспечить размещение настоящего постановления на интернет-ресурсе акимата города Усть-Каменогорска после его официального опубликования.

<a id="p3"></a>

3. Контроль за исполнением данного постановления возложить на курирующего заместителя акима города Усть-Каменогорска.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
