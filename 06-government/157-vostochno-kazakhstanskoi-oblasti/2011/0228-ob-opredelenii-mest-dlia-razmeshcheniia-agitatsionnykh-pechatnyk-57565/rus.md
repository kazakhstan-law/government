# Об определении мест для размещения агитационных печатных материалов по Шемонаихинскому району

В соответствии с пунктом 6 статьи 28 Конституционного Закона Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан» акимат Шемонаихинского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Определить места для размещения агитационных печатных материалов по Шемонаихинскому району согласно приложению.

<a id="p2"></a>

2. Акимам города Шемонаиха, поселков и сельских округов оснастить указанные места информационными стендами.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на заместителя акима района Колтунову Т.Д.

<a id="p4"></a>

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Исполняющий обязанности акима Шемонаихинского района**
