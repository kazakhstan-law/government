# Көкпекті ауданының елді мекендерінде көшпелі сауданы жүзеге асыру үшін орындарды белгілеу туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін – өзі басқару туралы» Заңының 31 бабы 1 тармағының 4-2) тармақшасына, Қазақстан Республикасының 2004 жылғы 12 сәуірдегі «Сауда қызметін реттеу туралы» Заңының 8 бабының 3) тармақшасына, 27 бабына, Қазақстан Республикасы ұлттық экономика Министрі міндетін атқарушының 2015 жылғы 27 наурыздағы № 264 (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 11148 болып тіркелген) бұйрығымен бекітілген Ішкі сауда қағидаларының 102 тармағына сәйкес, Көкпекті ауданының елді мекендері аумағында сауда қызметін реттеу мақсатында, Көкпекті ауданының әкімдігі ҚАУЛЫ ЕТЕДІ:

1. Көкпекті ауданы елді мекендерінің аумағында көшпелі сауданы жүзеге асыруға арналған орындар осы қаулының қосымшасына сәйкес белгіленсін.

2. «Көкпекті ауданының кәсіпкерлік және туризм бөлімі» мемлекеттік мекемесі Қазақстан Республикасы заңнамасымен бекітілген тәртіпте:

   1) Шығыс Қазақстан облысының әділет Департаментінде осы қаулының мемлекеттік тіркелуін;

   2) осы қаулы мемлекеттік тіркеуден өткеннен кейін күнтізбелік он күн ішінде, оның көшірмелерін Көкпекті ауданының аумағында таратылатын мерзімдік басылымдарға ресми жариялау үшін жіберілуін;

   3) ресми жарияланғаннан кейін Көкпекті ауданы әкімдігінің интернет – ресурсында осы қаулының орналастырылуын қамтамасыз етсін.

3. Осы қаулының орындалуына бақылау жасау Көкпекті ауданы әкімінің орынбасары Даурен Бакытжанович Койгельдинге жүктелсін.

4. Осы қаулы оның алғашқы ресми жарияланған күннен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Көкпекті ауданының елді мекендерінде көшпелі сауданы жүзеге асыруға арналған орындар тізбесі

1. Құлынжон ауылында Кеңес көшесінің бойындағы «Жолан» кафесі мен балалар ойын алаңы арасында;

2. Миролюбовка ауылында Асламов көшесінің бойындағы мешіт ғимараты мен «Пикник» кафесінің арасындағы алаң;

3. Раздольное ауылында Мира көшесінің бойындағы «Берёзка» дүкені жанында;

4. Мариногорка ауылында Абай көшесінің бойындағы «Нива» дүкені жанында;

<a id="p5"></a>

5. Преображенка ауылында Заречная көшесінің бойындағы мәдениет үйі ғимаратының іргелес аумағында;

<a id="p6"></a>

6. Үлгілімалшы ауылында мәдениет үйінің жанында;

<a id="p7"></a>

7. Көкпекті ауылында Абай көшесінің бойындағы «Ырыс» дүкені жанында;

<a id="p8"></a>

8. Самар ауылында «Арман» ашық базарының аумағында;

<a id="p9"></a>

9. Теректі ауылында Бірлік көшесінің бойындағы «Дана» дүкені жанында;

<a id="p10"></a>

10. Биғаш ауылында М.Цепура көшесінің бойындағы «Раушан» дүкені жанында;

<a id="p11"></a>

11. Аққала ауылында Тәуелсіздік көшесінің бойындағы «Алёна» дүкені жанында;

<a id="p12"></a>

12. Сарыбел ауылында Абай көшесінің бойындағы мәдениет үйі ғимаратына қарама – қарсы;

<a id="p13"></a>

13. Тассай ауылында М.Төлегенов көшесінің бойындағы «Жайдары» дүкені жанында;

<a id="p14"></a>

14. Бастаушы ауылында Абай көшесінің бойындағы «Айман» дүкені жанында;

<a id="p15"></a>

15. Үлкенбөкен ауылында Киров көшесінің бойындағы мектеп ғимаратына қарама – қарсы;

<a id="p16"></a>

16. Көкжайық ауылында Саяхимов көшесінің бойындағы «Айя» дүкеніне қарама – қарсы;

<a id="p17"></a>

17. Палатцы ауылында М.Горький көшесінің бойындағы «Ульяна» дүкені жанында.
