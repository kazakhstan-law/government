# Аудан шаруашылықтарында ауыл шаруашылық жануарлардың бірдейлендірілуін өткізу туралы

Қазақстан Республикасы Ауыл шаруашылық Министрлігінің 05.04.2006 жылғы № 218 бұйрығына сәйкес “Ауыл шаруашылық жануарларына бірдейлендіруді жүргізу” Ережесі туралы 02.04.2003 жылғы № 164 бұйрығына өзгерту мен толықтырулар енгізілуіне байланысты, “Ветеринария туралы” Қазақстан Республикасының 2002 жылғы 10 шілде күнгі № 339-11 Заңының 25, 32-баптарын және “Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы” Қазақстан Республикасының 2001 жылғы 23 қаңтардағы № 148-11 Заңының 37-бабының 1, 2-тармақтарын басшылыққа ала отырып аудан әкімдігі ҚАУЛЫ ҚАБЫЛДАЙДЫ:

<a id="p1"></a>

1. Аудан аумағында ауыл шаруашылық жануарларын бірдейлендіру 2007 жылдың қаңтар, шілде айларында өткізілсін.

<a id="p2"></a>

2. Аудандық ауыл шаруашылық бөлімі (А.Саметов) және ауыл, кент округтерінің әкімдеріне;

   А) Өздеріне қарасты округтеріндегі ветеринариялық қызметтермен бірлесе отырып, барлық меншік түріндегі ауыл шаруашылық жануарларын бірдейлендіруді ұйымдастыру тапсырылсын.

   Б) Малдарды бірдейлендірудің қортындысының нәтижесі округтерінің шаруашылық кітаптарында көрініс табуы қамтамасыз етілсін.

<a id="p3"></a>

3. Қазақстан Республикасы Ауыл шаруашылығы Министрлігінің аудандық аумақтық инспекциясы (А.Жамағатов) бірдейлендірудің қортындысын компьютерлік деректер базасына енгізілуіне бақылау жасасын.

<a id="p4"></a>

4. Аудандық ішкі істер бөлімі; (бастығының міндетін атқарушы Д.Жанарбеков) тасымалдау кезінде шикізат және мал өнімдеріне берілген жолдама құжаттардың түгелдігіне бақылау жасауды қамтамасыз етсін.

<a id="p5"></a>

5. Аудандық статистика бөлімі (Д.Жөргекбаев) аудан аумағындағы малдардың толық мәліметтерінің дұрыстығына бақылау жасауды қамтамасыз етілсін.

<a id="p6"></a>

6. Қаулының орындалуына бақылау жасау аудан экімінің орынбасары А.Смаиловқа жүктелсін.

<a id="p7"></a>

7. Аудандық әкімдіктің 2 желтоқсан 003 жылғы № 432-А қаулысының күші жойылсын.

<a id="p8"></a>

8. Осы қаулы әділет басқармасынан тіркеуден өткен күннен бастап күшіне енгізілсін.
