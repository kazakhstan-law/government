# Сайлау алдындағы барлық кандидаттар үшін үгіттік баспа материалдарын орналастыру үшін орындар белгілеу туралы

"Қазақстан Республикасындағы сайлау туралы" Қазақстан Республикасының 1995 жылғы 28 қыркүйектегi Конституциялық Заңының 28-бабының 6-тармағына, "Қазақстан Республикасындағы жергiлiктi мемлекеттiк басқару және өзiн-өзi басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 31-бабына сәйкес Қызылорда қаласының әкімдігі ҚАУЛЫ ЕТЕДІ:

1. Қосымшаға сәйкес қалалық сайлау комиссиясымен бiрлесіп сайлау алдындағы барлық кандидаттар үшін үгiттік баспа материалдарын орналастыру үшін орындар белгiленсiн.

2. Осы қаулының орындалуын бақылау қала әкімінің орынбасары Р. Рүстемовке жүктелсін.

3. Осы қаулы оның алғашқы ресми жарияланғанынан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

# Сайлау алдындағы барлық кандидаттар үшін үгіттік баспа материалдарын орналастыру үшін орындар

1. "Шұғыла" мөлтек ауданындағы Ғани Мұратбаев және Бұхарбай батыр көшелерінің қиылысындағы аялдама, солтүстік–шығыс жағы;

2. Еркін Әуелбеков көшесі N 58, солтүстік–шығыс жағы;

3. Әлихан Бөкейхан көшесі N 100 А, оңтүстік–шығыс жағы;

<a id="p4"></a>

4. Абай Құнанбаев даңғылындағы "Болашақ" университетіне қарама-қарсы аялдама, оңтүстік–шығыс жағы;

<a id="p5"></a>

5. Қорқыт ата көшесі N 144, солтүстік–батыс жағы;

<a id="p6"></a>

6. Иван Журба N 28, солтүстік-батыс жағы;

<a id="p7"></a>

7. Қорқыт ата көшесі N 73, N 6 қалалық емхана, солтүстік–шығыс жағы;

<a id="p8"></a>

8. Әлихан Бөкейхан және Амангелді Иманов көшелерінің қиылысындағы аялдама, солтүстік-батыс жағы;

<a id="p9"></a>

9. Әміре Қашаубаев көшесі N 37, Мәдина Ералиева атындағы мәдениет үйі, солтүстік-батыс жағы;

<a id="p10"></a>

10. N 197 қазақ орта мектебі, Достық көшесі N 38, оңтүстік-шығыс жағы;

<a id="p11"></a>

11. Қызылжарма ауылдық округі, Рахмет Батырбаев көшесіндегі N 5547 әскери бөлімше, оңтүстік-шығыс жағы;

<a id="p12"></a>

12. Мешітбай Қаржаубаев көшесі N 6, N 120 Ж. Жабаев атындағы орта мектебі, оңтүстік жағы;

<a id="p13"></a>

13. Жанқожа батыр көшесі N 82 А, Жалаңтөс Баһадүр атындағы спортта дарынды балаларға арналған мектеп интернаты, оңтүстік-батыс жағы;

<a id="p14"></a>

14. Астана даңғылы N 71, солтүстік-шығыс жағы;

<a id="p15"></a>

15. Тоғанас батыр көшесі N 1, шығыс жағы;

<a id="p16"></a>

16. Тасбөгет кенті, Шахмардан Есенов көшесі, Сәбира Майқанова атындағы мәдениет үйіне қарама-қарсы аялдама, оңтүстік-шығыс жағы;

<a id="p17"></a>

17. Тасбөгет кентіндегі орталық алаңда, оңтүстік-шығыс жағы;

<a id="p18"></a>

18. Белкөл кетіндегі орталық алаңда, оңтүстік-батыс жағы;

<a id="p19"></a>

19. Қызылжарма ауылдық округіндегі орталық алаңда, оңтүстік-шығыс жағы;

<a id="p20"></a>

20. Қызылөзек ауылдық округіндегі орталық алаңда, оңтүстік-батыс жағы;

<a id="p21"></a>

21. Ақсуат ауылдық округіндегі орталық алаңда, оңтүстік-шығыс жағы;

<a id="p22"></a>

22. Ақжарма ауылдық округіндегі орталық алаңда, оңтүстік-шығыс жағы;

<a id="p23"></a>

23. Қарауылтөбе ауылдық округіндегі орталық алаңда, солтүстік-батыс жағы;

<a id="p24"></a>

24. Талсуат ауылдық округіндегі орталық алаңда, оңтүстік-батыс жағы;

<a id="p25"></a>

25. Қосшыңырау ауылдық округіндегі орталық алаңда, оңтүстік-шығыс жағы;

<a id="p26"></a>

26. "Ақмешіт" мөлтек ауданы, Мұрат Саламатов көшесінде орналасқан Жібек жолы май құю бекетіне қарама-қарсы, солтүстік–шығыс жағы;

<a id="p27"></a>

27. Бейбарыс Сұлтан көшесі N 29, солтүстік-батыс жағы;

<a id="p28"></a>

28. Абай Құнанбаев даңғылы, Илья Ильин атындағы спорт алаңы, батыс жағы.
