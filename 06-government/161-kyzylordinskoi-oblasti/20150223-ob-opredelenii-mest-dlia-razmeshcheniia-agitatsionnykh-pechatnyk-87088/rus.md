# Об определении мест для размещения агитационных печатных материалов

В соответствии с Конституционным законом Республики Казахстан от 28 сентября 1995 года «О выборах в Республике Казахстан» акимат Аральского района ПОСТАНОВЛЯЕТ:

1. Совместно с Аральской районной избирательной комиссией определить места для размещения агитационных печатных материалов для всех кандидатов согласно приложению.

2. Контроль за исполнением настоящего постановления возложить на руководителя государственного учреждения «Аппарат акима Аральского района» Алишевой Ж.

3. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня первого официального опубликования.
