# Табиғатты қорғау іс шаралары тізбесін бекіту туралы

"Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" 2001 жылғы 23 қаңтардағы N 148-ІІ Заңы, "Қоршаған ортаны қорғау туралы" 1997 жылғы 15 шілдедегі N 160-І Заңына сәйкес және облыс аумағында табиғатты қорғау шараларына облыстық бюджеттен бөлінетін қаржының мақсатты жұмсалуын реттеу мақсатында облыс әкімияты ҚАУЛЫ ЕТЕДІ:

1. Қоса берілген облыс аумағындағы табиғатты қорғау шаралары тізбесі бекітілсін.

2. Бекітілген тізбені жүзеге асыру облыстық табиғат қорғау шаралары жөніндегі басқармасы жүктелсін.

3. Осы қаулының орындалуына бақылау жасау облыс әкімінің орынбасары Б.Мұхамедовке жүктелсін.

**Облыс әкімі**

**С.Нұрғисаев**

# Қызылорда облысы бойынша табиғатты қорғау іс-шаралары ТІЗБЕСІ

## 1. Су ресурстарын тиімді пайдалану және оны қорғау

1. Қала және өндірістік кәсіпорындарда сарқынды, қалдық суларды тазарту қондырғыларының құрылысын салу және жөндеу жұмыстары, сондай-ақ канализациялық насостар мен құбырларының құрылысын салу және жөндеуден өткізу.

2. Қалалардағы және ірі елді мекендердегі сарқынды, қалдық сулардың құрамы мен көлемін бақылау мақсатында автоматтық жүйені енгізу, тазалау әдістерін зерттеу үшін тәжірибелік қондырғылар орнату, қалдық сулардың жер асты су қорларына қосылып кетпеуін қадағалау.

3. Қашыртқы және дренаж суларының табиғи ортаға және оның нысандарына қосымша зиянды әсерін болдырмау үшін биологиялық инженерлік кешенді құрылыс жүргізу, фильтрацияға қарсы экран және биологиялық каналдар салу, зиянды қалдықтарды ұстайтын құрылымдар мен тұндырмалар, аэрациялық қондырғылар орнату арқылы сапасын жақсартып, қайта пайдалану іс-шараларын жүзеге асыру.

<a id="p4"></a>

4. Қашыртқы және дренаж суларын қайта пайдаланудың шараларын іске асыру, сонымен қатар қашыртқыларды және тік дренаж ұңғыларын таза қалыпты жағдайда ұстап, ыза сулардың көтерілуіне жол бермеу.

<a id="p5"></a>

5. Жер бетіндегі су көздерін тиімді пайдалану, тоғандар мен көлдерді суландыру және бау-бақша, жасыл желектерді көгерту үшін каналдар мен арықтарды тазарту, бұлақ көздерін ашу, су тоспаларын салумен жөндеу, қорғаныс дамбаларын көтеру.

<a id="p6"></a>

6. Судағы тіршілік иелерінің өмір сүру шартының жақсаруы және балықтардың босалқы қорының ұдайы көбеюі үшін аймақтағы су тоғандары мен көлдерде балық мелиоративтік жұмыстарын жүргізу.

<a id="p7"></a>

7. Су тұшыту жөніндегі жұмыстарды жүзеге асыру, шет аймақтарда шахтылық құдықтарын, су ұңғымаларын бұрғылау және жөндеу.

<a id="p8"></a>

8. Аймақта су қорларына зиянды ластағыш заттарды шығарушы көздеріне түгендеу шараларын жүргізу.

<a id="p9"></a>

9. Облыс аумағында және шалғай мал жайылымдарындағы су ұңғымаларын түгендеу жұмыстарын жүргізу.

## 2. Ауа бассейінін қорғау

<a id="p10"></a>

10. Өндірістік кәсіпорындарының, жылу энергия орталықтарының ауа атмосферасына зиянды газдарды лимиттен тыс шығарып ластағаны үшін еселенген төлемдерді анықтау мақсатында жасалынатын аналитикалық бақылауларды химиялық реактивтермен қамтамасыз ету.

<a id="p11"></a>

11. Ауа атмосферасына зиянды ластағыш заттарды шығарушы көздерге түгендеу шараларын жүргізу, ауа кеңістігінің сапасын тексеру үшін лабораторияларды бақылау приборлармен жабдықтау.

<a id="p12"></a>

12. Арал теңізі өңірінің, "Байқоңыр" ғарыш кешенінің, Барсакелмес қорығының сусыз қалған аймағының, "Возрождение" аралының ауа атмосферасына тигізетін зиянды әсерлерін болдырмау және залалсыздандыру шараларын іске асыру.

## 3. Жер ресурстарын қорғау

<a id="p13"></a>

13. Карьерлік және жабылған кеніш орындардағы бүлінген жерлердің құнарлығын қалпына келтіру.

<a id="p14"></a>

14. Шөлейт аймақтардағы жайылымдарды азған жерлерді қалпына келтіру, Арал теңізі ұлтанындағы құрғаған жерлердегі дауылдардан көтерілген тұз, шаңды тоқтату үшін шөлге, сорға төзімді бұталар мен өсімдіктерді егу, құм көшкінін тоқтаудың барлық шараларын қарастыру.

<a id="p15"></a>

15. Облыс аймағындағы ірі елді мекендердегі сорланған көлдердің орнын құрғату.

<a id="p16"></a>

16. Аймақтағы жер ресурстарын ластағыш көздерін түгендеу.

<a id="p17"></a>

17. Жерді жел және су эрозиясынан, батпақтанудан сорланудан қорғау жұмыстарын жүргізу.

## 4. Өндірістік және тұрмыстық заттардың қалдықтарын пайдалану

<a id="p18"></a>

18. Қалдықтарды өңдейтін және жағатын заводтардың, сондай-ақ тұрмыстық және өндірістік қалдықтарды сақтайтын полигондардың құрылыстарын салу, қалпына келтіру, кеңейту, жөндеу жұмыстары.

<a id="p19"></a>

19. Радиоактивтік қалдықтарды жинау, тасу, қайта өңдеу және көму іс-шараларын жүзеге асыру.

<a id="p20"></a>

20. Гербицидтер мен пестицидтердің қораптарын жинақтау және оны орталықтандырылған жерге көмуді ұйымдастыру.

## 5. Экологиялық ағарту жұмысы, мамандарды даярлау

<a id="p21"></a>

21. Мамандардың экологиялық білімділігін арттыру үшін оқу ұйымдастыру.

<a id="p22"></a>

22. Экологиялық ағарту жұмыстар мен білімді мектептерде, жоғарғы оқу орындарында, кәсіпорындар мен мекемелерде оқыту жұмыстарын жүргізу, семинарлар, көрмелер ұйымдастырып, плакаттар, кітапшалар, кітаптар, газеттер шығару, паннолар жасау, үздіктерді көтермелеу.

<a id="p23"></a>

23. Бұқаралық ақпарат құралдары арқылы экологиялық білімді және озық үлгілі тәжірибелі насихаттау, қоршаған ортаны қорғаудың ақпараттық жүйесін дамыту.

## 6. Ғылыми зерттеу жұмыстары

<a id="p24"></a>

24. Ауадағы, судағы, топырақтағы зиянды қоспалары жедел анықтап залалсыздандыру жолдарын зерттеу.

<a id="p25"></a>

25. Өндірістік кәсіпорындардан, жылу орталықтарынан ауаға бөлінетін зиянды газдарды тазалау.

<a id="p26"></a>

26. Арал өңірі аймағында мал және егін өнімдерін өндірудің оңтайлы технологиясын жасауды зерттеу.

<a id="p27"></a>

27. Қашыртқы және сарқынды суларды экологиялық қауіпсіз жолымен пайдалану жолдарын, Сырдария өзенінің ластануының экологиялық мелиоративтік жағдайына тигізетін әсерін, балық шаруашылығы маңызы бар көлдерге бионегіздеме жасау.

<a id="p28"></a>

28. Экологиялық аудандастыру жұмыстарын жүргізу.

<a id="p29"></a>

29. Облыстың шөлейт аймағындағы жайылымы азған тақырларда, құмда, сорланған жерлерде, Арал теңізінің құрғаған ұлтанында өсетін бұталар мен өсімдіктердің түрлерін зерттеп, оны қолданысқа енгізуге ұсыныстар әзірлеу.

<a id="p30"></a>

30. Барсакелмес қорығының өсімдіктер мен жануарлар дүниесін зерттеу.

## 7. Биотехникалық жұмыстар

<a id="p31"></a>

31. Ерекше қорғалатын жануарлардың, құстардың, балықтардың санын көбейту, оларды қорғау.

<a id="p32"></a>

32. Жабайы аңдардың есебін жүргізу, жыртқыш аңдардың санын шектеу және оған сыйақы төлеу.

<a id="p33"></a>

33. Қорғанышты жасыл белдеулер, саялы және жеміс бақтарын көбейту үшін ағаштар егу, қолда бар бақтарды күту, питомниктер жасау.

<a id="p34"></a>

34. Облыс аймағы бойынша аңшылық жерлерде биотехникалық шараларын атқару.

<a id="p35"></a>

35. Күріш атызында және таяз суда қалған балық шабартарын құтқару жұмыстарын жүргізу.

<a id="p36"></a>

36. Ормандар және өсімдіктер зиянкестеріне, ауруларына қарсы күрес жұмыстарын жүргізу.
