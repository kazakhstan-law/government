# Об определении мест для размещения агитационных печатных материалов

В соответствии с Конституционным законом Республики Казахстан от 28 сентября 1995 года “О выборах в Республике Казахстан” акимат Жалагашского района ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Совместно с Жалагашской районной избирательной комиссией определить места для размещения агитационных печатных материалов для всех кандидатов согласно приложению.

<a id="p2"></a>

2. Акимам поселка и сельских округов оснастить места размещения агитационных печатных материалов стендами, щитами, тумбами.

<a id="p3"></a>

3. Контроль за исполнением настоящего постановления возложить на руководителя коммунального государственного учреждения “Аппарат акима Жалагашского района” акимата Жалагашского района Ш.Калыбаева.

<a id="p4"></a>

4. Настоящее постановление вводится в действие со дня первого официального опубликования.
