# Жүзеге асырылатын міндеттерді орындау үшін қажетті және жеткілікті дербес деректердің тізбесін бекіту туралы

«Дербес деректер және оларды қорғау туралы» Қазақстан Республикасының 2013 жылғы 21 мамырдағы Заңының 25-бабының 2-тармағының 1) тармақшасына және Қазақстан Республикасы Президентінің 2002 жылғы 5 тамыздағы № 917 Жарлығымен бекітілген Республикалық бюджеттің атқарылуын бақылау жөніндегі есеп комитеті туралы ереженің 19-тармағының 3) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған Жүзеге асырылатын міндеттерді орындау үшін қажетті және жеткілікті дербес деректердің тізбесі бекітілсін.

<a id="p2"></a>

2. Персоналды басқару секторы (С.Д. Тәженова) Қазақстан Республикасының заңнамасына сәйкес, дербес деректерді қорғауды қамтамасыз етсін.

<a id="p3"></a>

3. Заң бөлімі (Ю.Ф. Энгель) заңнамамен белгіленген тәртіпте:

   1) бұйрықтың Қазақстан Республикасы Әділет министрлігінде мемлекеттік тіркелуін қамтамасыз етсін;

   2) бұйрық Қазақстан Республикасы Әділет министрлігінде мемлекеттік тіркелгеннен кейін оны 10 күнтізбелік күн ішінде бұқаралық ақпарат құралдарына ресми жариялануға жолдасын.

<a id="p4"></a>

4. Бұйрықтың орындалуын бақылау аппарат басшысына (М.Т. Райымқұлов) жүктелсін.

<a id="p5"></a>

5. Бұйрық өздеріне қатысы бойынша Республикалық бюджеттің атқарылуын бақылау жөніндегі есеп комитетінің лауазымды адамдарының назарына жеткізілсін.

<a id="p6"></a>

6. Осы бұйрық 2011 жылғы 25 қарашадан бастап қолданысқа енгізіледі.

## Жүзеге асырылатын міндеттерді орындау үшін қажетті және жеткілікті дербес деректердің тізбесі

<a id="an0_p1"></a>

1. Тегі;

<a id="an0_p2"></a>

2. Аты;

<a id="an0_p3"></a>

3. Әкесінің аты (бар болған жағдайда);

<a id="an0_p4"></a>

4. Тегін, атын, әкесінің атын ауыстырғаны туралы мәліметтер;

<a id="an0_p5"></a>

5. Туған жылы, күні және айы;

<a id="an0_p6"></a>

6. Туған жері;

<a id="an0_p7"></a>

7. Ұлты;

<a id="an0_p8"></a>

8. Жынысы;

<a id="an0_p9"></a>

9. Жеке басын куәландыратын құжаттың деректері: құжаттың атауы; құжаттың нөмірі; құжаттың берілген күні; құжаттың жарамдылық мерзімі; құжатты берген орган.

<a id="an0_p10"></a>

10. Отбасы жағдайы туралы мәлімет: неке жағдайы; неке қию туралы куәлік деректері; неке бұзу туралы куәлік деректері; жұбайының тегі, аты, әкесінің аты (бар болған жағдайда); жұбайының жеке басын куәландыратын құжаттың деректері; отбасының басқа мүшелерінің, қарауындағы адамдардың тегі, аты, әкесінің аты (бар болған жағдайда) және туған күндері; балаларының бар-жоғы, туу туралы куәлік деректері.

<a id="an0_p11"></a>

11. Әскери міндетті адамдарды және әскери қызметке шақыруға жататын адамдарды әскери есепке алу туралы мәліметтер: әскери билеттің сериясы, нөмірі, берілген (тапсырған) күні; әскери билетті берген органның атауы; әскери-есепке алу мамандығы; әскери атағы; есепке алу/шығару туралы деректер; әскери қызметтен босату негізі.

<a id="an0_p12"></a>

12. Азаматтығы туралы мәліметтер: азаматтығы (бұрынғы азаматтығы); Қазақстан Республикасы азаматтығын алған күні; Қазақстан Республикасы азаматтығын жоғалтқан күні.

<a id="an0_p13"></a>

13. Жеке сәйкестендіру нөмірі (ЖСН).

<a id="an0_p14"></a>

14. Зейнетақы шартының көшірмесі.

<a id="an0_p15"></a>

15. Портреттік бейнесі (цифрланған фотосуреті).

<a id="an0_p16"></a>

16. Білімі, біліктілігі және арнайы атақтарының немесе арнайы даярлығының бар-жоғы туралы мәлімет (дипломның, куәліктің, аттестаттың немесе білім беру мекемесін бітіргені туралы басқа да құжаттың сериясы, нөмірі, берілген күні, соның ішінде білім беру мекемесінің атауы және орналасқан жері, факультеті немесе бөлімі, білім беру мекемесін бітіргеннен кейінгі біліктілігі және мамандығы, ғылыми деңгейі, ғылыми атағы, шетел тілдерін білуі).

<a id="an0_p17"></a>

17. Ағымдағы уақыттағы еңбек қызметі туралы деректер: лауазымын, құрылымдық бөлімшесін, ұйымын, оның атауын толық көрсету; жалпы және үздіксіз еңбек өтілі; мекенжайлары және телефондары, сондай-ақ басқа ұйымдарда бұрын атқарған лауазымының толық атауын және осы ұйымдарда жұмыс істеген уақытын көрсете отырып, олардың атаулары.

<a id="an0_p18"></a>

18. Мемлекеттік және ведомстволық наградалары, құрмет және арнайы атақтары, көтермелеулері туралы мәліметтер; награда, атақ немесе көтермелеу атауы немесе аты; марапаттау туралы нормативтік актінің күні мен түрі немесе көтермелеу күні.

<a id="an0_p19"></a>

19. Мекенжайы мен телефоны.

<a id="an0_p20"></a>

20. Салық декларациясын тапсыру туралы мәліметтер.

<a id="an0_p21"></a>

21. Бұрынғы жұмыс орнындағы жалақысы және соңғы еңбек демалысы туралы мәліметтер.

<a id="an0_p22"></a>

22. Коммерциялық ұйымдардың жарғылық капиталындағы өз үлесін, акцияларын (акциясын) және тұлғаға заң жүзінде тиесілі ақшаны қоспағанда, пайдаланылуы кіріс алуға әкеп соғатын өзге де мүлікті, сондай-ақ мүліктік жалға берілген мүліктік сенімгерлік басқаруға беру туралы мәліметтер.

<a id="an0_p23"></a>

23. Денсаулық жағдайы туралы анықтамалар.

<a id="an0_p24"></a>

24. Соттылығының болуы (болмауы) туралы мәліметтер.
