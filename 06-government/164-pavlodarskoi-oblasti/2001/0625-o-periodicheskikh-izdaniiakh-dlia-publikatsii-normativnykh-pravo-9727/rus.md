# О периодических изданиях для публикации нормативных правовых актов

Статьи 37 Закона Республики Казахстан от 23 января 2001 года «О местном государственном управлении в Республики Казахстана» акимат области ПОСТАНОВЛЯЕТ :

<a id="p1"></a>

1. Определить изданиями для официальных публикаций нормативных правовых актов и акима области государственные предприятия издания – газеты «Сарыарка самалы», «Звезда Прииртышья», «Павлодарский вестник».

<a id="p2"></a>

2. Признать утратившим силу распоряжение акима области от 200 года № 1-31-р «О периодических изданиях для публикации нормативных правовых актов».

<a id="p3"></a>

3. Подготовку документов для публикации возложить на руководителя аппарата акима области Бондаренко Г.И.

   **Аким области**

   **Г. Жакиянов**
