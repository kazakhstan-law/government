# Об установлении тарифа на регулярные автомобильные перевозки пассажиров и багажа на регулярных внутрирайонных маршрутах района Байдибек

В соответствии с пунктом 2 статьи 31 Закона Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», статьей 19 Закона Республики Казахстан «Об автомобильном транспорте» акимат района Байдибек ПОСТАНОВЛЯЕТ:

1. Установить тариф на регулярные социально значимые перевозки пассажиров по внутрирайонным маршрутам в районе Байдибек по указанному ниже курсу:

   1) 180 (сто восемьдесят) тенге на пассажира по маршруту «Шаян-Шакпак-Шаян»;

   2) 150 (сто пятьдесят) тенге на одного пассажира по маршруту «Шаян-Таскудук-Шаян»;

   3) 250 (двести пятьдесят) тенге на одного пассажира по маршруту «Шаян-Шалдар-Шаян»;

   4) 250 (двести пятьдесят) тенге на одного пассажира по маршруту «Шаян-Екпинди-Шаян»;

   5) 250 (двести пятьдесят) тенге на одного пассажира по маршруту «Шаян-Жулдыз-Шаян»;

   6) 350 (триста пятьдесят) тенге на одного пассажира по маршруту «Шаян-Саркырама-Шаян»;

   7) 500 (пятьсот) тенге на одного пассажира по маршруту «Шаян-Туракты-Шаян»;

   8) 400 (четыреста) тенге на одного пассажира по маршруту «Шаян-Жиенкум-Шаян»;

   9) 400 (четыреста) тенге на одного пассажира по маршруту «Шаян – Алмалы» Шаян»;

   10) 400 (четыреста) тенге на одного пассажира по маршруту «Шаян-Теректы-Шаян»;

   11) 500 (пятьсот) тенге на одного пассажира по маршруту «Шаян-Тайманов-Шаян»;

   12) 500 (пятьсот) тенге на одного пассажира по маршруту «Шаян- Кайнарбулак-Шаян»;

   13) 750 (семьсот пятьдесят) тенге на пассажира по маршруту «Шаян - Кенсай – Шаян»;

   14) (750 (семьсот пятьдесят) тенге на одного пассажира по маршруту «Шаян - Сарыбулак – Шаян».

2. Соблюдать требования статьи 20 Закона Республики Казахстан «Об автомобильном транспорте».

3. Контроль за исполнением настоящего постановления возложить на курирующего заместителя акима района.

4. Настоящее постановление вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
