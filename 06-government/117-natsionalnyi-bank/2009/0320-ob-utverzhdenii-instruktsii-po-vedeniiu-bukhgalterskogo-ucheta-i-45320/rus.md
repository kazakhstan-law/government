# Об утверждении Инструкции по ведению бухгалтерского учета исламскими специальными финансовыми компаниями

В целях установления порядка ведения бухгалтерского учета исламскими специальными финансовыми компаниями, в соответствии с пунктом 13 статьи 32-6 Закона Республики Казахстан от 2 июля 2003 года "О рынке ценных бумаг" Правление Национального Банка Республики Казахстан ПОСТАНОВЛЯЕТ:

<a id="p1"></a>

1. Утвердить прилагаемую Инструкцию по ведению бухгалтерского учета исламскими специальными финансовыми компаниями.

<a id="p2"></a>

2. Настоящее постановление вводится в действие по истечении четырнадцати дней со дня государственной регистрации в Министерстве юстиции Республики Казахстан.

<a id="p3"></a>

3. Департаменту бухгалтерского учета (Шалгимбаева Н.Т.):

   1) совместно с Юридическим департаментом (Шарипов С.Б.) принять меры к государственной регистрации в Министерстве юстиции Республики Казахстан настоящего постановления;

   2) в десятидневный срок со дня государственной регистрации в Министерстве юстиции Республики Казахстан настоящего постановления довести его до сведения заинтересованных подразделений центрального аппарата и территориальных филиалов Национального Банка Республики Казахстан, Агентства Республики Казахстан по регулированию и надзору финансового рынка и финансовых организаций и Объединения юридических лиц "Ассоциация финансистов Казахстана".

<a id="p4"></a>

4. Контроль за исполнением настоящего постановления возложить на заместителя Председателя Национального Банка Республики Казахстан Галиеву Д.Т.

**Председатель Национального Банка**

## Инструкция по ведению бухгалтерского учета исламскими специальными финансовыми компаниями

### Глава 1. Общие положения

<a id="an0_p1"></a>

1. Настоящая Инструкция разработана в соответствии с законами Республики Казахстан от 30 марта 1995 года «О Национальном Банке Республики Казахстан», от 2 июля 2003 года «О рынке ценных бумаг», от 28 февраля 2007 года «О бухгалтерском учете и финансовой отчетности», международными стандартами финансовой отчетности и детализирует ведение бухгалтерского учета исламскими специальными финансовыми компаниями (далее – организация).

> *Сноска. Пункт 1 в редакции постановления Правления Национального Банка РК от 17.07.2015 № 131 (вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования).*

<a id="an0_p2"></a>

2. В настоящей Инструкции используются понятия, предусмотренные Законами Республики Казахстан от 2 июля 2003 года «О рынке ценных бумаг», от 28 февраля 2007 года «О бухгалтерском учете и финансовой отчетности» и международными стандартами финансовой отчетности.

> *Сноска. Пункт 2 в редакции постановления Правления Национального Банка РК от 28.01.2016 № 6 (вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования).*

<a id="an0_p3"></a>

3. Допускается совершение дополнительных бухгалтерских записей, не противоречащих требованиям настоящей Инструкции и законодательству Республики Казахстан о бухгалтерском учете и финансовой отчетности.

### Глава 2. Бухгалтерский учет исламских арендных сертификатов

<a id="an0_p4"></a>

4. При выпуске исламских арендных сертификатов на сумму денег, полученных в результате их размещения, осуществляется следующая бухгалтерская запись:

```
     Дт 1030    "Денежные средства на текущих счетах"
     Кт 4030 94 "Выпущенные в обращение исламские арендные
                сертификаты".
```

<a id="an0_p5"></a>

5. При приобретении имущества на деньги, полученные в результате размещения исламских арендных сертификатов, осуществляется следующая бухгалтерская запись:

```
     Дт 1280 92 "Выделенные активы исламской специальной финансовой
                компании"
```

```
     Кт 1030    "Денежные средства на текущих счетах".
```

<a id="an0_p6"></a>

6. При предоставлении имущества в аренду осуществляется следующая бухгалтерская запись:

```
     Дт 1280 93 "Выделенные активы исламской специальной финансовой
                компании, переданные в аренду (финансовый лизинг)"
     Кт 1280 92 "Выделенные активы исламской специальной финансовой
                компании".
```

<a id="an0_p7"></a>

7. При амортизации основных средств, приобретенных на деньги, полученные в результате размещения исламских арендных сертификатов, и предоставленных в аренду (операционная аренда), осуществляется следующая бухгалтерская запись:

```
     Дт 7450    "Расходы по операционной аренде"
     Кт 1280 94 "Амортизация выделенных активов исламской
                специальной финансовой компании, переданных в
                аренду".
```

<a id="an0_p8"></a>

8. При начислении платежей по договору аренды (финансового лизинга) имущества, приобретенного на деньги, полученные в результате размещения исламских арендных сертификатов, осуществляются следующие бухгалтерские записи:

1) по договорам операционной аренды:

```
     Дт 1270 91 "Начисленные доходы от сдачи имущества в аренду"
     Кт 6260    "Доходы от операционной аренды";
```

2) по договорам финансовой аренды:

```
     Дт 1280 93 "Выделенные активы исламской специальной финансовой
                компании, переданные в аренду (финансовый лизинг)"
     Кт 6130    "Доходы от финансовой аренды".
```

<a id="an0_p9"></a>

9. При получении платежей по договору аренды имущества, приобретенного на деньги, полученные в результате размещения исламских арендных сертификатов, осуществляются следующие бухгалтерские записи:

1) по договорам операционной аренды:

```
     Дт 1060 91 "Выделенные активы специальной финансовой компании
                 на текущих счетах в банке-кастодиане"
     Кт 1270 91 "Начисленные доходы от сдачи имущества в аренду";
```

2) по договорам финансовой аренды:

```
     Дт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане"
     Кт 1280 93 "Выделенные активы исламской специальной финансовой
                компании, переданные в аренду (финансовый лизинг)".
```

<a id="an0_p10"></a>

10. При начислении расходов по выпущенным в обращение исламским арендным сертификатам осуществляется следующая бухгалтерская запись:

```
     Дт 7310 93 "Расходы, связанные с выплатой дохода по исламским
                арендным сертификатам"
     Кт 4160 01 "Начисленные расходы в виде вознаграждения по ценным
                бумагам, выпущенным в обращение".
```

<a id="an0_p11"></a>

11. При выплате доходов по выпущенным в обращение исламским арендным сертификатам, осуществляется следующая бухгалтерская запись:

```
     Дт 4160 01 "Начисленные расходы в виде вознаграждения по ценным
                бумагам, выпущенным в обращение"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане".
```

<a id="an0_p12"></a>

12. При выкупе оригинатором имущества у организации, осуществляются следующие бухгалтерские записи:

1) на сумму выкупаемого имущества:

```
     Дт 1030    "Денежные средства на текущих счетах"
     Кт 1280 93 "Выделенные активы исламской специальной финансовой
                компании, переданные в аренду (финансовый лизинг)";
```

2) и одновременно, на сумму погашаемых исламских арендных сертификатов:

```
     Дт 4030 94 "Выпущенные в обращение исламские арендные
                 сертификаты"
     Кт 1030    "Денежные средства на текущих счетах".
```

### Глава 3. Бухгалтерский учет исламских сертификатов участия

<a id="an0_p13"></a>

13. При размещении исламских сертификатов участия на сумму выпуска организацией осуществляется следующая бухгалтерская запись:

```
     Дт 1030    "Денежные средства на текущих счетах"
     Кт 4030 95 "Выпущенные в обращение исламские сертификаты
                участия".
```

<a id="an0_p14"></a>

14. При инвестировании средств, полученных в результате размещения исламских сертификатов участия, в инвестиционный проект (новый и/или существующий) или финансировании предпринимательской деятельности на основании договора простого товарищества либо с созданием юридического лица в организационно-правовой форме акционерного общества или товарищества с ограниченной ответственностью (далее - инвестиционный проект) осуществляется следующая бухгалтерская запись:

```
     Дт 1280 95 "Выделенные активы исламской специальной финансовой
                компании в инвестиционных проектах"
     Кт 1030    "Денежные средства на текущих счетах".
```

<a id="an0_p15"></a>

15. При передаче акций (долей участия), принадлежащих организации, в доверительное управление оригинатору для участия в инвестиционном проекте осуществляется следующая бухгалтерская запись:

```
     Приход    8760    "Акции (доли участия), переданные в доверительное
                        управление оригинатору"
```

<a id="an0_p16"></a>

16. При получении дохода по инвестиционному проекту осуществляется следующая бухгалтерская запись:

```
     Дт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане"
     Кт 6120    "Доходы по дивидендам"
        6400    "Доля прибыли организаций, учитываемых по методу
                долевого участия".
```

<a id="an0_p17"></a>

17. При выплате дохода по инвестиционному проекту оригинатору согласно условиям проспекта выпуска исламских сертификатов участия осуществляются следующие бухгалтерские записи:

```
     Дт 7310 94 "Расходы, связанные с выплатой дохода по исламским
                сертификатам участия"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане"
     и, одновременно, на сумму дохода организации:
     Дт 1030    "Денежные средства на текущих счетах"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане".
```

<a id="an0_p18"></a>

18. В случае если проспектом выпуска исламских сертификатов участия предусмотрено получение оригинатором комиссионного вознаграждения на сумму выплачиваемого комиссионного вознаграждения осуществляется следующая бухгалтерская запись:

```
     Дт 7470 26 "Комиссионные расходы за услуги по доверительным
                операциям"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане".
```

<a id="an0_p19"></a>

19. При возврате средств, полученных в результате размещения исламских сертификатов участия и инвестированных в инвестиционный проект, осуществляется следующая бухгалтерская запись:

```
     Дт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане"
     Кт 1280 95 "Выделенные активы исламской специальной финансовой
                компании в инвестиционных проектах".
```

<a id="an0_p20"></a>

20. При погашении исламских сертификатов участия осуществляется следующая бухгалтерская запись:

```
     Дт 4030 95 "Выпущенные в обращение исламские сертификаты
                участия"
        7310 94 "Расходы, связанные с выплатой дохода по исламским
                сертификатам участия"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане".
```

<a id="an0_p21"></a>

21. При изъятии акций (долей участия), принадлежащих организации, из доверительного управления оригинатора осуществляется следующая бухгалтерская запись:

```
     Расход     8760    "Акции (доли участия), переданные
                         в доверительное управление оригинатору".
```

### Глава 4. Бухгалтерский учет операций по созданию резервного фонда

<a id="an0_p22"></a>

22. При создании резервного фонда, предназначенного для покрытия убытков, возникающих в результате инвестирования денег, полученных от размещения исламских ценных бумаг, осуществляются следующие бухгалтерские записи:

```
     Дт 7440 91 "Расходы по формированию резервного фонда по
                исламским ценным бумагам"
     Кт 4030 96 "Резервный фонд по исламским ценным бумагам".
```

<a id="an0_p23"></a>

23. При уменьшении (аннулировании) резервного фонда, предназначенного для покрытия убытков, возникающих в результате инвестирования денег, полученных от размещения исламских ценных бумаг, осуществляется следующая бухгалтерская запись:

```
     Дт 4030 96 "Резервный фонд по исламским ценным бумагам"
     Кт 6240 91 "Доходы от восстановления (аннулирования) резервного
                фонда по исламским ценным бумагам".
```

<a id="an0_p24"></a>

24. При возмещении держателям исламских ценных бумаг убытков, возникших в результате инвестирования денег, полученных от размещения исламских ценных бумаг, осуществляется следующая бухгалтерская запись:

```
     Дт 4030 96 "Резервный фонд по исламским ценным бумагам"
     Кт 1060 91 "Выделенные активы специальной финансовой компании
                на текущих счетах в банке-кастодиане".
```
