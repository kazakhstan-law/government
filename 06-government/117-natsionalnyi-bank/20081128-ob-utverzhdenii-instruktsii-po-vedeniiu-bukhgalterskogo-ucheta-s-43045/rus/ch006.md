## Глава 6. Бухгалтерский учет договоров займа

> *Сноска. Инструкция дополнена главой 6 в соответствии с постановлением Правления Национального Банка РК от 24.02.2012 № 43 (вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования); в редакции постановления Правления Национального Банка РК от 02.11.2017 № 200 (вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования).*

68. На дату заключения договоров займа с кредитором, обеспеченных выделенными активами, в целях исполнения сделки проектного финансирования осуществляются следующие бухгалтерские записи:

1) на сумму привлеченного займа (не превышающую фактическую сумму по договору):

```
      Дт 1030    "Денежные средства на текущих счетах"
      Кт 3010    "Краткосрочные банковские займы",
         3050 04 "Краткосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций"
         4010    "Долгосрочные банковские займы",
         4030 03 "Долгосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций";
```

2) на сумму понесенных организацией расходов в виде комиссионных расходов, связанных с получением займа (на сумму скидки):

```
      Дт 3050 06 "Дисконт по краткосрочным полученным займам",
         4030 12 "Дисконт по долгосрочным полученным займам"
         3010    "Краткосрочные банковские займы",
         3050 04 "Краткосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций",
         4010    "Долгосрочные банковские займы",
         4030 03 "Долгосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций";
```

69. При передаче исполнителю денег, полученных от кредитора, осуществляется следующая бухгалтерская запись:

```
      Дт 3390 92 "Обязательства перед исполнителем"
      Кт 1030    "Денежные средства на текущих счетах".
```

70. При начислении расходов по привлеченным займам, включая амортизацию дисконта (скидки), на каждую отчетную дату осуществляются следующие бухгалтерские записи:

1) на сумму начисленного вознаграждения:

```
      Дт 7310 24 "Расходы, связанные с выплатой вознаграждения по
                 полученным займам"
      Кт 3380 25 "Начисленные расходы в виде вознаграждения по
                 полученным займам";
```

2) на сумму амортизации дисконта:

```
      Дт 7310 07 "Расходы по амортизации дисконта по полученным
                 займам"
      Кт 3050 06 "Дисконт по краткосрочным полученным займам",
         4030 12 "Дисконт по долгосрочным полученным займам";
```

71. При выплате начисленного вознаграждения по договору займа, осуществляется следующая бухгалтерская запись:

```
      Дт 3380 25 "Начисленные расходы в виде вознаграждения по
                 полученным займам"
      Кт 1030    "Денежные средства на текущих счетах"
```

72. При погашении основного долга займа осуществляются следующие бухгалтерские записи:

```
      Дт 3010    "Краткосрочные банковские займы",
         3050 04 "Краткосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций",
         4010    "Долгосрочные банковские займы",
         4030 03 "Долгосрочные займы, полученные от организаций,
                 осуществляющих отдельные виды банковских операций"
      Кт 1030 "Денежные средства на текущих счетах".
```
